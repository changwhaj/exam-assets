PTR: 역방향 DNS 조회는 원격 호스트에서 IP 주소를 '소유한' 사람을 확인하는 데 사용됩니다. 참조: https://www.mailenable.com/kb/content/article.asp?ID=ME020206 CNAME 레코드는 DNS 이름이나 하위 도메인 이름을 다른 DNS 이름이나 도메인 이름 또는 하위 도메인 이름으로 리디렉션하는 데 사용됩니다. 참조: https://support.dnsimple.com/articles/cname-record/ DNS 레코드 유형과 그 용도에 대해 읽어보면 좋을 것 같습니다. 기본적인 이해가 없다면 길을 잃을 것입니다. https://ns1.com/resources/dns-types-records-servers-and-queries DNS는 IT 분야의 핵심 구성 요소입니다. 이 정보가 도움이 되기를 바랍니다.

To resolve the records of a private DNS zone from your virtual network, you must link the virtual network with the zone. Linked virtual networks have full access and can resolve all DNS records published in the private zone. You can also enable autoregistration on a virtual network link. When you enable autoregistration on a virtual network link, the DNS records for the virtual machines in that virtual network are registered in the private zone. When autoregistration gets enabled, Azure DNS will update the zone record whenever a virtual machine gets created, changes its' IP address, or gets deleted. https://docs.microsoft.com/en-us/azure/dns/private-dns-overview
