주제 #: 4

Azure Kubernetes Service(AKS) 클러스터에서 호스팅될 마이크로서비스 아키텍처를 디자인하고 있습니다. 마이크로서비스를 사용하는 앱은 Azure 가상 머신에서 호스팅됩니다. 가상 머신과 AKS 클러스터는 동일한 가상 네트워크에 상주합니다.
소비자 앱에 마이크로서비스를 노출하는 솔루션을 디자인해야 합니다. 솔루션은 다음 요구 사항을 충족해야 합니다.
✑ 마이크로서비스에 대한 수신 액세스는 단일 개인 IP 주소로 제한되어야 하며 상호 TLS 인증을 사용하여 보호되어야 합니다.
✑ 수신 마이크로서비스 호출 수는 속도 제한되어야 합니다.
✑ 비용은 최소화되어야 합니다.
솔루션에 무엇을 포함해야 합니까?

  • A. Azure 웹 애플리케이션 방화벽(WAF)이 있는 Azure 앱 게이트웨이
  • B. 서비스 엔드포인트가 있는 Azure API 관리 표준 계층
  • C. Azure 웹 애플리케이션 방화벽(WAF)을 갖춘 Azure Front Door
  • D. 가상 네트워크 연결이 있는 Azure API Management 프리미엄 계층 가장 많이 투표된

You need to design a solution to expose the microservices to the consumer apps. The solution must meet the following requirements:
✑ Ingress access to the microservices must be restricted to a single private IP address and protected by using mutual TLS authentication.

✑ Costs must be minimized.
