주제 #: 1

HOTSPOT -
Azure Active Directory(Azure AD) 인증을 사용하는 App1이라는 Azure 웹앱을 배포할 계획입니다.
App1은 회사 사용자가 인터넷을 통해 액세스합니다. 모든 사용자는 Windows 10을 실행하고 Azure AD에 가입된 컴퓨터를 가지고 있습니다.
사용자가 인증을 요구받지 않고 App1에 연결할 수 있고 회사 소유의 컴퓨터에서만 App1에 액세스할 수 있도록 하는 솔루션을 추천해야 합니다.
각 요구 사항에 대해 무엇을 추천해야 합니까? 답하려면 답변 영역에서 적절한 옵션을 선택하세요.
참고: 각 정답은 1점입니다.
핫 영역:

제안된 답변 보기 답변 숨기기
제안된 답변:
상자 1: Azure AD 앱 등록
Azure Active Directory(AD)는 클라우드 기반 디렉터리 및 ID 관리 서비스를 제공합니다. Azure AD를 사용하여 애플리케이션 사용자를 관리하고 Azure Active Directory를 사용하여 애플리케이션에 대한 액세스를 인증할 수 있습니다.
애플리케이션을 Azure Active Directory 테넌트에 등록합니다.
상자 2: 조건부 액세스 정책
조건부 액세스 정책은 가장 단순한 if-then 문으로, 사용자가 리소스에 액세스하려면 작업을 완료해야 합니다.
조건부 액세스 정책을 사용하면 필요할 때 적절한 액세스 제어를 적용하여 조직의 보안을 유지하고 필요하지 않을 때 사용자의 방해가 되지 않도록 할 수 있습니다.

Actual exam question from Microsoft's AZ-305
Question #: 6
Topic #: 1

HOTSPOT -
You plan to deploy an Azure web app named App1 that will use Azure Active Directory (Azure AD) authentication.
App1 will be accessed from the internet by the users at your company. All the users have computers that run Windows 10 and are joined to Azure AD.
You need to recommend a solution to ensure that the users can connect to App1 without being prompted for authentication and can access App1 only from company-owned computers.
What should you recommend for each requirement? To answer, select the appropriate options in the answer area.
NOTE: Each correct selection is worth one point.
Hot Area:

Show Suggested Answer Hide Answer
Suggested Answer:
Box 1: An Azure AD app registration
Azure active directory (AD) provides cloud based directory and identity management services.You can use azure AD to manage users of your application and authenticate access to your applications using azure active directory.
You register your application with Azure active directory tenant.
Box 2: A conditional access policy
Conditional Access policies at their simplest are if-then statements, if a user wants to access a resource, then they must complete an action.
By using Conditional Access policies, you can apply the right access controls when needed to keep your organization secure and stay out of your user's way when not needed.
