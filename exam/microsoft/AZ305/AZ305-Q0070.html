There are two types of Virtual WANs. one is the BASIC and the second one is STANDARD. BASIC supports only SITE to SITE VPN. STANDARD supports below configs, ExpressRoute User VPN (P2S) VPN (site-to-site) Inter-hub and VNet-to-VNet transiting through the virtual hub Azure Firewall NVA in a virtual WAN NOTE: You can upgrade from Basic to Standard, but you cannot revert from Standard back to Basic.

A. Upgrade VirtualWAN1 to Standard. To create an ExpressRoute association with VirtualWAN1, you need to upgrade VirtualWAN1 from the Basic tier to the Standard tier.
