Selected Answer: D
D. Session persistence to Client IP. To ensure that visitors are serviced by the same web server for each request, you need to enable session persistence, which maps a client's session to a specific server. In this case, you would want to use Client IP session persistence so that subsequent requests from the same client are sent to the same web server. Floating IP (direct server return) is an option that enables traffic to bypass the load balancer and go directly to the backend servers. This is typically used for scenarios where the backend servers need to return traffic directly to the client, such as for media streaming or UDP-based protocols. However, it is not relevant for ensuring session persistence.
