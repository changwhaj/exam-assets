질문 #: 20
주제 #: 1

드래그 앤 드롭 -
여러 가상 머신(VM)을 배포하기 위해 Azure Resource Manager(ARM) 템플릿을 다운로드했습니다. ARM 템플릿은 현재 VM을 기반으로 하지만 관리자 암호를 참조하도록 조정해야 합니다.
암호가 일반 텍스트로 저장될 수 없도록 해야 합니다.
목표를 달성하기 위해 필요한 구성 요소를 만들 준비를 하고 있습니다.
목표를 달성하기 위해 다음 중 어떤 것을 만들어야 합니까? 목록에서 정답 영역으로 올바른 옵션을 끌어서 답하십시오.
선택 및 배치:

제안된 답변 보기 답변 숨기기
제안된 답변: An Azure Key Vault, An access policy
Azure Key Vault: 암호, 키, 인증서 등의 비밀 정보를 안전하게 저장하고 관리할 수 있는 서비스입니다. 관리자 암호를 Key Vault에 저장하면, ARM 템플릿에서 이 비밀 정보를 참조하여 VM을 배포할 수 있습니다. 이를 통해 암호를 일반 텍스트로 템플릿에 포함시키지 않고도 안전하게 사용할 수 있습니다.

액세스 정책: Key Vault에 저장된 비밀 정보에 대한 액세스를 제어하는 정책입니다. 이를 통해 어떤 사용자나 서비스가 특정 비밀에 접근할 수 있는지를 정의할 수 있습니다. ARM 템플릿이 Key Vault에서 비밀 정보를 가져올 수 있도록 적절한 액세스 권한을 부여해야 합니다.

따라서, 관리자 암호를 안전하게 관리하고 ARM 템플릿에서 이를 참조하려면, 먼저 Azure Key Vault에 암호를 저장하고, 해당 템플릿이 이 비밀에 접근할 수 있도록 적절한 액세스 정책을 설정해야 합니다.
