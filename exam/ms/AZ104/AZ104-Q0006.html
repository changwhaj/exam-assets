You can't change the usage model (per enabled user or per authentication) after an MFA provider is created. If you purchased enough licenses to cover all users that are enabled for MFA, you can delete the MFA provider altogether. If your MFA provider isn't linked to a Microsoft Entra tenant, or you link the new MFA provider to a different Microsoft Entra tenant, user settings and configuration options aren't transferred. Also, existing Microsoft Entra multifactor authentication Servers need to be reactivated using activation credentials generated through the MFA Provider.
