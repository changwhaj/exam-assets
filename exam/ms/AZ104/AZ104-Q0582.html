To ensure that when a new Microsoft 365 group is created, the group name is automatically formatted as <Department><Group name>, you need to configure a group naming policy in Microsoft Entra (formerly Azure AD). This can be achieved by setting a prefix based on the department attribute. 1- Create a group naming policy: This is the first step to establish the framework for naming groups. 2- Set Add prefix to Attribute: This step specifies that the prefix will be an attribute rather than a static string. 3- Set Select type to Department: Finally, you specify that the 'Department' attribute will be used as the prefix.
