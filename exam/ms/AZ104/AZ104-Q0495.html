Microsoft 365 그룹과 보안 그룹에는 라이선스를 할당할 수 있지만, 메일 사용 가능 보안 그룹에는 할당할 수 없습니다. 또한, 라이선스를 할당받으려면 그룹에 보안이 활성화되어 있어야 합니다. 다음 목록에서: 그룹1: 보안 그룹(보안 활성화) - 라이선스를 할당할 수 있습니다. 그룹2: 메일 사용 가능 보안 그룹(보안 활성화) - 메일 사용 가능 보안 그룹에 라이선스를 할당할 수 없습니다. 그룹3: Microsoft 365 그룹(보안 활성화) - 라이선스를 할당할 수 있습니다. 그룹4: Microsoft 365 그룹(보안 비활성화) - 보안이 비활성화된 그룹에 라이선스를 할당할 수 없습니다. 정답은 B입니다. 그룹1과 그룹3에만 해당됩니다.
