For the AKS cluster, you need to choose a network type that will support App1.
What should you choose?

  • A. kubenet
  • B. Azure Container Networking Interface (CNI) Most Voted

선택된 답변: B
꿀을 좋아하는 이유는 B이기 때문입니다. Kubnetes 네트워킹을 사용하는 경우 논리적으로 다른 주소 공간에서 Azure Virtual Network 서브넷으로 IP 주소를 수신하고 NAT를 사용하여 POD에서 Azure Virtual Network로 IP를 변환하고 그 반대의 경우도 마찬가지입니다. Azure Container Networking Interface(ACNI)를 사용하는 경우: 모든 POD가 서브넷에서 IP를 가져와 직접 액세스할 수 있지만 이러한 방법의 유일한 문제점은 IP 주소 고갈로 이어질 수 있다는 것입니다.
