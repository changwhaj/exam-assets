Bing Copilot: No, selecting “Use dedicated data endpoint” for Registry1 does not directly address the issue of deploying a container instance using image1. The error message you received likely indicates that the image is inaccessible. This can happen due to several reasons, such as incorrect credentials or firewall rules blocking access12. To resolve this issue, you should ensure that: The credentials used to access the Azure Container Registry are correct. The Azure Container Registry allows access from the Azure Container Instances service. You can achieve this by enabling the “Allow trusted services” option or using a managed identity12.
