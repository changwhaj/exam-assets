A. From the Licenses blade of Azure AD, assign a license Here's how you can do it: Sign in to the Azure portal using an account with administrative privileges. In the left-hand menu, go to "Azure Active Directory." Under "Azure Active Directory," click on "Licenses." In the "Licenses" blade, you should see the purchased Azure AD Premium P2 licenses. Select the Azure AD Premium P2 license. In the "Assignments" section, click on "Add assignments." Choose the users you want to assign the licenses to. In this case, select 10 users. Click the "Save" button to assign the Azure AD Premium P2 licenses to the selected users. This action will ensure that these 10 users have access to all Azure AD Premium features included with the P2 license.
