VPN gateways An Azure VPN Gateway connects an Azure virtual network to other Azure virtual networks, or to an on-premises network. A public IP address is assigned to the VPN Gateway to enable it to communicate with the remote network. You can only assign a dynamic basic public IP address to a VPN gateway Refe: https://stackoverflow.com/questions/51881442/azure-static-ip-for-vpn The public IP address is dynamically assigned to this object when the VPN gateway is created. The only time the Public IP address changes is when the gateway is deleted and re-created. It doesn't change across resizing, resetting, or other internal maintenance/upgrades of your VPN gateway. Refe: https://docs.microsoft.com/en-us/azure/vpn-gateway/tutorial-site-to-site-portal So with these reference the answer is/should be correct: C
