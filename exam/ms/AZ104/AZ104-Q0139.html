You create an Azure Storage account named contosostorage.
You plan to create a file share named data.
Users need to map a drive to the data file share from home computers that run Windows 10.
Which outbound port should you open between the home computers and the data file share?

  • A. 80
  • B. 443
  • C. 445 Most Voted
  • D. 3389

To map a drive to the Azure file share from home computers that run Windows 10, you need to open outbound port 445. So the correct answer is: C. 445 This port is used for SMB (Server Message Block) protocol, which is what Windows uses for file sharing. Note that some ISPs block this port, so if you experience issues, a VPN or Azure ExpressRoute connection may be necessary to allow the traffic. Always ensure you are following security best practices when opening ports, especially when dealing with potentially sensitive data.
