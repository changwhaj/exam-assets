Microsoft의 AZ-305 의 실제 시험 문제
질문 #: 12
주제 #: 2

드래그 앤 드롭 -
온프레미스 환경에서 Azure로 데이터를 가져오려고 합니다. 다음 표에 데이터가 나와 있습니다.

데이터를 마이그레이션하는 데 무엇을 사용하는 것이 좋을까요? 답하려면 적절한 도구를 올바른 데이터 소스로 드래그하세요. 각 도구는 한 번, 두 번 이상 또는 전혀 사용하지 않을 수 있습니다. 창 사이의 분할 막대를 드래그하거나 스크롤하여 콘텐츠를 확인해야 할 수도 있습니다.
참고: 올바른 선택 항목은 각각 1점입니다.
선택 및 배치:

제안된 답변 보기 답변 숨기기
제안된 답변:
상자 1: 데이터 마이그레이션 어시스턴트 -
데이터 마이그레이션 어시스턴트(DMA)는 새 버전의 SQL Server 또는 Azure SQL Database에서 데이터베이스 기능에 영향을 줄 수 있는 호환성 문제를 감지하여 최신 데이터 플랫폼으로 업그레이드하는 데 도움이 됩니다. DMA는 대상 환경에 대한 성능 및 안정성 개선을 권장하며 스키마, 데이터 및 포함되지 않은 개체를 원본 서버에서 대상 서버로 이동할 수 있도록 합니다.
잘못된 예:
AzCopy는 저장소 계정에서 BLOB 또는 파일을 복사하는 데 사용할 수 있는 명령줄 유틸리티입니다.
상자 2: Azure Cosmos DB 데이터 마이그레이션 도구
Azure Cosmos DB 데이터 마이그레이션 도구를 사용하여 SQL Server 데이터베이스 테이블을 Azure Cosmos로 마이그레이션할 수 있습니다.
참조:
https://docs.microsoft.com/en-us/sql/dma/dma-overview
https://docs.microsoft.com/en-us/azure/cosmos-db/cosmosdb-migrationchoices

DRAG DROP -
You plan to import data from your on-premises environment to Azure. The data is shown in the following table.

What should you recommend using to migrate the data? To answer, drag the appropriate tools to the correct data sources. Each tool may be used once, more than once, or not at all. You may need to drag the split bar between panes or scroll to view content.
NOTE: Each correct selection is worth one point.
Select and Place:

Show Suggested Answer Hide Answer
Suggested Answer:
Box 1: Data Migration Assistant -
The Data Migration Assistant (DMA) helps you upgrade to a modern data platform by detecting compatibility issues that can impact database functionality in your new version of SQL Server or Azure SQL Database. DMA recommends performance and reliability improvements for your target environment and allows you to move your schema, data, and uncontained objects from your source server to your target server.
Incorrect:
AzCopy is a command-line utility that you can use to copy blobs or files to or from a storage account.
Box 2: Azure Cosmos DB Data Migration Tool
Azure Cosmos DB Data Migration Tool can used to migrate a SQL Server Database table to Azure Cosmos.
Reference:
https://docs.microsoft.com/en-us/sql/dma/dma-overview
https://docs.microsoft.com/en-us/azure/cosmos-db/cosmosdb-migrationchoices
