Deploy domain controllers for corp.fabrikam.com to virtual networks in Azure. Authentication during Internet Failure: By deploying domain controllers (DCs) for corp.fabrikam.com to virtual networks in Azure, users on the on-premises network can authenticate to corp.fabrikam.com even if an internet link fails. This ensures high availability and redundancy for authentication services. Azure Portal Authentication: Deploying domain controllers to virtual networks in Azure enables administrators to authenticate to the Azure portal using their corp.fabrikam.com credentials. This integration ensures a seamless single sign-on (SSO) experience.
