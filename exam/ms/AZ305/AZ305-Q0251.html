1. **Protection against Open Web Application Security Project (OWASP) Vulnerabilities**: This function is provided by **Azure Front Door**. It offers platform-level protection against network-level DDoS attacks¹. It also provides a Web Application Firewall². 2. **IP Filtering on a per-API level**: This function is provided by **Azure API Management**.
