You need to deploy an Azure Monitor monitoring solution for App. The solution must meet the following requirements:

• Support using synthetic transaction monitoring to monitor traffic between the App1 components.
• Minimize development effort.

What should you include in the solution?

  • A. Network insights
  • B. Application Insights Most Voted
  • C. Container insights
  • D. Log Analytics Workspace insights

B. Application Insights Explanation: Application Insights is a feature of Azure Monitor that provides deep insights into your application. It supports synthetic transaction monitoring, which allows you to create tests that simulate user interactions with your app to monitor its availability and performance. Minimize Development Effort: Application Insights integrates seamlessly with Azure services and requires minimal configuration to start collecting telemetry data, making it the best choice to meet the requirements with minimal development effort.
