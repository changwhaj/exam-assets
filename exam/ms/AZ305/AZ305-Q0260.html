You need to perform daily backups of the servers to a Recovery Services vault. The solution must meet the following requirements:

• Back up all the files and folders on the servers.
• Maintain three copies of the backups in Azure.
• Minimize costs.

Box 1: The Microsoft Azure Recovery Services (MARS) agent The MARS agent is a free and easy-to-use agent that can be installed on Windows servers to back up files and folders to Azure. Volume Shadow Copy Service (VSS) is a Windows service that provides a snapshot of the server's file system, which is used to create consistent backups. The VSS service is already installed and enabled on Windows Server by default, so it is not necessary to select it as a configuration option. Box 2: Locally-redundant storage (LRS) LRS is the most cost-effective storage option for Azure Backup. It replicates data three times within a single data center in the primary region, which provides sufficient durability for most workloads.
