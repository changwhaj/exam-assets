• Failover between replicas of the database must occur without any data loss.
• The database must remain available in the event of a zone outage.
• Costs must be minimized.

Which deployment option should you use?

  • B. Azure SQL Managed Instance General Purpose
  • C. Azure SQL Database Basic
  • D. Azure SQL Database Business Critical

Azure SQL Database Business Critical 이유는 다음과 같습니다. 데이터 손실 없는 장애 조치: Business Critical 계층은 동기 복제를 사용하여 복제본 간의 장애 조치가 데이터 손실 없이 발생하도록 합니다. 영역 중단 복원력: 영역 중복성을 지원하여 영역 중단 시에도 데이터베이스가 계속 사용 가능하도록 합니다. 비용 효율성: 높은 가용성과 복원력을 제공하면서도 일반적으로 유사한 수준의 가용성과 데이터 무결성을 제공하는 다른 옵션에 비해 비용 효율적입니다. 이 옵션은 높은 가용성, 데이터 무결성, 비용 효율성을 균형 있게 조절하여 요구 사항에 가장 적합한 선택입니다.
