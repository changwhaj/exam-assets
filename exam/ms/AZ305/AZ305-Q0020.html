Microsoft의 AZ-305 의 실제 시험 문제
질문 #: 20
주제 #: 1

HOTSPOT -
다음 기능을 구현하는 Azure 정책을 설계해야 합니다.
✑ 새 리소스의 경우 리소스가 배포되는 리소스 그룹의 태그 및 값과 일치하는 태그 및 값을 할당합니다.
✑ 기존 리소스의 경우 태그 및 값이 리소스를 포함하는 리소스 그룹의 태그 및 값과 일치하는지 확인합니다.
✑ 비준수 리소스의 경우 자동 생성된 수정 작업을 트리거하여 누락된 태그 및 값을 만듭니다.
솔루션은 최소 권한의 원칙을 사용해야 합니다.
설계에 무엇을 포함해야 합니까? 답하려면 답변 영역에서 적절한 옵션을 선택합니다.
참고: 각 올바른 선택은 1점입니다.
핫 영역:

제안된 답변 보기 답변 숨기기
제안된 답변:
상자 1: 수정 -
수정은 생성 또는 업데이트 중에 구독이나 리소스에 속성이나 태그를 추가, 업데이트 또는 제거하는 데 사용됩니다. 일반적인 예로는 costCenter와 같은 리소스에서 태그를 업데이트하는 것입니다. 기존의 비준수 리소스는 수정 작업으로 수정할 수 있습니다. 단일 수정 규칙에는 여러 작업이 있을 수 있습니다. 효과가 수정으로 설정된 정책 할당에는 수정을 수행하기 위해 관리되는 ID가 필요합니다.
잘못된 예:
* 다음 효과는 더 이상 사용되지 않습니다. EnforceOPAConstraint EnforceRegoPolicy
* 추가는 생성 또는 업데이트 중에 요청된 리소스에 추가 필드를 추가하는 데 사용됩니다. 일반적인 예로는 저장소 리소스에 허용되는 IP를 지정하는 것입니다.
추가는 태그가 아닌 속성과 함께 사용하도록 의도되었습니다. 추가는 생성 또는 업데이트 요청 중에 리소스에 태그를 추가할 수 있지만
태그에 대해 수정 효과를 대신 사용하는 것이 좋습니다.
상자 2: 기여자 역할이 있는 관리되는 ID
관리되는 ID에는 관리되는 ID를 부여하기 위해 리소스를 수정하는 데 필요한 적절한 역할이 부여되어야 합니다.
기여자 - 모든 유형의 Azure 리소스를 만들고 관리할 수 있지만 다른 사람에게 액세스 권한을 부여할 수 없습니다.
잘못된 예:
사용자 액세스 관리자: Azure 리소스에 대한 사용자 액세스를 관리할 수 있습니다.

Actual exam question from Microsoft's AZ-305
Question #: 20
Topic #: 1

HOTSPOT -
You need to design an Azure policy that will implement the following functionality:
✑ For new resources, assign tags and values that match the tags and values of the resource group to which the resources are deployed.
✑ For existing resources, identify whether the tags and values match the tags and values of the resource group that contains the resources.
✑ For any non-compliant resources, trigger auto-generated remediation tasks to create missing tags and values.
The solution must use the principle of least privilege.
What should you include in the design? To answer, select the appropriate options in the answer area.
NOTE: Each correct selection is worth one point.
Hot Area:

Show Suggested Answer Hide Answer
Suggested Answer:
Box 1: Modify -
Modify is used to add, update, or remove properties or tags on a subscription or resource during creation or update. A common example is updating tags on resources such as costCenter. Existing non-compliant resources can be remediated with a remediation task. A single Modify rule can have any number of operations. Policy assignments with effect set as Modify require a managed identity to do remediation.
Incorrect:
* The following effects are deprecated: EnforceOPAConstraint EnforceRegoPolicy
* Append is used to add additional fields to the requested resource during creation or update. A common example is specifying allowed IPs for a storage resource.
Append is intended for use with non-tag properties. While Append can add tags to a resource during a create or update request, it's recommended to use the
Modify effect for tags instead.
Box 2: A managed identity with the Contributor role
The managed identity needs to be granted the appropriate roles required for remediating resources to grant the managed identity.
Contributor - Can create and manage all types of Azure resources but can't grant access to others.
Incorrect:
User Access Administrator: lets you manage user access to Azure resources.
