C. 지역 중복 백업 구현. Azure Database for MySQL의 지역 중복 백업(GRB) 기능을 사용하면 자동 백업을 다른 지역(geography)에 저장할 수 있습니다. 지역 전체 서비스 중단 시 지역 중복 백업에서 데이터베이스를 복원하여 가동 중지 시간을 최소화할 수 있습니다. 다른 옵션은 지역 장애 발생 시 비즈니스 연속성을 제공하지 않습니다. 옵션 A(읽기 복제본 생성)는 주로 읽기 작업이 많은 워크로드에 도움이 되며 재해 복구에는 적합하지 않습니다. 옵션 B(Azure 프리미엄 파일 공유에 데이터베이스 파일을 저장하는 옵션)는 성능을 향상시킬 수 있지만 재해 복구 솔루션을 제공하지는 않습니다. 옵션 D(네이티브 MySQL 복제 구성)는 Azure Database for MySQL에서 직접 지원되지 않습니다. 대신 지역 중복 백업과 같은 Azure의 기본 제공 비즈니스 연속성 기능을 사용해야 합니다.
