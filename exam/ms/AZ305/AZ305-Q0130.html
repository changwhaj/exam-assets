B. a general purpose v2 storage account that has hierarchical namespace enabled. Azure Blob Storage is designed to store large amounts of unstructured object data, such as text or binary data, and can store petabytes of data. General Purpose v2 accounts deliver the lowest per-gigabyte capacity prices for Azure Storage, as well as industry-competitive transaction prices. Hierarchical namespace allows the blob storage to support multiple levels of directories and subfolders. Moreover, when you enable a hierarchical namespace, the data in the account becomes accessible through Azure Data Lake Storage Gen2, which supports access control lists (ACLs) for granular permissions.
