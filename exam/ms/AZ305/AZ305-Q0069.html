선택한 답변: B
Azure SQL Database Business Critical은 모든 요구 사항을 충족하는 유일한 서비스 계층입니다. 로컬 SSD 스토리지와 데이터베이스 복제본 클러스터를 사용하여 고가용성과 성능을 제공합니다. 복제본이 동일 지역 내의 여러 가용성 영역에 분산되는 영역 중복성을 지원합니다. 또한 데이터 손실 없는 자동 장애 조치(failover)를 지원합니다. 하지만 이 서비스 계층은 다른 옵션들 중에서 가장 비용이 많이 드는 계층이기도 합니다. Azure SQL Database Serverless는 내부적으로 범용 서비스 계층을 사용하므로 데이터 손실 없는 장애 조치(failover) 요구 사항을 충족하지 못합니다. 또한 영역 중복성도 지원하지 않습니다. 사용량에 따라 컴퓨팅 리소스를 확장하고 비활성 상태일 때 데이터베이스를 일시 중지하므로 간헐적이고 예측 불가능한 워크로드에 비용 효율적인 옵션입니다.

Azure SQL Database 비즈니스 크리티컬 Azure SQL Database 비즈니스 크리티컬은 이러한 요구 사항을 충족하는 데 가장 적합한 옵션입니다. 여러 데이터베이스 복제본을 사용하는 Always On 가용성 그룹을 사용하므로 장애 조치(failover) 중 데이터 손실 없이 높은 수준의 가용성을 제공합니다. 또한 영역 중복 구성으로 배포할 수 있으므로 영역 중단 시에도 가용성을 유지합니다. 가장 저렴한 옵션은 아니지만 다른 모든 요구 사항을 충족하며 이러한 시나리오에 가장 적합한 선택입니다.
