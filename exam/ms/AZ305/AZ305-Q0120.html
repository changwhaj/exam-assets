HOTSPOT -

다음 요구 사항을 충족하는 배포 및 복원력 솔루션을 추천해야 합니다.
✑ 사용자가 시작한 백업을 지원합니다
. ✑ Azure 지역에서 여러 개의 자동 복제 인스턴스를 지원합니다.
✑ 비즈니스 연속성을 구현하고 유지하기 위한 관리 노력을 최소화합니다.
무엇을 추천해야 합니까? 대답하려면 답변 영역에서 적절한 옵션을 선택하십시오.
참고: 각 올바른 선택은 1점입니다.
핫 영역:

제안된 답변 보기 답변 숨기기
제안된 답변:
상자 1: Azure SQL 데이터베이스 -
잘못된 답변:
사용자 모방 백업은 Azure SQL 관리형 인스턴스에서 지원되지 않습니다.

상자 2: 활성 지리적 복제 -
Azure 지역에서 여러 개의 자동 복제 인스턴스에 활성 지리적 복제가 필요합니다.
지리적 복원을 위해 Azure SQL 데이터베이스 보안을 관리할 수 있습니다. SQL 데이터베이스는 지리적 복원에 사용할 수 없습니다.
잘못된 답변:
SQL Server가 아닙니다. 활성 지리적 복제에는 Azure SQL 데이터베이스가 필요합니다.

https://docs.microsoft.com/en-us/azure/azure-sql/database/active-geo-replication-overview

What should you recommend? To answer, select the appropriate options in the answer area.
