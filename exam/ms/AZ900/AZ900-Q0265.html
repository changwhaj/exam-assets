정답은 "Azure Security Center"입니다. 이름이 Microsoft Defender for Cloud로 변경되었습니다. https://learn.microsoft.com/en-us/azure/defender-for-cloud/defender-for-cloud-introduction#cspm---remediate-security-issues-and-watch-your-security-posture-improve Defender for Cloud를 처음 열면 Defender for Cloud는 다음과 같은 기능을 제공합니다. - 연결된 리소스를 Microsoft 클라우드 보안 벤치마크의 지침과 비교하여 평가한 결과를 기반으로 구독에 대한 보안 점수를 생성합니다. 이 점수를 사용하여 보안 태세를 파악하고, 규정 준수 대시보드를 통해 기본 제공 벤치마크를 기준으로 규정 준수 상태를 검토할 수 있습니다. 향상된 보안 기능을 활성화하면 규정 준수 평가에 사용되는 기준을 사용자 지정하고, NIST 및 Azure CIS와 같은 다른 규정이나 조직별 보안 요구 사항을 추가할 수 있습니다. 또한 AWS Foundational Security Best practices 표준을 기반으로 권장 사항과 점수를 적용할 수도 있습니다.
