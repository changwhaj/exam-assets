Copilot: The number of simultaneous user connections in an Azure Virtual Desktop host pool depends on the configuration and the load balancing algorithm used. Load Balancing Algorithms: Breadth-first: Distributes user sessions evenly across all session hosts. This means each session host will have a roughly equal number of user sessions1. Depth-first: Fills up one session host to its maximum capacity before moving on to the next1. Session Limits: The maximum number of sessions per host can be configured based on the VM size and the expected workload2. For example, a host might support 5 to 10 users depending on the resources allocated to it2. In theory, you can set a very high maximum session limit, but practical limits depend on the performance and resource requirements of the applications being used3. So, a host pool with 20 session hosts can support more than 20 simultaneous user connections, depending on how you configure the session limits and the load balancing strategy.
