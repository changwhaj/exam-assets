이 질문에는 분명히 두 가지 답변이 필요하며, 제 생각에는 나타나는 순서대로 답변이 나와 있습니다. 리소스 그룹과 저장소 계정. Azure의 파일 공유는 저장소 계정을 사용하여 생성되므로 첫 번째 답변은 매우 명확합니다. Azure 파일 공유는 저장소 계정에 배포되는데, 저장소 계정은 공유 저장소 풀을 나타내는 최상위 개체입니다. 이 저장소 풀은 여러 파일 공유를 배포하는 데 사용될 수 있습니다. 예를 들어 SMB 파일 공유를 생성할 때 새 저장소 계정을 만들 수 있습니다. 저장소 계정을 생성하기 위해 작성해야 하는 첫 번째 탭은 "기본"으로 표시되며, 저장소 계정을 생성하는 데 필요한 필드가 포함되어 있습니다. 필수 필드 중 하나는 "리소스 그룹"입니다. 리소스 그룹은 웹앱, 데이터베이스, 저장소 계정과 같은 Azure 리소스가 배포되고 관리되는 논리적 컨테이너입니다. 리소스는 VM, 저장소 또는 SQL 데이터베이스와 같이 사용자가 생성하는 서비스의 인스턴스입니다. https://learn.microsoft.com/en-us/azure/storage/files/storage-how-to-create-file-share?tabs=azure-portal

This question clearly requires two answers and to my mind they are in order of appearance: Resource Groups and Storage Accounts The first answer is quite abvious as File Shares in Azure are created using Storage accounts. Azure file shares are deployed into storage accounts, which are top-level objects that represent a shared pool of storage. This pool of storage can be used to deploy multiple file shares. When creating an SMB file share for example, we can create a new storage account. The first tab to complete to create a storage account is labeled Basics, which contains the required fields to create a storage account. On of the mandatory fields is called "Resource Group".A resource group is a logical container into which Azure resources like web apps, databases and storage accounts are deployed and managed. Resources are instances of services that you create like VMs, storage or SQL databases. https://learn.microsoft.com/en-us/azure/storage/files/storage-how-to-create-file-share?tabs=azure-portal
