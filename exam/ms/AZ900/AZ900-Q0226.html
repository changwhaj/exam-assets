핫스팟 -
다음 각 문장에 대해, 문장이 맞으면 '예'를 선택하고, 틀리면 '아니요'를 선택하세요.
참고: 정답은 1점입니다.
핫스팟:

제안된 답변 보기 답변 숨기기
제안된 답변:
상자 1: 예 -
Azure Security Center는 데이터 센터의 보안 태세를 강화하고 온프레미스뿐 아니라 클라우드(Azure 기반 여부와 관계없이)의 하이브리드 워크로드 전반에 걸쳐 고급 위협 보호 기능을 제공하는 통합 인프라 보안 관리 시스템입니다.

상자 2: 아니요 -
지속적인 평가 및 보안 권장 사항과 Azure 보안 점수 두 가지 기능만 무료입니다.

상자 3: 예 -
Security Center의 고급 모니터링 기능을 통해 시간 경과에 따른 규정 준수 및 거버넌스를 추적하고 관리할 수 있습니다. 전반적인 규정 준수는 구독이 워크로드와 관련된 정책을 얼마나 준수하는지를 측정하는 척도를 제공합니다.
참고:
https://docs.microsoft.com/en-us/azure/security-center/security-center-intro
