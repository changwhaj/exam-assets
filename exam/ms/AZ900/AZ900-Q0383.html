지역 중복 저장소(GRS)를 사용하는 Azure Storage 계정은 데이터 복사본 6개를 유지합니다. GRS를 사용하면 Azure는 데이터가 저장된 주 지역에서 수백 마일 떨어진 보조 지역에 데이터를 복제합니다. 보조 지역에는 Azure가 데이터 복사본 3개를 추가로 만들어 총 복사본 수가 6개가 됩니다. 이는 주 지역에 영향을 미치는 주요 재해나 중단 발생 시 데이터 보호 계층을 강화합니다. 이러한 이벤트가 발생하면 Azure는 자동으로 보조 지역으로 장애 조치(failover)하여 보조 지역의 데이터를 사용할 수 있도록 합니다.
