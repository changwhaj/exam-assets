NYY The statement 'Azure virtual networks deployed to the same Azure region are connected by default' is False. To connect Azure Virtual Networks, even within the same region, you need to explicitly configure VNet peering or a Virtual Network Gateway. VMs in different networks cannot communicate by default. All Azure resources have a name. The name must be unique within a scope, that may vary for each resource type. For example, the name of a virtual network must be unique within a resource group, but can be duplicated within a subscription or Azure region The statement: 'The Azure virtual network's address space must be unique within a subscription' is True. Azure Virtual Network (VNet) is a fundamental component of the Azure networking model and provides isolation for your applications. Each VNet you create has its own IP address space with a range that you specify.
