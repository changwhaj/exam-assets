정답은 B입니다. Azure Information Protection(AIP)은 중요한 문서와 이메일 메시지를 분류하고 보호할 수 있는 클라우드 기반 솔루션입니다. Azure Active Directory를 사용하여 사용자를 인증하고, Azure Rights Management를 사용하여 보호된 문서에 대한 액세스를 암호화하고 제어합니다. AIP에 사용되는 암호화는 Azure Rights Management(Azure RMS)를 기반으로 하며, 암호화, ID 및 권한 부여 정책을 사용하여 전송 중이거나 저장 중인 파일과 이메일을 보호합니다.

Azure Information Protection (sometimes referred to as AIP) is a cloud-based solution that helps an organization to classify and optionally, protect its documents and emails by applying labels. Labels can be applied automatically by administrators who define rules and conditions, manually by users, or a combination where users are given recommendations. Ref : https://docs.microsoft.com/en-us/azure/information-protection/what-is-information-protection

B is the answer. Azure Information Protection (AIP) is a cloud-based solution that allows you to classify and protect your sensitive documents and email messages. It uses Azure Active Directory to authenticate users, and it uses Azure Rights Management to encrypt and control access to the protected documents. The encryption used in AIP is based on Azure Rights Management (Azure RMS), which uses encryption, identity, and authorization policies to help secure files and email, both in transit and when at rest.
