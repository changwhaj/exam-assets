Resource Manager templates.
You need to recommend which Azure service will minimize the administrative effort required to deploy and remove the virtual machines.
What should you recommend?

  • A. Azure Reserved Virtual Machine (VM) Instances
  • B. Azure DevTest Labs Most Voted
  • C. Azure virtual machine scale sets
  • D. Azure Virtual Desktop

I would recommend using Azure virtual machine scale sets (Option C) to minimize the administrative effort required to deploy and remove the virtual machines.
