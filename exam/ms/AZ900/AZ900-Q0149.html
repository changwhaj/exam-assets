드래그 앤 드롭 -
클라우드 서비스 모델을 해당 제품과 연결하세요.
정답을 찾으려면 왼쪽 열에서 해당 모델을 오른쪽 제품 목록으로 드래그하세요. 각 모델은 한 번, 여러 번 또는 전혀 사용하지 않을 수 있습니다.
참고: 정답 하나당 1점입니다.
선택 및 배치:

제안된 답변 보기 답변 숨기기
제안된 답변:
박스 1: 서비스형 플랫폼(PaaS)
Azure App Service는 웹 애플리케이션 구축을 위한 완전 관리형 플랫폼입니다.
서비스형 플랫폼(PaaS)은 클라우드 기반의 완벽한 개발 및 배포 환경으로, 간단한 클라우드 기반 앱부터 정교한 클라우드 기반 엔터프라이즈 애플리케이션까지 모든 것을 제공할 수 있는 리소스를 제공합니다.
박스 2: 서비스형 인프라(IaaS)
Windows Azure Virtual Machines는 Windows Azure의 서비스형 인프라(IaaS) 제품으로, 2012년에 출시되었습니다.
박스 3: 서비스형 소프트웨어(SaaS)
Dynamics 365는 핵심 고객, 직원 및 비즈니스 활동을 혁신하고 활성화하도록 설계된 상호 연결된 모듈식 SaaS(서비스형 소프트웨어) 애플리케이션 및 서비스 세트입니다.
참고:
https://azure.microsoft.com/en-us/overview/what-is-paas/
https://azure.microsoft.com/en-us/blog/infrastructure-as-a-service-series-virtual-machines-and-windows/ https://pipol.com/what-is-microsoft-dynamics-365

Question #: 149
Topic #: 1

DRAG DROP -
Match the cloud service models to the appropriate offerings.
To answer, drag the appropriate model from the column on the left to its offering on the right. Each model may be used once, more than once, or not at all.
NOTE: Each correct match is worth one point.
Select and Place:

Show Suggested Answer Hide Answer
Suggested Answer:
Box 1: Platform as a service (PaaS)
Azure App Service is a fully managed platform for building web applications.
Platform as a service (PaaS) is a complete development and deployment environment in the cloud, with resources that enable you to deliver everything from simple cloud-based apps to sophisticated, cloud-enabled enterprise applications.
Box 2: Infrastructure as a service (IaaS)
Windows Azure Virtual Machines, an Infrastructure-as-a-Service (IaaS) offering in Windows Azure, was released back in 2012.
Box 3: Software as a service (SaaS)
Dynamics 365 is a set of interconnected, modular Software-as-a-Service (SaaS) applications and services designed to both transform and enable your core customers, employees, and business activities.
