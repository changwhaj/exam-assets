선택한 답변: B
정답은 B입니다. 네, 맞습니다. Azure Cost Management는 모든 Azure 구독, 리소스 그룹 및 관리 그룹에 걸쳐 조직의 Azure 지출 및 사용량에 대한 통합된 보기를 제공합니다. Azure Cost Management를 사용하면 가상 머신의 사용량 데이터를 보고 관리할 수 있습니다. Azure Cost Management에서 지난 3개월 동안의 가상 머신 사용량을 보려면 다음 단계를 따르세요. 1. Azure Portal에 로그인하고 Azure Cost Management 및 청구 페이지로 이동합니다. 2. 페이지 상단의 드롭다운 메뉴에서 원하는 범위(예: 구독 또는 리소스 그룹)를 선택합니다. 3. "비용 분석" 탭을 클릭하여 선택한 범위의 비용 및 사용량 데이터를 확인합니다. 4. 페이지 상단의 필터를 사용하여 원하는 날짜 범위(예: 지난 3개월)를 선택합니다. 5. "그룹화 기준" 드롭다운 메뉴에서 "사용량" 옵션을 선택합니다. 6. 필터 및 그룹화 옵션을 사용하여 가상 머신의 사용량 데이터를 더욱 구체화합니다.

Selected Answer: A
You can use Azure Advisor to identify underutilized or unused Azure virtual machines. Azure Advisor provides recommendations to optimize your Azure resources, including identifying underutilized or unused virtual machines. It analyzes usage patterns and provides recommendations to right-size or decommission virtual machines that are not being used or are underutilized. Azure Cost Management + Billing can also help identify underutilized virtual machines by providing cost analysis and usage reports. However, Azure Advisor is specifically designed to provide optimization recommendations for Azure resources. Azure reservations and Azure Policy are not directly related to identifying underutilized or unused virtual machines.
