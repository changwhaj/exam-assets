답은 '아니요'입니다. Active Directory를 Azure AD에 어떻게 연결할 수 있나요? Active Directory를 Azure AD에 연결하면 사용자에게 일관된 ID 환경을 제공할 수 있습니다. 기존 Active Directory 설치를 Azure AD에 연결하는 방법은 여러 가지가 있습니다. 가장 널리 사용되는 방법은 Azure AD Connect를 사용하는 것입니다. Azure AD Connect는 온프레미스 Active Directory와 Azure AD 간의 사용자 ID를 동기화합니다. Azure AD Connect는 두 ID 시스템 간의 변경 사항을 동기화하므로 SSO, 다단계 인증, 셀프 서비스 암호 재설정과 같은 기능을 두 시스템 모두에서 사용할 수 있습니다. 셀프 서비스 암호 재설정은 사용자가 알려진 손상된 암호를 사용하는 것을 방지합니다.
