Choices A & D are correct. A. Multiple subscriptions: Each department can have its own Azure subscription. This allows for isolated billing and resource management, giving each department control over their own resources and costs. D. Multiple resource groups: Within a single subscription, you can create multiple resource groups, each dedicated to a different department. Resource groups allow you to manage and organize resources based on lifecycle and administrative boundaries, making it easier for department administrators to manage resources specific to their department.
