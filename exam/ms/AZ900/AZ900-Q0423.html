A- 오답: 알림은 Azure Monitor 데이터에서 인프라 또는 애플리케이션에 문제가 있을 수 있음을 나타낼 때 사전에 알림을 제공하여 사용자가 문제를 알아차리기 전에 문제를 감지하고 해결하는 데 도움이 됩니다.B- 정답: Azure Monitor의 기능인 Azure Monitor Application Insights는 라이브 웹 애플리케이션의 APM(애플리케이션 성능 모니터링)에 탁월합니다.C- 오답: Log Analytics는 Azure Monitor 로그에서 수집된 데이터에서 로그 쿼리를 편집하고 실행하며 그 결과를 대화형으로 분석하는 Azure Portal의 도구입니다.D- 오답: Network Watcher를 사용하면 가상 머신(VM), 가상 네트워크(VNet), 애플리케이션 게이트웨이, 부하 분산 장치 등과 같은 IaaS 제품의 네트워크 상태를 모니터링하고 복구할 수 있습니다.Network Watcher는 PaaS 모니터링 또는 웹 분석용으로 설계 또는 의도된 것이 아닙니다.
