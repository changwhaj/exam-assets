주제 번호: 1

핫스팟 -
Azure Cloud Shell을 사용하여 Azure를 관리해야 합니다.
어떤 Azure Portal 아이콘을 선택해야 할까요? 답변하려면 답변 영역에서 해당 아이콘을 선택하세요.
핫스팟:

제안된 답변 보기 답변 숨기기
제안된 답변:
Azure Portal에서 아이콘을 클릭하여 Azure Cloud Shell에 액세스할 수 있습니다.
Azure Cloud Shell은 Azure 리소스를 관리하기 위한 대화형 인증 셸로, 브라우저에서 액세스 가능합니다. Bash 또는 PowerShell 중 작업 방식에 가장 적합한 셸 환경을 선택할 수 있는 유연성을 제공합니다.
Cloud Shell을 사용하면 Azure 관리 작업을 고려하여 구축된 브라우저 기반 명령줄 환경에 액세스할 수 있습니다.
참고:
https://docs.microsoft.com/en-us/azure/cloud-shell/overview?view=azure-cli-latest
Actual exam question from Microsoft's AZ-900
Question #: 215
Topic #: 1

HOTSPOT -
You need to manage Azure by using Azure Cloud Shell.
Which Azure portal icon should you select? To answer, select the appropriate icon in the answer area.
Hot Area:

Show Suggested Answer Hide Answer
Suggested Answer:
You can access Azure Cloud Shell in the Azure portal by clicking the icon.
Azure Cloud Shell is an interactive, authenticated, browser-accessible shell for managing Azure resources. It provides the flexibility of choosing the shell experience that best suits the way you work, either Bash or PowerShell.
Cloud Shell enables access to a browser-based command-line experience built with Azure management tasks in mind.
References:
https://docs.microsoft.com/en-us/azure/cloud-shell/overview?view=azure-cli-latest
