Microsoft AZ-900 의 실제 시험 문제
질문 번호: 170
주제 번호: 1

드래그 앤 드롭 -
Azure 서비스를 올바른 설명에 연결하세요.
지침: 정답을 입력하려면 왼쪽 열에서 해당 Azure 서비스를 오른쪽 설명으로 드래그 앤 드롭하세요. 각 서비스는 한 번, 여러 번 또는 전혀 사용하지 않을 수 있습니다.
참고: 올바른 설명 하나당 1점이 부여됩니다.
선택 및 배치:

제안된 답변 보기 답변 숨기기
제안된 답변:
상자 1: Azure SQL Database -
SQL Server는 관계형 데이터베이스 서비스입니다.Azure SQL Database는 Azure에서 관리되는 SQL Server 데이터베이스입니다.SQL Server는 Microsoft에서 관리하며, 데이터베이스에 액세스할 수만 있습니다.
상자 2: Azure SQL Synapse Analytics
Azure SQL Synapse Analytics(이전에는 Data Warehouse라고 함)는 Microsoft에서 제공하는 클라우드 기반 Platform-as-a-Service(PaaS)입니다.Amazon Redshift 또는 Snowflake와 같은 수준의 경쟁 제품에 속하는 대규모 분산형 MPP(대규모 병렬 처리) 관계형 데이터베이스 기술입니다.Azure SQL
Synapse Analytics는 Modern Data Warehouse 다중 플랫폼 아키텍처의 중요한 구성 요소입니다.Azure SQL Synapse Analytics는 배포 간에 공유되지 않는 아키텍처를 갖춘 MPP 시스템이기 때문에 병렬 처리를 활용할 수 있는 대규모 분석 워크로드에 적합합니다.
상자 3: Azure Data Lake Analytics
Azure Data Lake Analytics를 사용하면 몇 초 만에 빅데이터 작업을 처리할 수 있습니다. .NET 언어, R 또는 Python
으로 작성된 기존 라이브러리를 활용하여 쿼리, ETL, 분석, 머신 러닝, 기계 번역, 이미지 처리 및 감정 분석과 같은 다양한 워크로드 범주에 대해 페타바이트 규모의 데이터를 처리할 수 있습니다 . 상자 4: Azure HDInsight. Apache Hadoop은 클러스터에서 빅데이터 세트의 분산 처리 및 분석을 위한 최초의 오픈 소스 프레임워크였습니다. Hadoop 생태계에는 Apache Hive, Apache HBase, Spark, Kafka 등 관련 소프트웨어와 유틸리티가 포함됩니다. Azure HDInsight는 기업을 위한 클라우드 기반의 완전 관리형 풀 스펙트럼 오픈 소스 분석 서비스입니다. Azure HDInsight의 Apache Hadoop 클러스터 유형을 사용하면 HDFS, YARN 리소스 관리 및 간단한 MapReduce 프로그래밍 모델을 사용하여 배치 데이터를 병렬로 처리하고 분석할 수 있습니다. 참고: https://azure.microsoft.com/en-us/services/sql-database/ https://docs.microsoft.com/en-us/azure/sql-data-warehouse/sql-data-warehouse-overview-what-is https://docs.microsoft.com/bs-latn-ba/azure/hdinsight/hadoop/apache-hadoop-introduction https://www.blue-granite.com/blog/is-azure-sql-data-warehouse-a-good-fit-updated https://azure.microsoft.com/en-gb/services/data-lake-analytics/






Actual exam question from Microsoft's AZ-900
Question #: 170
Topic #: 1

DRAG DROP -
Match the Azure service to the correct description.
Instructions: To answer, drag the appropriate Azure service from the column on the left to its description on the right. Each service may be used once, more than once, or not at all.
NOTE: Each correct match is worth one point.
Select and Place:

Show Suggested Answer Hide Answer
Suggested Answer:
Box 1: Azure SQL Database -
SQL Server is a relational database service. Azure SQL Database is a managed SQL Server Database in Azure. The SQL Server is managed by Microsoft; you just have access to the database.
Box 2: Azure SQL Synapse Analytics
Azure SQL Synapse Analytics (previously called Data Warehouse) is a cloud-based Platform-as-a-Service (PaaS) offering from Microsoft. It is a large-scale, distributed, MPP (massively parallel processing) relational database technology in the same class of competitors as Amazon Redshift or Snowflake. Azure SQL
Synapse Analytics is an important component of the Modern Data Warehouse multi-platform architecture. Because Azure SQL Synapse Analytics is an MPP system with a shared-nothing architecture across distributions, it is meant for large-scale analytical workloads which can take advantage of parallelism.
Box 3: Azure Data Lake Analytics
You can process big data jobs in seconds with Azure Data Lake Analytics. You can process petabytes of data for diverse workload categories such as querying,
ETL, analytics, machine learning, machine translation, image processing and sentiment analysis by leveraging existing libraries written in .NET languages, R or
Python.
Box 4: Azure HDInsight.
Apache Hadoop was the original open-source framework for distributed processing and analysis of big data sets on clusters. The Hadoop ecosystem includes related software and utilities, including Apache Hive, Apache HBase, Spark, Kafka, and many others.
Azure HDInsight is a fully managed, full-spectrum, open-source analytics service in the cloud for enterprises. The Apache Hadoop cluster type in Azure HDInsight allows you to use HDFS, YARN resource management, and a simple MapReduce programming model to process and analyze batch data in parallel.
