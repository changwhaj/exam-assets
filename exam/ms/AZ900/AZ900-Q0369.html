이 질문은 밑줄 친 텍스트를 평가하여 정답인지 확인해야 합니다.
support.microsoft.com에서 Azure 지원 요청을 생성할 수 있습니다.
지침: 밑줄 친 텍스트를 검토하세요. 내용이 맞다면 '변경 필요 없음'을 선택하세요. 내용이 틀렸다면 내용이 맞는 답을 선택하세요.

  • A. 변경이 필요하지 않습니다.
  • B. Azure 포털 가장 많이 투표된
  • C. 지식 센터
  • D. 보안 및 규정 준수 관리 센터
제안된 답변 보기 답변 숨기기
제안된 답변: B
Azure Portal의 도움말 및 지원 블레이드 또는 지원 +
문제 해결 섹션에 있는 Azure 리소스의 상황에 맞는 메뉴에서 Azure 지원 요청을 만들 수 있습니다.
참고:
https://docs.microsoft.com/en-us/azure/azure-supportability/how-to-create-azure-support-request

Question #: 369
Topic #: 1

This question requires that you evaluate the underlined text to determine if it is correct.
You can create an Azure support request from support.microsoft.com.
Instructions: Review the underlined text. If it makes the statement correct, select `No change is needed.` If the statement is incorrect, select the answer choice that makes the statement correct.

  • A. No change is needed.
  • B. the Azure portal Most Voted
  • C. the Knowledge Center
  • D. the Security & Compliance admin center
Show Suggested Answer Hide Answer
Suggested Answer: B
You can create an Azure support request from the Help and Support blade in the Azure portal or from the context menu of an Azure resource in the Support +
Troubleshooting section.
Reference:
https://docs.microsoft.com/en-us/azure/azure-supportability/how-to-create-azure-support-request
