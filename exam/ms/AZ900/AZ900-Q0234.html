드래그 앤 드롭 -
Azure 서비스 혜택을 올바른 설명과 연결하세요.
지침: 정답을 입력하려면 왼쪽 열에서 해당 혜택을 오른쪽 설명으로 드래그하세요. 각 혜택은 한 번, 여러 번 또는 전혀 사용하지 않을 수 있습니다.
참고: 올바른 설명 하나당 1점이 부여됩니다.
선택 및 배치:

제안된 답변 보기 답변 숨기기
제안된 답변:
상자 1: Microsoft Sentinel -
Microsoft Sentinel은 확장 가능한 클라우드 네이티브 보안 정보 및 이벤트 관리(SIEM) 및 보안 오케스트레이션, 자동화 및 대응(SOAR) 솔루션입니다. Microsoft Sentinel은 기업 전반에 걸쳐 지능형 보안 분석 및 위협 인텔리전스를 제공하여 공격 탐지, 위협 가시성, 선제적 사냥 및 위협 대응을 위한 단일 솔루션을 제공합니다.
상자 2: Microsoft Defender for Cloud
Azure Portal을 통해 전체 보안 점수와 구독별 점수를 확인할 수 있습니다. Defender for Cloud는 포털에 보안 점수를 눈에 띄게 표시합니다.

상자 3: Azure Key Vault -
Azure Key Vault에 자격 증명 또는 키를 비밀로 저장하고 Azure Functions 앱에서 해당 비밀을 환경 변수로 참조하는 데 선호되는 방식입니다.

A secret is anything that you want to tightly control access to, such as API keys, passwords, certificates, or cryptographic keys. Key Vault service supports two types of containers: vaults and managed hardware security module(HSM) pools. Vaults support storing software and HSM-backed keys, secrets, and certificates.
