outdated answer new service offering synchronization is "Azure File Sync" The correct service is Azure File Sync, not Azure Files. Azure File Sync is specifically designed to enable synchronization between on-premises file servers and Azure Files, allowing you to centralize file storage in Azure while keeping local access to frequently used data. Azure Files, on the other hand, provides fully managed cloud file shares, but it doesn't include synchronization capabilities by itself. Reference : https://learn.microsoft.com/en-us/azure/storage/
