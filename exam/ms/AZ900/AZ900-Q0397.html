Premium Block Blob storage accounts only support Locally Redundant Storage (LRS). Unlike standard storage accounts, premium block blob storage does not support Geo-Redundant Storage (GRS), Zone-Redundant Storage (ZRS), or Read-Access Geo-Redundant Storage (RA-GRS). Since LRS keeps multiple copies of data within a single Azure region, it's ideal for workloads that require low-latency access and high-performance storage, but it doesn't provide geographic resilience.
