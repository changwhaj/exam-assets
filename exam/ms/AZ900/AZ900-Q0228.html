Azure Disk Encryption uses Azure Key Vault to manage the disk encryption keys and secrets. You must create an Azure Key Vault before you can encrypt an Azure virtual machine using Azure Disk Encryption. The Key Vault is used to store the encryption keys and secrets, and it provides a central location for managing and securing these keys. Once you have created the Key Vault, you can then enable disk encryption on the virtual machine and specify the Key Vault as the location for the encryption keys.
