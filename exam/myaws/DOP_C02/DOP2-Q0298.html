Amazon의 AWS Certified DevOps Engineer - Professional DOP-C02 의 시험 문제
질문 #: 298
주제 #: 1

한 회사에 Amazon Elastic Kubernetes Service(Amazon EKS) 클러스터에 호스팅된 웹 애플리케이션이 있습니다. EKS 클러스터는 인터넷 연결 애플리케이션 로드 밸런서를 통해 제공되는 AWS Fargate에서 실행됩니다.

애플리케이션에서 안정성 문제가 발생하여 응답 시간이 길어졌습니다. DevOps 엔지니어는 Amazon CloudWatch에서 관찰 가능성을 구성하여 문제를 해결해야 합니다. 솔루션은 최소한 필요한 권한만 제공해야 합니다.

이러한 요구 사항을 충족하는 단계 조합은 무엇입니까? (세 가지를 선택하십시오.)

  • A. CloudWatch 에이전트를 Kubernetes StatefulSet으로 EKS 클러스터에 배포합니다. 가장 많이 투표된
  • B. Kubernetes DaemonSet으로 AWS Distro for OpenTelemetry Collector를 EKS 클러스터에 배포합니다.
  • C. Amazon EKS의 서비스 계정에 대한 IAM 역할을 사용하여 Kubernetes 서비스 계정을 IAM 역할과 연결합니다. CloudWatchAgentServerPolicy AWS 관리 정책을 사용합니다. 가장 많이 투표된
  • D. Amazon EKS의 서비스 계정에 대한 IAM 역할을 사용하여 Kubernetes 서비스 계정을 IAM 역할과 연결합니다. CloudWatchAgentAdminPolicy AWS 관리 정책을 사용합니다.
  • E. EKS 클러스터에 대한 IAM OpenID Connect(OIDC) 공급자를 구성합니다.
  • F. EKS 클러스터에 대해 EKS 제어 평면 로깅을 활성화합니다. 가장 많이 투표된
제안된 답변 보기 답변 숨기기
제안된 답변: ACF (OK)
A: CloudWatch 에이전트를 Kubernetes StatefulSet으로 EKS 클러스터에 배포하여 CloudWatch 메트릭 및 로그 수집을 할 수 있습니다. 이를 통해 EKS 환경의 관찰성을 설정할 수 있습니다.
C: EKS의 서비스 계정에 IAM 역할을 연결하고 CloudWatchAgentServerPolicy를 사용하여 필요한 최소 권한만 제공하여 CloudWatch 에이전트를 통해 로그 및 메트릭을 수집할 수 있습니다.
F: EKS 제어 평면 로깅을 활성화하여 EKS 클러스터의 제어 평면 로그를 CloudWatch에 기록하고, 애플리케이션 수준의 문제를 추적할 수 있도록 합니다.

이 세 가지 옵션은 EKS 클러스터에서의 관찰성을 활성화하고 문제 해결을 위한 필요한 최소 권한을 제공하는 방법입니다.

B, C, E도 좋은 선택입니다. 각 옵션을 설명드리겠습니다:
B: CloudWatch Logs를 활성화하여 CloudWatch Logs Insights에서 EKS 클러스터의 실시간 로그 검색을 가능하게 합니다. 이를 통해 로그 데이터를 분석하고, EKS 클러스터의 활동에 대한 즉각적인 통찰을 제공할 수 있습니다.
C: IAM 역할을 Kubernetes 서비스 계정에 연결하여, CloudWatch 에이전트가 EKS에서 메트릭과 로그를 수집하도록 허용합니다. 이 방식은 필요 최소 권한을 제공하면서 Kubernetes와 AWS 리소스 간의 보안 통합을 강화합니다.
E: EKS 제어 평면 로깅을 활성화하여 CloudWatch에 EKS 상태와 이벤트 로그를 기록합니다. 이는 EKS 클러스터의 전반적인 상태를 모니터링하고, 운영 효율성을 높이는 데 유용합니다.

B, C, E는 CloudWatch와의 통합을 통해 EKS 클러스터의 상태와 성능을 효율적으로 모니터링하고, 실시간 로그 분석 및 이벤트 추적을 제공하는 방법으로 효과적입니다.

A company has a web application that is hosted on an Amazon Elastic Kubernetes Service (Amazon EKS) cluster. The EKS cluster runs on AWS Fargate that is available through an internet-facing Application Load Balancer.

The application is experiencing stability issues that lead to longer response times. A DevOps engineer needs to configure observability in Amazon CloudWatch to troubleshoot the issue. The solution must provide only the minimum necessary permissions.

Which combination of steps will meet these requirements? (Choose three.)

  • A. Deploy the CloudWatch agent as a Kubernetes StatefulSet to the EKS cluster. Most Voted
  • B. Deploy the AWS Distro for OpenTelemetry Collector as a Kubernetes DaemonSet to the EKS cluster.
  • C. Associate a Kubernetes service account with an IAM role by using IAM roles for service accounts in Amazon EKS. Use the CloudWatchAgentServerPolicy AWS managed policy. Most Voted
  • D. Associate a Kubernetes service account with an IAM role by using IAM roles for service accounts in Amazon EKS. Use the CloudWatchAgentAdminPolicy AWS managed policy.
  • E. Configure an IAM OpenID Connect (OIDC) provider for the EKS cluster.
  • F. Enable EKS control plane logging for the EKS cluster. Most Voted
