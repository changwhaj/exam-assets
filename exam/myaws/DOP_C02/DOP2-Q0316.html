주제 #: 1

한 회사에 Amazon CloudWatch Logs 로그 그룹에 액세스 로그를 업로드하는 애플리케이션이 있습니다. 로그 줄의 필드에는 응답 코드와 애플리케이션 이름이 포함됩니다.

이 회사는 특정 범위와 특정 애플리케이션 이름을 가진 응답 코드별 요청 수를 추적하는 CloudWatch 메트릭을 만들고자 합니다.

어떤 솔루션이 이러한 요구 사항을 충족할까요?

  • A. CloudWatch Logs 로그 스트림에서 응답 코드 범위와 일치하도록 CloudWatch Logs 로그 이벤트 필터를 만듭니다. 메트릭을 증가시키도록 로그 이벤트 필터를 구성합니다. 응답 코드와 애플리케이션 이름을 차원으로 설정합니다.
  • B. CloudWatch Logs 로그 그룹에서 응답 코드 범위와 일치하도록 CloudWatch Logs 메트릭 필터를 만듭니다. 메트릭을 증가시키도록 메트릭 필터를 구성합니다. 응답 코드와 애플리케이션 이름을 차원으로 설정합니다. 가장 많이 투표된
  • C. 응답 코드 범위와 일치하는 필터가 있는 CloudWatch Logs 로그 스트림에서 CloudWatch Contributor Insights 규칙을 만듭니다. 응답 코드와 애플리케이션 이름을 차원으로 사용하여 CloudWatch 메트릭을 증가시키도록 Contributor Insights 규칙을 구성합니다.
  • D. 응답 코드 범위와 일치하도록 CloudWatch Logs 로그 그룹에 CloudWatch Logs Insights 쿼리를 만듭니다. 응답 코드와 애플리케이션 이름을 차원으로 사용하여 CloudWatch 메트릭을 증가시키도록 Logs Insights 쿼리를 구성합니다.
제안된 답변 보기 답변 숨기기
제안된 답변: B (OK)
B는 CloudWatch Logs 메트릭 필터를 사용하여 응답 코드 범위와 애플리케이션 이름을 기반으로 메트릭을 생성하는 방법입니다. 이를 통해 로그 그룹에서 특정 조건에 맞는 로그를 필터링하고, 해당 조건을 만족하는 로그 이벤트에 대해 메트릭을 증가시킬 수 있습니다. 응답 코드와 애플리케이션 이름을 차원으로 설정하여 CloudWatch 메트릭을 정확하게 추적할 수 있습니다.

다른 옵션들은 메트릭 필터와 같은 기능을 제공하지만, B가 요구된 조건에 가장 적합한 솔루션입니다.

The company wants to create a CloudWatch metric to track the number of requests by response code in a specific range and with a specific application name.

Which solution will meet these requirements?

  • A. Create a CloudWatch Logs log event filter on the CloudWatch Logs log stream to match the response code range. Configure the log event filter to increment a metric. Set the response code and application name as dimensions.
  • B. Create a CloudWatch Logs metric filter on the CloudWatch Logs log group to match the response code range. Configure the metric filter to increment a metric. Set the response code and application name as dimensions. Most Voted
  • C. Create a CloudWatch Contributor Insights rule on the CloudWatch Logs log stream with a filter to match the response code range. Configure the Contributor Insights rule to increment a CloudWatch metric with the response code and application name as dimensions.
  • D. Create a CloudWatch Logs Insights query on the CloudWatch Logs log group to match the response code range. Configure the Logs Insights query to increment a CloudWatch metric with the response code and application name as dimensions.
