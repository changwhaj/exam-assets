Selected Answer: B
The scenario includes: • Input features: age, cholesterol, blood pressure, smoking status, exercise habits • A target label: whether the patient has heart disease (yes/no) When a dataset contains both features and a labeled outcome, the appropriate ML technique is supervised learning. This is a classification problem because the model predicts a categorical label (heart disease vs. no heart disease).
