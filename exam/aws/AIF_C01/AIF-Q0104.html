Amazon Bedrock은 AWS Key Management Service(AWS KMS)를 사용하여 모델 아티팩트 암호화를 지원합니다. AWS KMS를 사용하면 회사에서 관리하는 암호화 키(고객 관리 키 또는 CMK)를 사용하여 모델 사용자 지정 작업 중에 생성된 모델 아티팩트를 암호화할 수 있습니다.

B. Amazon Inspector: Inspector는 AWS 리소스의 보안 취약점을 검사하는 취약점 관리 서비스입니다. C. Amazon Macie: Macie는 머신 러닝을 사용하여 AWS에서 민감한 데이터를 검색하고 보호하는 데이터 보안 및 개인 정보 보호 서비스입니다. D. AWS Secrets Manager: Secrets Manager는 암호, API 키, 데이터베이스 자격 증명과 같은 비밀 정보를 관리하는 데 도움이 됩니다. 암호화된 비밀 정보를 저장할 수 있지만, 저장된 모델 아티팩트를 보호하는 데 사용되는 암호화 키를 관리하는 주요 서비스는 아닙니다.
