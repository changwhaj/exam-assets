주제 #: 1

한 회사가 Amazon EC2의 Amazon Elastic Container Service(Amazon ECS) 클러스터에서 내부 애플리케이션을 실행하고 있습니다. ECS 클러스터 인스턴스는 퍼블릭 인터넷에 연결할 수 있습니다. 클러스터 인스턴스에서 실행되는 ECS 작업은 프라이빗 Amazon Elastic Container Registry(Amazon ECR) 리포지토리와 퍼블릭 ECR 레지스트리 리포지토리의 이미지를 모두 사용하도록 구성되어 있습니다.

새로운 보안 정책에 따라 회사는 ECS 클러스터의 인터넷 직접 액세스를 제거해야 합니다. 회사는 클러스터를 호스팅하는 VPC에서 모든 NAT 게이트웨이와 인터넷 게이트웨이를 제거해야 합니다. DevOps 엔지니어는 ECS 클러스터가 퍼블릭 ECR 레지스트리와 프라이빗 ECR 리포지토리에서 이미지를 계속 다운로드할 수 있는지 확인해야 합니다. 퍼블릭 ECR 레지스트리의 이미지는 최신 상태로 유지되어야 합니다. 새 버전의 이미지는 게시 후 24시간 이내에 ECS 클러스터에서 사용할 수 있어야 합니다.

운영 오버헤드를 최소화하면서 이러한 요구 사항을 충족하는 단계 조합은 무엇입니까? (세 가지를 선택하세요.)

  • A. 퍼블릭 ECR 레지스트리에서 다운로드한 각 이미지에 대해 AWS CodeBuild 프로젝트와 새 프라이빗 ECR 리포지토리를 만듭니다. 각 프로젝트를 구성하여 퍼블릭 ECR 리포지토리에서 이미지를 끌어와 새 프라이빗 ECR 리포지토리에 푸시합니다. 24시간마다 CodeBuild 프로젝트를 호출하는 Amazon EventBridge 규칙을 만듭니다. ECS 클러스터의 각 작업 정의를 업데이트하여 새 프라이빗 ECR 리포지토리를 참조합니다.
  • B. 퍼블릭 ECR 레지스트리에서 다운로드한 각 이미지에 대해 새로운 Amazon ECR 풀스루 캐시 규칙을 만듭니다. 각 풀스루 캐시 규칙을 호출하는 AWS Lambda 함수를 만듭니다. 24시간마다 Lambda 함수를 호출하는 Amazon EventBridge 규칙을 만듭니다. 풀스루 캐시의 이미지를 참조하도록 ECS 클러스터의 각 작업 정의를 업데이트합니다.
  • C. 퍼블릭 ECR 레지스트리에 대한 새로운 Amazon ECR 풀스루 캐시 규칙을 만듭니다. 풀스루 캐시의 이미지를 참조하도록 ECS 클러스터의 각 작업 정의를 업데이트합니다. VPC에서 인터넷 액세스를 제거하기 전에 각 퍼블릭 이미지가 풀스루 캐시를 통해 최소한 한 번 다운로드되었는지 확인합니다. 가장 많이 투표된
  • D. VPC에 있는 공개 ECR 저장소에 대한 Amazon ECR 인터페이스 VPC 엔드포인트를 생성합니다.
  • E. VPC에 있는 개인 ECR 저장소에 대한 Amazon ECR 인터페이스 VPC 엔드포인트를 생성합니다. 가장 많이 투표된
  • F. VPC에 Amazon S3 게이트웨이 엔드포인트를 생성합니다. 가장 많이 투표된

Exam question from Amazon's AWS Certified DevOps Engineer - Professional DOP-C02
Question #: 322
Topic #: 1

A company is running an internal application in an Amazon Elastic Container Service (Amazon ECS) cluster on Amazon EC2. The ECS cluster instances can connect to the public internet. The ECS tasks that run on the cluster instances are configured to use images from both private Amazon Elastic Container Registry (Amazon ECR) repositories and a public ECR registry repository.

A new security policy requires the company to remove the ECS cluster's direct access to the internet. The company must remove any NAT gateways and internet gateways from the VPC that hosts the cluster. A DevOps engineer needs to ensure the ECS cluster can still download images from both the public ECR registry and the private ECR repositories. Images from the public ECR registry must remain up-to-date. New versions of the images must be available to the ECS cluster within 24 hours of publication.

Which combination of steps will meet these requirements with the LEAST operational overhead? (Choose three.)

  • A. Create an AWS CodeBuild project and a new private ECR repository for each image that is downloaded from the public ECR registry. Configure each project to pull the image from the public ECR repository and push the image to the new private ECR repository. Create an Amazon EventBridge rule that invokes the CodeBuild project once every 24 hours. Update each task definition in the ECS cluster to refer to the new private ECR repository.
  • B. Create a new Amazon ECR pull through cache rule for each image that is downloaded from the public ECR registry. Create an AWS Lambda function that invokes each pull through cache rule. Create an Amazon EventBridge rule that invokes the Lambda function once every 24 hours. Update each task definition in the ECS cluster to refer to the image from the pull through cache.
  • C. Create a new Amazon ECR pull through cache rule for the public ECR registry. Update each task definition in the ECS cluster to refer to the image from the pull through cache. Ensure each public image has been downloaded through the pull through cache at least once before removing internet access from the VPC. Most Voted
  • D. Create an Amazon ECR interface VPC endpoint for the public ECR repositories that are in the VPC.
  • E. Create an Amazon ECR interface VPC endpoint for the private ECR repositories that are in the VPC. Most Voted
  • F. Create an Amazon S3 gateway endpoint in the VPC. Most Voted

C. ECR Pull Through Cache for Public Images This allows public ECR images to be cached in your private ECR. You avoid internet access by referencing the cached copy. Once an image is pulled through the cache, it's stored in private ECR and available for future use even without internet access. Ensures that new versions can still be fetched (within 24h of publication), assuming it's referenced and updated in the cache. Least operational overhead: No need for custom pipelines or daily sync jobs. E. Interface VPC Endpoint for Private ECR Needed to let ECS pull private images without internet or NAT gateway. Interface VPC endpoints connect your VPC to ECR APIs via AWS PrivateLink. F. S3 Gateway Endpoint ECR stores image layers in Amazon S3. When ECS pulls an image, it downloads layers from S3 — so the cluster needs S3 access even if ECR is private. A gateway endpoint provides private S3 access from the VPC.
