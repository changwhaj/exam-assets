소프트웨어 개발팀에서 웹 애플리케이션의 CI/CD 파이프라인을 구현하고 있습니다. 이 팀은 AWS CodeBuild를 사용하여 Java 기반 소스 코드를 컴파일하고 단위 테스트를 실행합니다.

CodeBuild 프로젝트에서 생성된 아티팩트를 저장해야 합니다.

이 요구 사항을 충족하는 솔루션은 무엇입니까?

  • A. Amazon S3 버킷을 생성합니다. S3 버킷을 프로젝트의 아티팩트 출력 위치로 구성합니다. 아티팩트 위치를 프로젝트의 buildspec 파일에 추가합니다. CodeBuild 프로젝트의 리소스 액세스 역할이 S3 버킷에 액세스할 수 있도록 허용하는 S3 버킷 정책을 구성합니다.
  • B. Amazon S3 버킷을 생성합니다. 프로젝트의 buildspec 파일에 S3 버킷을 아티팩트 출력 위치로 설정합니다. 아티팩트 위치를 프로젝트의 buildspec 파일에 추가합니다.
    CodeBuild 서비스 역할이 S3 버킷에 액세스할 수 있도록 허용하는 S3 버킷 정책을 구성합니다.
  • C. Amazon Elastic File System(Amazon EFS) 파일 시스템을 프로젝트의 파일 시스템 위치로 구성합니다. 프로젝트의 buildspec 파일에서 EFS 파일 시스템을 아티팩트 출력 위치로 구성합니다. CodeBuild가 해당 파일 시스템에 액세스할 수 있도록 허용하는 파일 시스템 정책을 구성합니다. 가장 많이 투표된
  • D. Amazon Elastic Block Store(Amazon EBS) 볼륨을 생성합니다. 프로젝트의 buildspec 파일에서 EBS 볼륨을 아티팩트 출력 위치로 설정합니다. CodeBuild가 해당 볼륨에 액세스할 수 있도록 허용하는 IAM 역할을 구성합니다.

A software development team is implementing a CI/CD pipeline for its web application. The team is using AWS CodeBuild to compile Java-based source code and to run unit tests.

The team needs to store the artifacts that are created by the CodeBuild project.

Which solution will meet this requirement?

  • A. Create an Amazon S3 bucket. Configure the S3 bucket as an artifact output location in the project. Add the artifact locations to the project's buildspec file. Configure an S3 bucket policy that allows the CodeBuild project's resource access role to access the S3 bucket.
  • B. Create an Amazon S3 bucket. Configure the S3 bucket as an artifact output location in the project's buildspec file. Add the artifact locations to the project's buildspec file.
    Configure an S3 bucket policy that allows the CodeBuild service role to access the S3 bucket.
  • C. Configure an Amazon Elastic File System (Amazon EFS) file system as a file system location for the project. Configure the EFS file system as the artifact output location in the project's buildspec file. Configure a file system policy that allows CodeBuild to access the file system. Most Voted
  • D. Create an Amazon Elastic Block Store (Amazon EBS) volume. Configure the EBS volume as the artifact output location in the project's buildspec file. Configure an IAM role that allows CodeBuild to access the volume.
