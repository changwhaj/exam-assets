한 회사에 Amazon API Gateway REST API, AWS Lambda 함수, Amazon DynamoDB 테이블을 사용하는 애플리케이션이 있습니다. 이 애플리케이션은 현재 단일 AWS 리전에서 실행되고 있습니다. 회사는 두 리전에서 애플리케이션의 고가용성을 확보하고자 합니다. 사용자 트래픽은 지연 시간이 가장 짧은 리전으로 라우팅되어야 합니다.

이러한 요구 사항을 충족하는 단계 조합은 무엇입니까? (세 가지 선택)

  • A. 두 번째 지역에 DynamoDB 테이블의 복제본을 만듭니다. 가장 많이 투표된
  • B. DynamoDB 테이블에 대한 글로벌 보조 인덱스를 생성합니다.
  • C. 두 번째 지역에 REST API와 Lambda 함수의 복사본을 만듭니다. 가장 많이 투표된
  • D. Amazon Route 53에서 상태 확인을 생성합니다. 장애 조치 라우팅 정책이 포함된 DNS 레코드를 생성합니다.
  • E. Amazon Route 53에서 상태 확인을 생성합니다. 지연 라우팅 정책이 포함된 DNS 레코드를 생성합니다. 가장 많이 투표된
  • F. Amazon Route 53에 다중값 응답 라우팅 정책을 포함하는 DNS 레코드를 만듭니다.

Exam question from Amazon's AWS Certified DevOps Engineer - Professional DOP-C02

Topic #: 1

A company has an application that uses an Amazon API Gateway REST API, AWS Lambda functions, and an Amazon DynamoDB table. The application currently runs in a single AWS Region. The company wants to make the application highly available across two Regions. User traffic must be routed to the Region that provides the least latency.

Which combination of steps will meet these requirements? (Choose three.)

  • A. Create a replica of the DynamoDB table in a second Region. Most Voted
  • B. Create a global secondary index for the DynamoDB table.
  • C. Create copies of the REST API and the Lambda functions in a second Region. Most Voted
  • D. Create health checks in Amazon Route 53. Create DNS records that include a failover routing policy.
  • E. Create health checks in Amazon Route 53. Create DNS records that include a latency routing policy. Most Voted
  • F. Create DNS records in Amazon Route 53 that include a multivalue answer routing policy.

A (replicate DynamoDB) — You need a DynamoDB replica (Global Table) in the second Region so each Region has a local copy of the data for low-latency reads/writes and resilience. C (copy API + Lambdas) — API Gateway and the Lambda functions must be deployed in the second Region so the Region can serve requests locally (active–active setup). E (Route 53 latency routing + health checks) — Use Route 53 latency routing so users are routed to the Region with the lowest network latency. Adding Route 53 health checks helps route around an unhealthy endpoint.
