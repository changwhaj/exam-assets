Amazon의 AWS Certified DevOps Engineer - Professional DOP-C02의 시험 문제
질문 #: 363
주제 #: 1

DevOps 엔지니어는 AWS WAF를 사용하여 AWS 계정에서 웹 ACL을 관리합니다. DevOps 엔지니어는 계정의 모든 애플리케이션 로드 밸런서(ALB)에 AWS WAF가 활성화되어 있는지 확인해야 합니다. DevOps 엔지니어는 AWS CloudFormation 템플릿을 사용하여 각 애플리케이션 스택의 배포 프로세스의 일부로 개별 ALB와 AWS WAF를 배포합니다. ALB가 배포된 후 AWS WAF가 ALB에서 제거되면 AWS WAF가 ALB에 자동으로 추가되어야 합니다.

어떤 솔루션이 가장 높은 운영 효율성으로 이러한 요구 사항을 충족할까요?

  • A. AWS Config를 활성화합니다. alb-waf-enabled 관리 규칙을 추가합니다. AWS Systems Manager Automation 문서를 만들어 ALB에 AWS WAF를 추가합니다. 규칙을 편집하여 자동으로 수정합니다. Systems Manager Automation 문서를 수정 작업으로 선택합니다.
  • B. AWS Config를 활성화합니다. alb-waf-enabled 관리형 규칙을 추가합니다. 모든 AWS Config ConfigurationItemChangeNotification 알림 유형을 AWS Lambda 함수로 전송하는 Amazon EventBridge 규칙을 만듭니다. Lambda 함수를 구성하여 탐지 모드에서 AWS Config start-resource-evaluation API를 호출합니다.
  • C. CloudFormation 템플릿에서 detect-stack-drift API를 호출하는 AWS Lambda 함수를 주기적으로 호출하도록 Amazon EventBridge 규칙을 구성합니다. AWS::WAFv2::WebACLAssociation 리소스가 drifted 상태를 표시하는 경우 waf.fail_open.enabled를 true로 설정하여 ALB 속성을 수정하도록 Lambda 함수를 구성합니다.
  • D. CloudFormation 템플릿에서 detect-stack-drift API를 호출하는 AWS Lambda 함수를 주기적으로 호출하도록 Amazon EventBridge 규칙을 구성합니다. AWS::WAFv2::WebACLAssociation 리소스가 drifted 상태를 표시하는 경우 CloudFormation 스택을 삭제하고 다시 배포하도록 Lambda 함수를 구성합니다.

Exam question from Amazon's AWS Certified DevOps Engineer - Professional DOP-C02
Question #: 363
Topic #: 1

A DevOps engineer uses AWS WAF to manage web ACLs across an AWS account. The DevOps engineer must ensure that AWS WAF is enabled for all Application Load Balancers (ALBs) in the account. The DevOps engineer uses an AWS CloudFormation template to deploy an individual ALB and AWS WAF as part of each application stack's deployment process. If AWS WAF is removed from the ALB after the ALB is deployed, AWS WAF must be added to the ALB automatically.

Which solution will meet these requirements with the MOST operational efficiency?

  • A. Enable AWS Config. Add the alb-waf-enabled managed rule. Create an AWS Systems Manager Automation document to add AWS WAF to an ALB. Edit the rule to automatically remediate. Select the Systems Manager Automation document as the remediation action.
  • B. Enable AWS Config. Add the alb-waf-enabled managed rule. Create an Amazon EventBridge rule to send all AWS Config ConfigurationItemChangeNotification notification types to an AWS Lambda function. Configure the Lambda function to call the AWS Config start-resource-evaluation API in detective mode.
  • C. Configure an Amazon EventBridge rule to periodically call an AWS Lambda function that calls the detect-stack-drift API on the CloudFormation template. Configure the Lambda function to modify the ALB attributes with waf.fail_open.enabled set to true if the AWS::WAFv2::WebACLAssociation resource shows a status of drifted.
  • D. Configure an Amazon EventBridge rule to periodically call an AWS Lambda function that calls the detect-stack-drift API on the CloudFormation template. Configure the Lambda function to delete and redeploy the CloudFormation stack if the AWS::WAFv2::WebACLAssociation resource shows a status of drifted.

AWS Config can detect non-compliance, such as an ALB without a WAF. The alb-waf-enabled managed rule checks for exactly that: whether an AWS WAF ACL is associated with the ALB. By configuring an automatic remediation action with Systems Manager Automation, you can automatically reattach the Web ACL to the ALB as soon as non-compliance is detected. This approach is 100% automated, based on managed services, with no scripting or manual detection required.
