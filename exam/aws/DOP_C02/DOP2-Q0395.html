주제 번호: 1

DevOps 엔지니어는 AWS 클라우드 배포와 온프레미스 배포를 위한 배포 아티팩트를 표준화하는 클라우드 기반 솔루션을 설계해야 합니다. 현재 온프레미스 데이터 센터와 AWS 환경 간에는 라우팅 트래픽이 없습니다.

이 솔루션은 퍼블릭 리포지토리에서 다운스트림 패키지를 사용할 수 있어야 하며 고가용성을 보장해야 합니다. 데이터는 전송 중과 저장 시 모두 암호화되어야 합니다. 솔루션은 배포 아티팩트를 객체 스토리지에 저장하고 Amazon Elastic Container Service(Amazon ECS)에 배포해야 합니다. 배포 아티팩트가 공용 인터넷을 통해 전송되는 경우 전송 중에도 암호화되어야 합니다.

DevOps 엔지니어는 2주 이내에 이 솔루션을 배포해야 합니다.

이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • B. AWS Direct Connect 연결과 VPN 연결을 사용하여 온프레미스 데이터 센터를 AWS에 연결합니다. 타사 아티팩트 관리 소프트웨어를 Amazon EC2 인스턴스에 배포합니다.
  • C. 온프레미스 데이터 센터를 AWS에 연결하기 위해 두 개의 AWS VPN 연결을 사용합니다. 배포 아티팩트는 AWS CodeArtifact를 사용하여 저장합니다.
  • D. 병렬 AWS Direct Connect 연결을 사용하여 온프레미스 데이터 센터를 AWS에 연결합니다. 타사 아티팩트 관리 소프트웨어를 Amazon EC2 인스턴스에 배포합니다.

Exam question from Amazon's AWS Certified DevOps Engineer - Professional DOP-C02
Question #: 395
Topic #: 1

A DevOps engineer needs to design a cloud-based solution to standardize deployment artifacts for AWS Cloud deployments and on-premises deployments. There is currently no routing traffic between the on-premises data center and the AWS environment.

The solution must be able to consume downstream packages from public repositories and must be highly available. Data must be encrypted in transit and at rest. The solution must store the deployment artifacts in object storage and deploy the deployment artifacts into Amazon Elastic Container Service (Amazon ECS). The deployment artifacts must be encrypted in transit if the deployment artifacts travel across the public internet.

The DevOps engineer needs to deploy this solution in less than two weeks.

Which solution will meet these requirements?

  • B. Use an AWS Direct Connect connection and a VPN connection to connect the on-premises data center to AWS. Deploy third-party artifact management software on Amazon EC2 instances.
  • C. Use two AWS VPN connections to connect the on-premises data center to AWS. Use AWS CodeArtifact to store the deployment artifacts.
  • D. Use parallel AWS Direct Connect connections to connect the on-premises data center to AWS. Deploy third-party artifact management software on Amazon EC2 instances.

The correct answer is C. Two critical constraints drive this solution: the "less than two weeks" timeline and the need for "high availability." AWS CodeArtifact is a fully managed service that provides instant high availability and encryption for package management without the overhead of managing EC2 instances. Combined with AWS VPN, which can be established quickly over the internet, this approach offers the fastest and most secure way to standardize hybrid cloud deployment artifacts under tight deadlines.
