한 회사가 AWS 계정에서 여러 애플리케이션을 호스팅하고 있습니다. 각 애플리케이션은 Amazon CloudWatch의 자체 로그 그룹으로 로그를 전송합니다. 이 회사의 CloudWatch 수집 비용이 증가하고 있습니다.

DevOps 엔지니어는 어떤 애플리케이션이 로깅 비용 증가의 원인인지 파악해야 합니다.

어떤 솔루션이 이 요구 사항을 가장 운영 효율적으로 충족할 수 있을까요?

  • A. CloudWatch 메트릭을 사용하여 가장 많은 데이터를 수신하는 CloudWatch 로그 그룹을 식별하는 사용자 지정 표현식을 만듭니다.
  • B. Amazon CloudWatch Logs Insights를 사용하여 애플리케이션 로그 그룹에 대한 쿼리를 생성하여 특정 기간 동안 데이터를 수신한 로그 그룹 수를 식별합니다. 가장 많이 투표된
  • C. AWS Cost Explorer를 사용하여 CloudWatch 사용에 대한 비용을 자세히 설명하는 비용 보고서를 생성합니다.
  • D. AWS CloudTrail을 사용하여 각 애플리케이션의 CreateLogStream 이벤트를 필터링합니다.

A company hosts several applications in an AWS account. Each application sends logs to its own log group in Amazon CloudWatch. The company's CloudWatch costs for ingestion are increasing.

A DevOps engineer needs to identify which applications are the source of the increased logging costs.

Which solution will meet this requirement in the MOST operationally efficient way?

  • A. Use CloudWatch metrics to create a custom expression that identifies the CloudWatch log groups that receive the most data.
  • B. Use Amazon CloudWatch Logs Insights to create a query for the application log groups to identify the number of log groups that received data during a specific time period. Most Voted
  • C. Use AWS Cost Explorer to generate a cost report that details costs for CloudWatch usage.
  • D. Use AWS CloudTrail to filter for CreateLogStream events for each application.
