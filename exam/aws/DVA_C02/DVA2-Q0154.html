What should the developer do to meet these requirements?

  • A. Configure an AWS CloudTrail log file delivery to an Amazon S3 bucket. Create an Amazon CloudWatch alarm for the GetSecretValue Secrets Manager API operation requests.
  • B. Create a secretsmanager-secret-unused AWS Config managed rule. Create an Amazon EventBridge rule to initiate notifications when the AWS Config managed rule is met. Most Voted
  • C. Deactivate the applications secrets and monitor the applications error logs temporarily.
  • D. Configure AWS X-Ray for the applications. Create a sampling rule to match the GetSecretValue Secrets Manager API operation requests.

선택된 답변: A
A. AWS Step Functions 상태 머신을 사용하여 API 오류를 모니터링합니다. '대기(Wait)' 상태를 사용하여 Lambda 함수 호출을 지연시킵니다. 이는 실행 가능하고 효율적인 솔루션입니다. AWS Step Functions는 Lambda 함수 호출을 오케스트레이션하고 API 호출 속도 제한 처리를 포함한 워크플로를 관리할 수 있습니다. '대기' 상태를 사용하여 API 호출 사이에 지연 시간을 두어 속도 제한을 준수할 수 있습니다. 또한 이 접근 방식을 통해 오류 및 재시도를 효과적으로 처리할 수 있습니다. B. Amazon Simple Queue Service(Amazon SQS) 큐를 사용하여 API 호출을 저장합니다. Lambda 함수가 API 호출 임계값 내에서 큐를 폴링하도록 구성합니다. SQS를 사용하여 API 호출 요청을 큐에 저장하는 것은 워크로드를 관리하는 좋은 방법이지만, 솔루션이 복잡해집니다. Lambda 함수는 큐를 관리하고 API 호출이 임계값 내에서 이루어지도록 수정해야 합니다. 이 접근 방식은 Step Functions를 사용하는 것만큼 간단하고 효율적이지 않을 수 있습니다.
