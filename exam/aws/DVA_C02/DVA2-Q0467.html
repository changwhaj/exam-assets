개발자가 AWS Lambda 함수를 컴파일하고 결과를 .zip 파일로 패키징합니다. Lambda 콘솔의 함수 페이지를 사용하여 로컬에 패키징된 .zip 파일을 업로드하려고 시도합니다. 하지만 Lambda에 패키지를 푸시할 때 콘솔에 다음과 같은 오류가 발생합니다.



개발자가 코드를 게시하기 위해 사용할 수 있는 해결 방법은 무엇입니까? (두 가지를 선택하십시오.)

  • A. 패키지를 Amazon에 업로드합니다. 3. Lambda 콘솔의 함수 페이지를 사용하여 S3 위치에서 패키지를 업로드합니다.
  • B. 최대 패키지 크기를 늘리기 위해 AWS 지원 티켓을 생성하세요.
  • C. `update-function-code` AWS CLI 명령어를 사용합니다. `--publish` 매개변수를 전달합니다.
  • D. Lambda 함수를 Docker 컨테이너 이미지로 재구성합니다. 해당 이미지를 Amazon Elastic Container Registry(Amazon ECR)에 업로드합니다. Lambda 콘솔을 사용하여 새 Lambda 함수를 생성합니다. Amazon ECR에 배포된 이미지를 참조합니다.
  • E. .zip 파일에 디지털 서명을 합니다. Lambda 콘솔을 사용하여 새 Lambda 함수를 생성합니다. 새 Lambda 함수의 구성을 업데이트하여 코드 서명 구성의 Amazon 리소스 이름(ARN)을 포함시킵니다.
