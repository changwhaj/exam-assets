문제 번호: 531
주제 번호: 1

한 회사가 Amazon EC2 인스턴스에서 실행되는 애플리케이션을 보유하고 있습니다. 이 애플리케이션은 다른 애플리케이션과 공유될 동적 기능 플래그를 사용해야 합니다. 애플리케이션은 정해진 간격으로 새로운 기능 플래그 값을 폴링해야 하며, 값을 가져올 때 캐시해야 합니다.

이러한 요구 사항을 가장 운영 효율적인 방식으로 충족하는 솔루션은 무엇일까요?

  • A. 기능 플래그 값을 AWS Secrets Manager에 저장합니다. 애플리케이션에서 지연 로딩 전략을 사용하여 Amazon ElastiCache 노드를 구성하고 해당 값을 캐시합니다. 애플리케이션을 업데이트하여 ElastiCache에서 일정 간격으로 값을 폴링하도록 합니다.
  • B. 기능 플래그 값을 Amazon DynamoDB 테이블에 저장합니다. 애플리케이션에서 지연 로딩 전략을 사용하여 DynamoDB Accelerator(DAX)가 해당 값을 캐시하도록 구성합니다. 애플리케이션을 업데이트하여 DynamoDB에서 일정 간격으로 값을 폴링하도록 합니다. 가장 많은 표를 받은
  • C. 기능 플래그 값을 AWS AppConfig에 저장합니다. EC2 인스턴스에서 AWS AppConfig 에이전트를 구성하여 지정된 간격으로 값을 폴링하도록 합니다. 애플리케이션을 업데이트하여 AppConfig 에이전트의 localhost 엔드포인트에서 값을 가져오도록 합니다.
  • D. 기능 플래그 값을 AWS Systems Manager 파라미터 스토어에 저장합니다. 애플리케이션이 지정된 간격으로 값을 폴링하도록 구성합니다. 애플리케이션이 AWS SDK를 사용하여 파라미터 스토어에서 값을 검색하고 메모리에 저장하도록 구성합니다.

Exam question from Amazon's AWS Certified Developer - Associate DVA-C02
Question #: 531
Topic #: 1

A company has an application that runs on Amazon EC2 instances. The application needs to use dynamic feature flags that will be shared with other applications. The application must poll on an interval for new feature flag values. The values must be cached when they are retrieved.

Which solution will meet these requirements in the MOST operationally efficient way?

  • A. Store the feature flag values in AWS Secrets Manager. Configure an Amazon ElastiCache node to cache the values by using a lazy loading strategy in the application. Update the application to poll for the values on an interval from ElastiCache.
  • B. Store the feature flag values in an Amazon DynamoDB table. Configure DynamoDB Accelerator (DAX) to cache the values by using a lazy loading strategy in the application. Update the application to poll for the values on an interval from DynamoDB. Most Voted
  • C. Store the feature flag values in AWS AppConfig. Configure AWS AppConfig Agent on the EC2 instances to poll for the values on an interval. Update the application to retrieve the values from the AppConfig Agent localhost endpoint.
  • D. Store the feature flag values in AWS Systems Manager Parameter Store. Configure the application to poll on an interval. Configure the application to use the AWS SDK to retrieve the values from Parameter Store and to store the values in memory.
