주제 번호: 1

한 회사가 파트너로부터 매일 주문을 일괄 처리하는 애플리케이션을 사용하고 있습니다. 이 애플리케이션은 AWS Lambda 함수를 사용하여 이러한 일괄 처리를 수행합니다.

만약 일괄 처리된 주문에 주문이 하나도 없다면, Lambda 함수는 가능한 한 빨리 Amazon Simple Notification Service(Amazon SNS) 토픽에 알림을 게시해야 합니다.

이 요구 사항을 충족하면서 구현 노력이 가장 적은 방법은 무엇일까요? (두 가지를 선택하세요.)

  • A. 기존 Lambda 함수의 코드를 업데이트하여 각 파트너별 일괄 주문 건수를 나타내는 Amazon CloudWatch 사용자 지정 메트릭을 전송하도록 합니다. 가장 많은 표를 받은
  • B. Amazon Kinesis 데이터 스트림 소비자로 사용할 새 Lambda 함수를 생성합니다. 새 Lambda 함수를 구성하여 주문을 추적하고, 배치에 주문이 없을 경우 SNS 토픽에 게시하도록 합니다.
  • C. 사용자 지정 메트릭 값이 0일 때 SNS 토픽으로 알림을 보내도록 Amazon CloudWatch 알람을 설정합니다. 가장 많은 표를 받은
  • D. Amazon CloudWatch 지표를 24시간마다 분석하여 주문이 없는 배치를 식별하는 새로운 Lambda 함수를 예약합니다. Lambda 함수가 SNS 토픽에 게시하도록 구성합니다.
  • E. 기존 Lambda 함수를 수정하여 주문 내역을 Amazon Kinesis 데이터 스트림에 기록합니다.

Topic #: 1

A company has an application that receives batches of orders from partners every day. The application uses an AWS Lambda function to process the batches.

If a batch contains no orders, the Lambda function must publish to an Amazon Simple Notification Service (Amazon SNS) topic as soon as possible.

Which combination of steps will meet this requirement with the LEAST implementation effort? (Choose two.)

  • A. Update the existing Lambda function's code to send an Amazon CloudWatch custom metric for the number of orders in a batch for each partner. Most Voted
  • B. Create a new Lambda function as an Amazon Kinesis data stream consumer. Configure the new Lambda function to track orders and to publish to the SNS topic when a batch contains no orders.
  • C. Set up an Amazon CloudWatch alarm that will send a notification to the SNS topic when the value of the custom metric is 0. Most Voted
  • D. Schedule a new Lambda function to analyze Amazon CloudWatch metrics every 24 hours to identify batches that contain no orders. Configure the Lambda function to publish to the SNS topic.
  • E. Modify the existing Lambda function to log orders to an Amazon Kinesis data stream.
