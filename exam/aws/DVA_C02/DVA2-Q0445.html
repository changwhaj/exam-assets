주제 번호: 1

한 개발자가 서버리스 애플리케이션의 배포 프로세스를 자동화하는 스크립트를 작성하고 있습니다. 이 개발자는 기존 AWS 서버리스 애플리케이션 모델(AWS SAM) 템플릿을 사용하려고 합니다.

이 프로젝트에 어떤 템플릿을 사용해야 할까요? (두 가지를 선택하세요.)

  • A. `aws cloudformation package` 명령을 호출하여 배포 패키지를 생성합니다. 그런 다음 `aws cloudformation deploy` 명령을 호출하여 패키지를 배포합니다. 가장 많은 표를 받은
  • B. sam package 명령어를 호출하여 배포 패키지를 생성합니다. 그런 다음 sam deploy 명령어를 호출하여 패키지를 배포합니다. 가장 많은 표를 받은
  • C. `aws s3 cp` 명령을 호출하여 AWS SAM 템플릿을 Amazon S3에 업로드합니다. `aws lambda update-function-code` 명령을 호출하여 애플리케이션을 생성합니다.
  • D. 로컬에서 ZIP 패키지를 생성하고 aws serverlessrepo create-application 명령을 호출하여 애플리케이션을 생성합니다.
  • E. ZIP 패키지를 생성하여 Amazon S3에 업로드합니다. aws cloudformation create-stack 명령을 호출하여 애플리케이션을 생성합니다.

What should the developer use for the project? (Choose two.)

  • A. Call aws cloudformation package to create the deployment package. Call aws cloudformation deploy to deploy the package afterward. Most Voted
  • B. Call sam package to create the deployment package. Call sam deploy to deploy the package afterward. Most Voted
  • C. Call aws s3 cp to upload the AWS SAM template to Amazon S3. Call aws lambda update-function-code to create the application.
  • D. Create a ZIP package locally and call aws serverlessrepo create-applicatiion to create the application.
  • E. Create a ZIP package and upload it to Amazon S3. Call aws cloudformation create-stack to create the application.
