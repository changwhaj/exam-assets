한 개발자가 Amazon API Gateway의 WebSocket API를 사용하는 애플리케이션을 개발했습니다. 이 개발자는 API Gateway Lambda 인증기를 사용하여 애플리케이션에 대한 접근을 제어하려고 합니다. 또한

자격 증명 캐싱을 추가하고, 매 요청마다 비밀 키와 인증 토큰을 반복적으로 사용하는 것을 줄여야 합니다.

이러한 요구 사항을 충족하기 위해 개발자가 취해야 할 조치는 무엇일까요? (두 가지를 선택하세요.)

  • A. 토큰 기반 Lambda 인증기를 사용합니다. 가장 많은 표를 받은
  • B. 요청 매개변수 기반 Lambda 인증자를 사용합니다.
  • C. APIGateway Lambda 권한 부여기의 컨텍스트 맵을 참조하도록 통합 요청 매핑 템플릿을 구성합니다. 가장 많은 표를 받은
  • D. API Gateway Lambda 인증자의 ID API 키 값을 참조하도록 통합 요청 매핑 템플릿을 구성합니다.
  • E. WebSocket API에 VPC 엔드포인트 정책을 사용합니다.

A developer has an application that uses WebSocket APIs in Amazon API Gateway. The developer wants to use an API Gateway Lambda authorizer to control access to the application.

The developer needs to add credential caching and reduce repeated usage of secret keys and authorization tokens on every request.

Which combination of steps should the developer take to meet these requirements? (Choose two.)

  • A. Use a token-based Lambda authorizer. Most Voted
  • B. Use a request parameter-based Lambda authorizer.
  • C. Configure an integration request mapping template to reference the context map from the APIGateway Lambda authorizer. Most Voted
  • D. Configure an integration request mapping template to reference the identity API key value from the API Gateway Lambda authorizer.
  • E. Use VPC endpoint policies for the WebSocket APIs.
