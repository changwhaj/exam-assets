A: AWS Storage Gateway – 온프레미스 환경과 AWS 스토리지 서비스를 통합하는 데 사용되며 데이터베이스 마이그레이션에는 적합하지 않습니다. B: AWS Application Migration Service – 전체 서버 또는 애플리케이션을 재호스팅하는 데 사용되며 데이터베이스에 특화되어 있지 않습니다. Selected Answer: D
A: AWS Storage Gateway – Used for integrating on-premises environments with AWS storage services, not for migrating databases. B: AWS Application Migration Service – Used to rehost entire servers or applications, not focused on databases. C: AWS DataSync – Transfers files between on-premises and AWS, not structured databases. D: AWS Database Migration Service (AWS DMS), it helps migrate on-premises databases to AWS managed database services with a simplified and reliable process.
