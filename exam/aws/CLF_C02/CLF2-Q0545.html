Amazon Aurora is a fully managed database service. According to the AWS shared responsibility model, AWS is responsible for managing the encryption of: Database clusters Automated backups Database snapshots This includes the encryption mechanisms and infrastructure (such as storage-level encryption using AWS-managed services). What the company is responsible for: Choosing whether encryption is enabled Managing access controls and permissions Managing encryption keys (if using customer-managed keys in AWS KMS) ✅ Under the AWS shared responsibility model, AWS manages the encryption of Amazon Aurora database clusters and snapshots.
