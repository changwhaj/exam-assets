C. AWS Identity and Access Management(IAM) 액세스 분석기 - 이 도구는 다른 AWS 계정과 공유되는 정책을 포함하여 리소스 액세스 정책을 식별하고 분석하는 데 도움이 됩니다. IAM 자격 증명 보고서는 AWS 계정의 사용자 자격 증명에 대한 정보를 제공하지만 계정 간 공유는 지원하지 않습니다.
