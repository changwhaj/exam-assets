정답은 C입니다. IAM 액세스 분석기: IAM 정책을 분석하여 잠재적인 문제와 과도한 권한을 식별하지만, 암호 및 액세스 키 순환 세부 정보에 특화되어 있지는 않습니다. AWS 아티팩트: 주로 IaC(인프라스트럭처 코드) 구성을 관리하고 추적하는 데 사용되며, 자격 증명 감사와는 직접적인 관련이 없습니다. AWS 감사 관리자: 다양한 AWS 서비스에 걸쳐 감사를 관리하고 자동화하는 포괄적인 플랫폼을 제공하지만, 바로 사용 가능한 IAM 자격 증명 보고서에 비해 추가 설정 및 구성이 필요합니다.

C. IAM 자격 증명 보고서: IAM(Identity and Access Management) 자격 증명 보고서는 AWS 계정의 모든 사용자와 암호 및 액세스 키 순환 세부 정보를 포함한 다양한 자격 증명 상태를 자세히 보여주는 보고서입니다. 이 보고서는 규정 준수를 위한 암호 및 액세스 키 순환 활동 감사에 필요한 정보를 제공합니다. IAM 자격 증명 보고서는 회사에서 요구하는 암호 및 액세스 키 순환 세부 정보 감사를 충족하는 AWS 서비스 또는 도구입니다. 다른 옵션은 다음과 같습니다. A. IAM 액세스 분석기: AWS 환경의 리소스 정책을 분석하여 의도치 않은 액세스를 식별하고 해결하는 데 도움을 줍니다. B. AWS 아티팩트: AWS 규정 준수 보고서 및 문서에 대한 온디맨드 액세스를 제공합니다. D. AWS 감사 관리자: AWS 사용량을 지속적으로 감사하여 규정 및 업계 표준에 대한 위험 및 규정 준수 평가 방법을 간소화합니다. 이러한 서비스는 규정 준수에 유용할 수 있지만 암호 및 액세스 키 순환 세부 정보 감사 요구 사항을 구체적으로 충족하지는 않습니다.

The Correct answer is C. IAM Access Analyzer: Analyzes IAM policies to identify potential issues and excessive permissions, but doesn't specifically focus on password and access key rotation details. AWS Artifact: Primarily used for managing and tracking infrastructure as code (IaC) configurations, not directly related to credential auditing. IAM credential report: This built-in IAM feature provides detailed information about the rotation history of user passwords and access keys within the account. It shows dates of last password and access key rotation, along with usernames and key IDs. This aligns perfectly with the requirement of auditing password and access key rotation details for compliance purposes. AWS Audit Manager: Offers a comprehensive platform for managing and automating audits across various AWS services, but it requires additional setup and configuration compared to the readily available IAM credential report
