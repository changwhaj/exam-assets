Topic #: 1

A network engineer needs to build a hybrid cloud architecture connecting on-premises networks to the AWS Cloud using AWS Direct Connect. The company has a few VPCs in a single AWS Region and expects to increase the number of VPCs to hundreds over time.
Which AWS service or feature should the engineer use to simplify and scale this connectivity as the VPCs increase in number?

  • A. VPC endpoints
  • B. AWS Transit Gateway Most Voted
  • C. Amazon Route 53
  • D. AWS Secrets Manager

A. VPC endpoints: Enable private connectivity between your VPC and supported AWS services. While useful for accessing AWS services without going over the internet, it doesn't directly address the need for connecting multiple VPCs and on-premises networks. B. With AWS Transit Gateway, network engineers can manage the connectivity centrally, making it a suitable solution for scenarios where multiple VPCs need to connect to on-premises networks. C.
