문제 번호: 463
주제 번호: 1

한 회사가 Amazon EC2 인스턴스가 시작될 때 특정 소프트웨어를 설치하는 솔루션을 구현해야 합니다.

이 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. EC2 인스턴스가 시작될 때 필요한 소프트웨어로 부트스트랩되도록 AWS Systems Manager State Manager 연결을 구성합니다. 가장 많은 표를 받은
  • B. Amazon CloudWatch 에이전트를 사용하여 EC2 인스턴스 시작 이벤트를 감지하고 필요한 소프트웨어를 주입합니다. StartTask API 작업에 대한 권한을 추가하도록 InstanceRole IAM 역할을 수정합니다.
  • C. Amazon Inspector를 사용하여 EC2 시작 이벤트를 감지합니다. EC2 시작 이벤트에 대한 라이프사이클 후크의 일부로 필요한 소프트웨어를 설치하도록 Amazon Inspector를 구성합니다.
  • D. AWS Security Hub 복구 작업을 사용하여 시작 시 필요한 소프트웨어를 설치합니다.
