아마존 AWS 공인 시스템 운영 관리자 - 어소시에이트 시험 문제
문제 번호: 125
주제 번호: 1

한 회사가 애플리케이션 로드 밸런서 뒤에 있는 Amazon EC2 인스턴스에 웹 애플리케이션을 호스팅하고 있습니다. 해당 인스턴스는 Amazon EC2 Auto Scaling 그룹에 속해 있습니다. 애플리케이션은 공개 URL을 통해 접근할 수 있습니다.

시스템 운영 관리자는 고객과 동일한 경로 및 조치를 따르는 애플리케이션 가용성 모니터링 솔루션을 구현해야 합니다. 모니터링 실행의 95% 미만에서 오류가 발견되지 않으면 시스템 운영 관리자에게 알림이 전송되어야 합니다.

이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. 고객 경로를 따라가는 스크립트를 사용하여 Amazon CloudWatch Synthetics 카나리를 생성합니다. 카나리가 정기적으로 실행되도록 예약합니다. SuccessPercent 지표가 95% 미만일 때 Amazon Simple Notification Service(Amazon SNS) 토픽에 메시지를 게시하는 CloudWatch 알람을 생성합니다. 가장 많은 표를 받은
  • B. 엔드포인트의 가용성을 모니터링하는 Amazon Route 53 상태 점검을 생성합니다. HealthCheckPercentageHealthy 지표가 95% 미만일 때 Amazon Simple Notification Service(Amazon SNS) 토픽에 메시지를 게시하는 Amazon CloudWatch 알람을 생성합니다.
  • C. 각 고객 경로에 대한 엔드포인트 사용 가능 여부를 확인하는 AWS Lambda 함수를 하나 생성합니다. Amazon EventBridge(Amazon CloudWatch Events)를 사용하여 Lambda 함수를 예약합니다. 엔드포인트에서 오류가 반환될 때 Amazon Simple Notification Service(Amazon SNS) 토픽에 메시지를 게시하도록 Lambda 함수를 구성합니다.
  • D. 각 고객 경로에 대해 특정 엔드포인트의 가용성을 확인하는 AWS Lambda 함수를 생성합니다. Amazon EventBridge(Amazon CloudWatch Events)를 사용하여 Lambda 함수를 예약합니다. 각 Lambda 함수가 엔드포인트 상태에 대한 사용자 지정 메트릭을 Amazon CloudWatch에 게시하도록 구성합니다. 각 사용자 지정 메트릭을 기반으로 CloudWatch 알람을 생성하여 알람 상태가 ALARM일 때 Amazon Simple Notification Service(Amazon SNS) 토픽에 메시지를 게시합니다.

Exam question from Amazon's AWS Certified SysOps Administrator - Associate
Question #: 125
Topic #: 1

A company hosts a web application on Amazon EC2 instances behind an Application Load Balancer. The instances are in an Amazon EC2 Auto Scaling group. The application is accessed with a public URL.

A SysOps administrator needs to implement a monitoring solution that checks the availability of the application and follows the same routes and actions as a customer. The SysOps administrator must receive a notification if less than 95% of the monitoring runs find no errors.

Which solution will meet these requirements?

  • A. Create an Amazon CloudWatch Synthetics canary with a script that follows customer routes. Schedule the canary to run on a recurring schedule. Create a CloudWatch alarm that publishes a message to an Amazon Simple Notification Service (Amazon SNS) topic when the SuccessPercent metric is less than 95%. Most Voted
  • B. Create Amazon Route 53 health checks that monitor the availability of the endpoint. Create Amazon CloudWatch alarms that publish a message to an Amazon Simple Notification Service (Amazon SNS) topic when the HealthCheckPercentageHealthy metric is less than 95%.
  • C. Create a single AWS Lambda function to check whether the endpoints are available for each customer path. Schedule the Lambda function by using Amazon EventBridge (Amazon CloudWatch Events). Configure the Lambda function to publish a message to an Amazon Simple Notification Service (Amazon SNS) topic when an endpoint returns an error.
  • D. Create an AWS Lambda function for each customer path to check whether that specific endpoint is available. Schedule the Lambda functions by using Amazon EventBridge (Amazon CloudWatch Events). Configure each Lambda function to publish a custom metric to Amazon CloudWatch for the endpoint status. Create CloudWatch alarms based on each custom metric to publish a message to an Amazon Simple Notification Service (Amazon SNS) topic when an alarm is in the ALARM state.
