아마존 AWS 공인 시스템 운영 관리자 - 어소시에이트 시험 문제
질문 번호: 360
주제 번호: 1

제조 회사는 모든 재고 품목의 재고 정보를 저장하기 위해 Amazon RDS DB 인스턴스를 사용합니다. 이 회사는 데이터베이스와 상호 작용하여 품목을 추가, 업데이트 및 삭제하는 여러 AWS Lambda 함수를 운영합니다. Lambda 함수는 데이터베이스에 연결하기 위해 하드코딩된 자격 증명을 사용합니다.

시스템 운영 관리자는 데이터베이스 자격 증명이 평문으로 저장되지 않도록 하고, 암호를 30일마다 변경해야 합니다.

이러한 요구 사항을 가장 운영 효율적인 방식으로 충족하는 솔루션은 무엇일까요?

  • A. 각 Lambda 함수에 대해 데이터베이스 암호를 환경 변수로 저장합니다. PasswordRotate라는 이름의 새 Lambda 함수를 생성합니다. Amazon EventBridge를 사용하여 PasswordRotate 함수를 30일마다 실행하도록 예약하고, 각 Lambda 함수의 데이터베이스 암호를 변경하고 환경 변수를 업데이트합니다.
  • B. AWS 키 관리 서비스(AWS KMS)를 사용하여 데이터베이스 암호를 암호화하고, 암호화된 암호를 각 Lambda 함수의 환경 변수로 저장합니다. 각 Lambda 함수에 KMS 키에 대한 액세스 권한을 부여하여 필요할 때 데이터베이스 암호를 복호화할 수 있도록 합니다. 30일마다 암호를 변경하는 PasswordRotate라는 이름의 새로운 Lambda 함수를 생성합니다.
  • C. AWS Secrets Manager를 사용하여 데이터베이스 자격 증명을 저장합니다. Secrets Manager 시크릿을 생성하고, Secrets Manager가 Lambda 함수를 사용하여 데이터베이스 암호를 자동으로 업데이트하도록 데이터베이스를 선택합니다. 자동 암호 갱신 일정을 30일로 지정합니다. 각 Lambda 함수가 Secrets Manager에서 데이터베이스 암호에 접근하도록 업데이트합니다. 가장 많은 표를 받은
  • D. AWS Systems Manager 파라미터 스토어를 사용하여 데이터베이스 자격 증명을 저장할 보안 문자열을 생성합니다. PasswordRotate라는 이름의 새로운 Lambda 함수를 생성합니다. Amazon EventBridge를 사용하여 PasswordRotate 함수를 30일마다 실행하도록 예약하고, 데이터베이스 암호를 변경하고 파라미터 스토어의 암호를 업데이트합니다. 각 Lambda 함수가 파라미터 스토어에서 데이터베이스 암호에 접근할 수 있도록 수정합니다.

A manufacturing company uses an Amazon RDS DB instance to store inventory of all stock items. The company maintains several AWS Lambda functions that interact with the database to add, update, and delete items. The Lambda functions use hardcoded credentials to connect to the database.

A SysOps administrator must ensure that the database credentials are never stored in plaintext and that the password is rotated every 30 days.

Which solution will meet these requirements in the MOST operationally efficient manner?

  • A. Store the database password as an environment variable for each Lambda function. Create a new Lambda function that is named PasswordRotate. Use Amazon EventBridge to schedule the PasswordRotate function every 30 days to change the database password and update the environment variable for each Lambda function.
  • B. Use AWS Key Management Service (AWS KMS) to encrypt the database password and to store the encrypted password as an environment variable for each Lambda function. Grant each Lambda function access to the KMS key so that the database password can be decrypted when required. Create a new Lambda function that is named PasswordRotate to change the password every 30 days.
  • C. Use AWS Secrets Manager to store credentials for the database. Create a Secrets Manager secret, and select the database so that Secrets Manager will use a Lambda function to update the database password automatically. Specify an automatic rotation schedule of 30 days. Update each Lambda function to access the database password from Secrets Manager. Most Voted
  • D. Use AWS Systems Manager Parameter Store to create a secure string to store credentials for the database. Create a new Lambda function called PasswordRotate. Use Amazon EventBridge to schedule the PasswordRotate function every 30 days to change the database password and to update the secret within Parameter Store. Update each Lambda function to access the database password from Parameter Store.
