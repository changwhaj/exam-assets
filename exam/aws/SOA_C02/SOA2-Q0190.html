아마존 AWS 공인 시스템 운영 관리자 - 어소시에이트 시험 문제
문제 번호: 190
주제 번호: 1

한 회사가 EU-WEST-2 리전의 Elastic Load Balancer 뒤에 있는 Amazon EC2 인스턴스에서 실행되는 간단한 웹 애플리케이션을 보유하고 있습니다. Amazon Route 53은 해당 애플리케이션에 대한 DNS 레코드를 보유하고 있으며 간단한 라우팅 정책을 사용합니다. 전 세계 사용자들이 웹 브라우저를 통해 이 애플리케이션에 접속합니다.

이 회사는 US-EAST-1 리전과 AP-SOUTH-1 리전에도 동일한 애플리케이션의 추가 복사본을 생성해야 합니다. 또한 사용자가 애플리케이션에 접속할 때 가장 빠른 응답 시간을 제공하는 리전으로 사용자를 연결해야 합니다.

이러한 요구 사항을 충족하기 위해 시스템 운영 관리자는 어떻게 해야 할까요?

  • A. 새로운 리전마다 새로운 Elastic Load Balancer와 애플리케이션 복사본을 실행할 새로운 EC2 인스턴스 세트를 생성합니다. 지리적 위치 기반 라우팅 정책으로 전환합니다.
  • B. 각 새로운 리전에서 애플리케이션 복사본을 새 EC2 인스턴스에 생성합니다. 이러한 새 EC2 인스턴스를 eu-west-2 리전의 Elastic Load Balancer에 추가합니다. 지연 시간 라우팅 정책으로 전환합니다.
  • C. 각 새 리전에서 애플리케이션 복사본을 새 EC2 인스턴스에 생성합니다. 이러한 새 EC2 인스턴스를 eu-west-2 리전의 Elastic Load Balancer에 추가합니다. 다중 값 라우팅 정책으로 전환합니다.
  • D. 각 새로운 리전에서 새로운 Elastic Load Balancer와 애플리케이션 복사본을 실행할 새로운 EC2 인스턴스 세트를 생성합니다. 지연 시간 라우팅 정책으로 전환합니다. 가장 많은 표를 받은

Exam question from Amazon's AWS Certified SysOps Administrator - Associate
Question #: 190
Topic #: 1

A company has a simple web application that runs on a set of Amazon EC2 instances behind an Elastic Load Balancer in the eu-west-2 Region. Amazon Route 53 holds a DNS record for the application with a simple routing policy. Users from all over the world access the application through their web browsers.

The company needs to create additional copies of the application in the us-east-1 Region and in the ap-south-1 Region. The company must direct users to the Region that provides the fastest response times when the users load the application.

What should a SysOps administrator do to meet these requirements?

  • A. In each new Region, create a new Elastic Load Balancer and a new set of EC2 instances to run a copy of the application. Transition to a geolocation routing policy.
  • B. In each new Region, create a copy of the application on new EC2 instances. Add these new EC2 instances to the Elastic Load Balancer in eu-west-2. Transition to a latency routing policy.
  • C. In each new Region, create a copy of the application on new EC2 instances. Add these new EC2 instances to the Elastic Load Balancer in eu-west-2. Transition to a multivalue routing policy.
  • D. In each new Region, create a new Elastic Load Balancer and a new set of EC2 instances to run a copy of the application. Transition to a latency routing policy. Most Voted
