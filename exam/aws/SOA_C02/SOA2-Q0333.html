아마존 AWS 공인 시스템 운영 관리자 - 어소시에이트 시험 문제
문제 번호: 333
주제 번호: 1

시스템 운영 관리자는 단일 프로덕션 AWS 계정에 배포된 50개 이상의 Amazon EC2 인스턴스를 관리합니다. 이 EC2 인스턴스들은 여러 가지 운영 체제를 실행하고 있습니다. 회사 규정에 따라 최소 한 달에 한 번 패치를 완료해야 합니다.

시스템 운영 관리자는 AWS Systems Manager를 사용하여 매달 운영 체제 패치에 소요되는 시간을 줄이고자 합니다.

이러한 요구 사항을 충족하기 위해 시스템 운영 관리자는 어떤 단계를 수행해야 할까요? (세 가지를 선택하세요.)

  • A. AWS 리소스 그룹을 사용하여 유사한 EC2 인스턴스를 리소스 그룹으로 묶습니다. 가장 많은 표를 받은
  • B. 시스템 관리자 패치 관리자에서 일정을 생성합니다. 대상으로 적절한 리소스 그룹을 지정합니다.
  • C. 운영 체제 패치를 위한 시스템 관리자 자동화 런북을 지정합니다. 유지 관리 기간에 런북을 작업으로 등록합니다. 대상으로 적절한 리소스 그룹을 지정합니다. 가장 많은 표를 받은
  • D. 필요한 패치의 상태를 모니터링하고 제어하기 위한 Systems Manager 자동화 런북을 생성합니다. 생성된 런북을 Systems Manager 패치 관리자에 적용합니다.
  • E. 각 리소스 그룹에 대해 시스템 관리자 유지 관리 창을 하나씩 생성합니다. 가장 많은 표를 받은
  • F. Systems Manager Fleet Manager를 구성하여 Systems Manager Automation 런북을 해당 리소스 그룹에 적용합니다.

Exam question from Amazon's AWS Certified SysOps Administrator - Associate
Question #: 333
Topic #: 1

A SysOps administrator is responsible for more than 50 Amazon EC2 instances that are deployed in a single production AWS account. The EC2 instances are running several different operating systems. The company's standards require patching to be completed at least once a month.

The SysOps administrator wants to use AWS Systems Manager to reduce the number of hours the company spends on operating system patching each month.

Which combination of steps should the SysOps administrator take to meet these requirements? (Choose three.)

  • A. Group similar EC2 instances together into resource groups by using AWS Resource Groups. Most Voted
  • B. Create a schedule in Systems Manager Patch Manager. Specify the appropriate resource group as the target.
  • C. Specify Systems Manager Automation runbooks to patch the operating systems. Register the runbooks as tasks in the maintenance window. Specify the appropriate resource group as the target. Most Voted
  • D. Create a Systems Manager Automation runbook to monitor and control the state of the patches required. Apply the runbook to Systems Manager Patch Manager.
  • E. Create a single Systems Manager maintenance window for each resource group. Most Voted
  • F. Configure Systems Manager Fleet Manager to apply a Systems Manager Automation runbook to the appropriate resource group.
