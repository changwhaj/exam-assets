아마존 AWS 공인 시스템 운영 관리자 - 어소시에이트 시험 문제
문제 번호: 413
주제 번호: 1

한 회사가 AWS에 애플리케이션을 배포했습니다. 이 애플리케이션은 Auto Scaling 그룹에 속한 Linux 기반 Amazon EC2 인스턴스에서 실행됩니다. Auto Scaling 그룹은 시작 템플릿을 사용하도록 구성되어 있습니다. 시작 템플릿은 기본 스토리지로 gp3(General Purpose SSD) EBS 볼륨을 사용하는 Amazon EBS(Amazon Elastic Block Store) 기반 EC2 인스턴스를 시작합니다.

시스템 운영 관리자는 모든 EC2 인스턴스가 동일한 기본 파일을 공유할 수 있도록 하는 솔루션을 구현해야 합니다. 또한 이 솔루션은 데이터 일관성을 보장해야 합니다.

이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. Amazon Elastic File System(Amazon EFS) 파일 시스템을 생성합니다. EFS 파일 시스템을 마운트하는 사용자 데이터가 포함된 새 시작 템플릿 버전을 생성합니다. 새 시작 템플릿 버전을 사용하여 최신 EC2 인스턴스를 순환 배치하고 이전 EC2 인스턴스를 종료하도록 Auto Scaling 그룹을 업데이트합니다. 가장 많은 표를 받은
  • B. EBS 볼륨에서 멀티 어태치를 활성화합니다. EBS 볼륨을 마운트하는 사용자 데이터가 포함된 새 시작 템플릿 버전을 생성합니다. 새 템플릿 버전을 사용하여 최신 EC2 인스턴스를 순환적으로 추가하고 기존 EC2 인스턴스를 종료하도록 자동 스케일링 그룹을 업데이트합니다.
  • C. Auto Scaling 그룹에 속한 모든 EC2 인스턴스의 EBS 볼륨 간 데이터를 동기화하는 cron 작업을 생성합니다. 인스턴스 시작 시 모든 EC2 인스턴스에서 cron 작업을 구성하도록 라이프사이클 후크를 생성합니다. 오래된 EC2 인스턴스를 교체합니다.
  • D. Amazon Elastic File System(Amazon EFS) 파일 시스템을 생성하는 새로운 시작 템플릿 버전을 만듭니다. 새 템플릿 버전을 사용하여 최신 EC2 인스턴스를 순환 배치하고 이전 EC2 인스턴스를 종료하도록 Auto Scaling 그룹을 업데이트합니다.

Exam question from Amazon's AWS Certified SysOps Administrator - Associate
Question #: 413
Topic #: 1

A company has deployed an application on AWS. The application runs on a fleet of Linux Amazon EC2 instances that are in an Auto Scaling group. The Auto Scaling group is configured to use launch templates. The launch templates launch Amazon Elastic Block Store (Amazon EBS) backed EC2 instances that use General Purpose SSD (gp3) EBS volumes for primary storage.

A SysOps administrator needs to implement a solution to ensure that all the EC2 instances can share the same underlying files. The solution also must ensure that the data is consistent.

Which solution will meet these requirements?

  • A. Create an Amazon Elastic File System (Amazon EFS) file system. Create a new launch template version that includes user data that mounts the EFS file system. Update the Auto Scaling group to use the new launch template version to cycle in newer EC2 instances and to terminate the older EC2 instances. Most Voted
  • B. Enable Multi-Attach on the EBS volumes. Create a new launch template version that includes user data that mounts the EBS volume. Update the Auto Scaling group to use the new template version to cycle in newer EC2 instances and to terminate the older EC2 instances.
  • C. Create a cron job that synchronizes the data between the EBS volumes for all the EC2 instances in the Auto Scaling group. Create a lifecycle hook during instance launch to configure the cron job on all the EC2 instances. Rotate out the older EC2 instances.
  • D. Create a new launch template version that creates an Amazon Elastic File System (Amazon EFS) file system. Update the Auto Scaling group to use the new template version to cycle in newer EC2 instances and to terminate the older EC2 instances.
