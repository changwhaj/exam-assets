주제 번호: 1

한 회사가 온프레미스 DNS 솔루션을 사용하고 있으며, example.com 도메인의 DNS 레코드를 Amazon Route 53 프라이빗 호스팅 영역에서 확인하려고 합니다. 이 회사는 온프레미스 네트워크와 VPC 간의 네트워크 연결을 위해 AWS Direct Connect 연결을 설정했습니다. 시스템 운영 관리자는 온프레미스 서버가 example.com 도메인의 레코드를 조회할 수 있도록 해야 합니다.

시스템 운영 관리자는 이러한 요구 사항을 충족하기 위해 무엇을 해야 할까요?

  • A. Route 53 리졸버 인바운드 엔드포인트를 생성합니다. 온프레미스 DNS 서버에서 TCP/UDP 포트 53을 통한 인바운드 트래픽을 허용하도록 엔드포인트에 보안 그룹을 연결합니다. 가장 많은 표를 받은
  • B. Route 53 리졸버 인바운드 엔드포인트를 생성합니다. 해당 엔드포인트에 보안 그룹을 연결하여 TCP/UDP 포트 53을 통해 온프레미스 DNS 서버로 나가는 트래픽을 허용합니다.
  • C. Route 53 리졸버 아웃바운드 엔드포인트를 생성합니다. 온프레미스 DNS 서버에서 TCP/UDP 포트 53을 통해 들어오는 트래픽을 허용하도록 엔드포인트에 보안 그룹을 연결합니다.
  • D. Route 53 리졸버 아웃바운드 엔드포인트를 생성합니다. 해당 엔드포인트에 보안 그룹을 연결하여 TCP/UDP 포트 53을 통해 온프레미스 DNS 서버로의 아웃바운드 트래픽을 허용합니다.

Topic #: 1

A company has an on-premises DNS solution and wants to resolve DNS records in an Amazon Route 53 private hosted zone for example.com. The company has set up an AWS Direct Connect connection for network connectivity between the on-premises network and the VPC. A SysOps administrator must ensure that an on-premises server can query records in the example.com domain.

What should the SysOps administrator do to meet these requirements?

  • A. Create a Route 53 Resolver inbound endpoint. Attach a security group to the endpoint to allow inbound traffic on TCP/UDP port 53 from the on-premises DNS servers. Most Voted
  • B. Create a Route 53 Resolver inbound endpoint. Attach a security group to the endpoint to allow outbound traffic on TCP/UDP port 53 to the on-premises DNS servers.
  • C. Create a Route 53 Resolver outbound endpoint. Attach a security group to the endpoint to allow inbound traffic on TCP/UDP port 53 from the on-premises DNS servers.
  • D. Create a Route 53 Resolver outbound endpoint. Attach a security group to the endpoint to allow outbound traffic on TCP/UDP port 53 to the on-premises DNS servers.
