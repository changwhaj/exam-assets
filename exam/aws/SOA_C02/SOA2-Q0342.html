아마존 AWS 공인 시스템 운영 관리자 - 어소시에이트 시험 문제
문제 번호: 342
주제 번호: 1

한 회사가 아마존 EC2 인스턴스에서 고성능 컴퓨팅(HPC) 애플리케이션을 운영하고 있습니다. 이 회사는 이 아키텍처를 두 개 이상의 EC2 인스턴스로 확장해야 합니다. 애플리케이션을 지원하기 위해 EC2 인스턴스들은 높은 속도와 낮은 지연 시간으로 서로 통신해야 합니다.

회사는 네트워크 성능이 EC2 인스턴스 간 필요한 통신을 지원할 수 있도록 보장하고자 합니다.

이러한 요구 사항을 충족하기 위해 시스템 운영 관리자는 무엇을 해야 할까요?

  • A. 클러스터 배치 그룹을 생성합니다. 기존 EC2 인스턴스를 Amazon Machine Image(AMI)로 백업합니다. AMI에서 EC2 인스턴스를 배치 그룹으로 복원합니다. 추가 EC2 인스턴스를 배치 그룹에 시작합니다. 가장 많은 표를 받은
  • B. 기존 EC2 인스턴스를 Amazon Machine Image(AMI)로 백업합니다. 해당 AMI를 지정하여 기존 EC2 인스턴스에서 시작 템플릿을 생성합니다. Auto Scaling 그룹을 생성하고 원하는 인스턴스 수를 구성합니다.
  • C. 네트워크 로드 밸런싱(NLB)과 대상 그룹을 생성합니다. 새 EC2 인스턴스를 시작하고 대상 그룹에 등록합니다. 기존 EC2 인스턴스도 대상 그룹에 등록합니다. 모든 애플리케이션 트래픽이 NLB를 통해 전달되도록 합니다.
  • D. 기존 EC2 인스턴스를 Amazon Machine Image(AMI)로 백업합니다. 기존 EC2 인스턴스가 있는 동일한 가용 영역에 해당 AMI를 사용하여 EC2 인스턴스의 추가 복제본을 생성합니다.

Question #: 342
Topic #: 1

A company runs a high performance computing (HPC) application on an Amazon EC2 instance. The company needs to scale this architecture to two or more EC2 instances. The EC2 instances will need to communicate with each other at high speeds with low latency to support the application.

The company wants to ensure that the network performance can support the required communication between the EC2 instances

What should a SysOps administrator do to meet these requirements?

  • A. Create a cluster placement group. Back up the existing EC2 instance to an Amazon Machine Image (AMI). Restore the EC2 instance from the AMI into the placement group. Launch the additional EC2 instances into the placement group. Most Voted
  • B. Back up the existing EC2 instance to an Amazon Machine Image (AMI). Create a launch template from the existing EC2 instance by specifying the AMI. Create an Auto Scaling group and configure the desired instance count.
  • C. Create a Network Load Balancer (NLB) and a target group. Launch the new EC2 instances and register them with the target group. Register the existing EC2 instance with the target group. Pass all application traffic through the NLB.
  • D. Back up the existing EC2 instance to an Amazon Machine Image (AMI). Create additional clones of the EC2 instance from the AMI in the same Availability Zone where the existing EC2 instance is located.
