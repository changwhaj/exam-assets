문제 번호: 259
주제 번호: 1

시스템 운영 관리자는 데이터베이스 성능 분석을 담당하고 있습니다. 해당 데이터베이스는 단일 Amazon RDS DB 인스턴스에서 실행됩니다. 시스템 운영 관리자는 트래픽이 가장 많은 시간대에 읽기 트래픽 증가로 인해 데이터베이스 리소스가 과도하게 사용되는 것을 발견했습니다.

시스템 운영 관리자는 RDS 성능을 개선하기 위해 어떤 조치를 취해야 할까요? (두 가지를 선택하세요.)

  • A. 읽기 복제본을 추가합니다 . 가장 많은 표를 받은
  • B. Memcached에 Amazon ElastiCache를 사용하도록 애플리케이션을 수정합니다. 가장 많은 표를 받은
  • C. 데이터베이스를 RDS에서 Amazon DynamoDB로 마이그레이션합니다.
  • D. 향상된 네트워킹이 활성화된 Amazon EC2로 데이터베이스를 마이그레이션합니다.
  • E. 데이터베이스를 멀티 AZ 배포로 업그레이드합니다.

A SysOps administrator is tasked with analyzing database performance. The database runs on a single Amazon RDS DB instance. The SysOps administrator finds that, during times of peak traffic, resources on the database are overutilized due to the amount of read traffic.

Which actions should the SysOps administrator take to improve RDS performance? (Choose two.)

  • A. Add a read replica Most Voted
  • B. Modify the application to use Amazon ElastiCache for Memcached. Most Voted
  • C. Migrate the database from RDS to Amazon DynamoDB.
  • D. Migrate the database to Amazon EC2 with enhanced networking enabled.
  • E. Upgrade the database to a Multi-AZ deployment.

A. Adding a read replica can offload read traffic from the primary RDS instance to the replica, thus improving performance during times of peak traffic. B. Amazon ElastiCache for Memcached is an in-memory data store that can be used to improve read performance.
