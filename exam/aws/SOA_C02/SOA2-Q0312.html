문제 번호: 312
주제 번호: 1

시스템 운영 관리자는 AWS CloudFormation 템플릿으로 생성된 Amazon RDS 데이터베이스의 자격 증명을 보호해야 합니다. 이 솔루션은 자격 증명을 암호화하고 자동 자격 증명 순환 기능을 지원해야 합니다.

이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. CloudFormation 템플릿에 AWS::SecretsManager::Secret 리소스를 생성합니다. AWS::RDS::DBInstance 리소스에서 resolve:secretsmanager 동적 참조를 사용하여 자격 증명을 참조합니다. 가장 많은 표를 받은
  • B. CloudFormation 템플릿에 AWS::SecretsManager::Secret 리소스를 생성합니다. resolve:ssm-secure 동적 참조를 사용하여 AWS::RDS::DBInstance 리소스에서 자격 증명을 참조합니다.
  • C. CloudFormation 템플릿에 AWS::SSM::Parameter 리소스를 생성합니다. resolve:ssm 동적 참조를 사용하여 AWS::RDS::DBInstance 리소스에서 자격 증명을 참조합니다.
  • D. CloudFormation 템플릿에서 데이터베이스 자격 증명에 대한 매개변수를 생성합니다. Ref 내장 함수를 사용하여 AWS::RDS::DBInstance 리소스에 자격 증명을 제공합니다.

Which solution will meet these requirements?

  • A. Create an AWS::SecretsManager::Secret resource in the CloudF ormation template. Reference the credentials in the AWS::RDS::DBInstance resource by using the resolve:secretsmanager dynamic reference. Most Voted
  • B. Create an AWS::SecretsManager::Secret resource in the CloudFormation template. Reference the credentials in the AWS::RDS::DBInstance resource by using the resolve:ssm-secure dynamic reference.
  • C. Create an AWS::SSM::Parameter resource in he CloudFormation template. Reference the credentias in the AWS::RDS::DBInstance resource by using the resolve:ssm dynamic reference.
  • D. Create parameters for the database credentials in the CloudFormation template. Use the Ref intrinsic function to provide the credentials to the AWS::RDS::DBInstance resource.
