한 회사가 A 계정에 AWS Lambda 함수를 보유하고 있습니다. 이 Lambda 함수는 B 계정에 있는 Amazon S3 버킷의 객체를 읽어야 합니다. 시스템 운영 관리자는 두 계정 모두에 해당하는 IAM 역할을 생성해야 합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. 계정 A에서 계정 B의 역할을 수임할 수 있는 Lambda 실행 역할을 생성합니다. 계정 B에서 해당 함수가 S3 버킷에 접근할 수 있도록 수임할 역할을 생성합니다. 가장 많은 표를 받은
  • B. 계정 A에서 S3 버킷에 대한 액세스 권한을 제공하는 Lambda 실행 역할을 생성합니다. 계정 B에서 해당 함수가 사용할 수 있는 역할을 생성합니다.
  • C. 계정 A에서 함수가 사용할 수 있는 역할을 생성합니다. 계정 B에서 S3 버킷에 대한 액세스 권한을 제공하는 Lambda 실행 역할을 생성합니다.
  • D. 계정 A에서 함수가 S3 버킷에 접근할 수 있도록 역할을 생성합니다. 계정 B에서 계정 A의 역할을 수임하는 Lambda 실행 역할을 생성합니다.

A company has an AWS Lambda function in Account A. The Lambda function needs to read the objects in an Amazon S3 bucket in Account B. A SysOps administrator must create corresponding IAM roles in both accounts.
Which solution will meet these requirements?

  • A. In Account A, create a Lambda execution role to assume the role in Account B. In Account B. create a role that the function can assume to gain access to the S3 bucket. Most Voted
  • B. In Account A, create a Lambda execution role that provides access to the S3 bucket. In Account B, create a role that the function can assume.
  • C. In Account A, create a role that the function can assume. In Account B, create a Lambda execution role that provides access to the S3 bucket.
  • D. In Account A. create a role that the function can assume to gain access to the S3 bucket. In Account B, create a Lambda execution role to assume the role in Account A.
