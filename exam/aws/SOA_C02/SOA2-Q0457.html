아마존 AWS 공인 시스템 운영 관리자 - 어소시에이트 시험 문제
문제 번호: 457
주제 번호: 1

ServiceNow를 사용하는 한 회사가 민감한 워크로드가 실행되는 AWS 계정을 보유하고 있습니다. 필요한 보안 그룹은 이미 설정되어 있습니다. 이 회사는 보안 그룹의 규칙이 변경될 때마다 ServiceNow에 인시던트를 생성하는 솔루션을 구현해야 합니다.

운영 노력을 최소화하면서 이 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. 보안 그룹이 변경될 때 ALARM 상태로 전환되는 Amazon CloudWatch 알람을 생성합니다. 해당 알람이 ServiceNow에 연결하여 인시던트를 생성하는 AWS Lambda 함수를 호출하도록 구성합니다.
  • B. AWS Security Hub를 활성화합니다. ServiceNow에 연결하여 인시던트를 생성하는 AWS Lambda 함수를 생성합니다. 보안 그룹 변경 사항을 감지하는 Amazon EventBridge 규칙을 생성합니다. 이벤트 유형을 Security Hub 발견 사항 - 사용자 지정 작업으로 구성합니다. EventBridge 규칙이 Lambda 함수를 호출하도록 구성합니다.
  • C. 보안 그룹 변경을 감지하는 Amazon EventBridge 규칙을 생성합니다. 이벤트 유형을 CloudTrail을 통한 AWS API 호출로 구성합니다. EventBridge 규칙이 AWS Systems Manager 자동화 런북인 AWS-CreateServiceNowIncident를 실행하여 ServiceNow에 인시던트를 생성하도록 구성합니다. 가장 많은 표를 받은
  • D. 보안 그룹 변경 사항을 감지하기 위해 ServiceNow에 영구적으로 연결된 Amazon EC2 인스턴스를 시작합니다. AWS CloudTrail 로그를 EC2 인스턴스로 내보냅니다. 30분마다 실행되도록 예약된 cron 작업을 수행하는 bash 스크립트를 작성하여 CloudTrail 로그에서 보안 그룹 변경 사항을 검색합니다. 변경 사항이 감지되면 ServiceNow에 인시던트를 생성하도록 EC2 인스턴스를 구성합니다.

A company that uses ServiceNow has an AWS account where a sensitive workload runs. The necessary security groups are in place. The company needs to implement a solution to create an incident in ServiceNow every time the rules change in any security group.

Which solution will meet this requirement with the LEAST operational effort?

  • A. Create an Amazon CloudWatch alarm that enters ALARM state when security groups change. Configure the alarm to invoke an AWS Lambda function that connects to ServiceNow to create an incident.
  • B. Enable AWS Security Hub. Create an AWS Lambda function that connects to ServiceNow to create an incident. Create an Amazon EventBridge rule to detect security group changes. Configure the event type as Security Hub Findings - Custom Action. Configure the EventBridge rule to invoke the Lambda function.
  • C. Create an Amazon EventBridge rule to detect security group changes. Configure the event type as AWS API Call via CloudTrail. Configure the EventBridge rule to run the AWS-CreateServiceNowIncidentAWS Systems Manager Automation runbook to create an incident in ServiceNow. Most Voted
  • D. Launch an Amazon EC2 instance that has a persistent connection to ServiceNow to detect security group changes. Export AWS CloudTrail logs to the EC2 instance. Write a bash script to run a scheduled cron job every 30 minutes to search the CloudTrail logs for security groups changes. Configure the EC2 instance to create an incident in ServiceNow when a change is detected.
