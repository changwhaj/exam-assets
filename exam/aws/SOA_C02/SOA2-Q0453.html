주제 번호: 1

한 회사가 AWS 계정의 지출을 추적해야 합니다. 현재 비용과 예상 비용이 특정 임계값을 초과할 경우 알림을 받아야 합니다.

이러한 요구 사항을 충족하면서 운영 오버헤드를 최소화하는 솔루션은 무엇일까요?

  • A. 새 IAM 역할을 생성합니다. 해당 역할에 AWSPurchaseOrdersServiceRolePolicy AWS 관리형 정책을 연결합니다. AWS Cost Explorer를 정기적으로 확인하여 현재 비용과 예상 비용을 모니터링하십시오.
  • B. AWS 비용 및 사용량 보고서를 생성합니다. 새 사용량 파일이 생성될 때 실행되는 AWS Step Functions 상태 머신을 생성합니다. 상태 머신이 데이터를 Amazon Forecast로 전달하고 AWS Lambda 함수를 호출하도록 구성합니다. Lambda 함수가 데이터를 구문 분석하고 비용이 임계값을 초과하는 경우 Amazon Simple Notification Service(Amazon SNS) 토픽으로 알림을 보내도록 구성합니다.
  • C. AWS 비용 및 사용량 보고서를 생성합니다. 현재 비용과 예상 비용을 서비스별로 구분합니다. 매월 Amazon SNS(Amazon Simple Notification Service) 토픽으로 보고서가 전송되도록 예약합니다.
  • D. AWS Budgets에서 반복 비용 예산을 생성합니다. 실제 비용에 대한 알림을 생성합니다. 예상 비용에 대한 두 번째 알림을 생성합니다. Amazon Simple Notification Service(Amazon SNS) 토픽을 구성하여 알림을 수신하도록 합니다. 가장 많은 표를 받은

A company needs to track spending in its AWS account. The company must receive a notification when current costs and forecasted costs exceed specific thresholds.

Which solution will meet these requirements with the LEAST operational overhead?

  • A. Create a new IAM role. Attach the AWSPurchaseOrdersServiceRolePolicy AWS managed policy to the role. Check AWS Cost Explorer on a regular basis to monitor current costs and forecasted costs.
  • B. Create an AWS Cost and Usage Report. Create an AWS Step Functions state machine that runs when a new usage file is generated. Configure the state machine to pass the data to Amazon Forecast and to invoke an AWS Lambda function. Configure the Lambda function to parse the data and to send a notification to an Amazon Simple Notification Service (Amazon SNS) topic if costs exceed the thresholds.
  • C. Create an AWS Cost and Usage Report. Separate the current costs and forecasted costs by service. Schedule the report to be sent to an Amazon Simple Notification Service (Amazon SNS) topic each month.
  • D. Create a recurring cost budget in AWS Budgets. Create an alert for the actual cost. Create a second alert for the forecasted costs. Configure an Amazon Simple Notification Service (Amazon SNS) topic to receive the alerts. Most Voted
