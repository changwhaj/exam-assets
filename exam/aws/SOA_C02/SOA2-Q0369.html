A company has an encrypted Amazon S3 bucket that is hosted in the ap-southeast-2 Region. Users from the eu-west-2 Region access the S3 bucket over the internet. The users from eu-west-2 need faster transfers to and from the S3 bucket for large files.

Which solution will meet these requirements?

  • A. Reduce the length of the S3 bucket prefixes within the S3 bucket.
  • B. Change the server-side encryption on the S3 bucket from AES to RSA.
  • C. Create a new S3 bucket that has an identical name in eu-west-2. Use the new S3 bucket endpoint's domain name for access.
  • D. Enable S3 Transfer Acceleration on the S3 bucket. Use the new s3-accelerate endpoint's domain name for access. Most Voted

D: S3 전송 가속은 Amazon CloudFront 글로벌 네트워크를 사용하여 S3 버킷으로의 업로드 및 다운로드 속도를 향상시킵니다. 이는 특히 장거리 또는 여러 리전으로 데이터를 전송할 때 유용합니다. 전송 가속을 활성화하면 데이터는 Amazon CloudFront의 최적화된 네트워크 경로를 통해 S3로 전송되어 업로드 및 다운로드 속도가 향상됩니다. 사용자는 전송 가속 전용 엔드포인트를 사용하여 버킷에 액세스할 수 있으며, 데이터는 가속된 네트워크를 통해 자동으로 전송됩니다. https://docs.aws.amazon.com/AmazonS3/latest/userguide/transfer-acceleration.html

D: S3 Transfer Acceleration uses the Amazon CloudFront global network to accelerate uploads to and downloads from an S3 bucket. This is especially useful when transferring data over long distances or across regions. By enabling Transfer Acceleration, data will be routed through Amazon CloudFront's optimized network paths to S3, providing faster upload and download speeds. Users can use the special endpoint for Transfer Acceleration to access the bucket, and data will be automatically routed through the accelerated network. https://docs.aws.amazon.com/AmazonS3/latest/userguide/transfer-acceleration.html
