주제 번호: 1

한 회사가 AWS 계정의 Amazon DynamoDB 테이블에 태깅 요구 사항을 적용해야 합니다. 시스템 운영 관리자는 적절한 태그가 없는 모든 DynamoDB 테이블을 식별하고 수정하는 솔루션을 구현해야 합니다.

이러한 요구 사항을 충족하면서 운영 오버헤드를 최소화하는 솔루션은 무엇일까요?

  • A. 모든 DynamoDB 테이블을 평가하고 수정하는 사용자 지정 AWS Lambda 함수를 생성합니다. 해당 Lambda 함수를 호출하도록 Amazon EventBridge 예약 규칙을 생성합니다.
  • B. 모든 DynamoDB 테이블을 평가하고 수정하는 사용자 지정 AWS Lambda 함수를 생성합니다. Lambda 함수를 호출하는 AWS Config 사용자 지정 규칙을 생성합니다.
  • C. 필수 태그가 포함된 AWS Config 관리형 규칙을 사용하여 모든 DynamoDB 테이블에서 적절한 태그를 확인합니다. AWS
    Systems Manager Automation 사용자 지정 런북을 사용하는 자동 복구 작업을 구성합니다. 가장 많은 표를 받은
  • D. 모든 DynamoDB 테이블에서 적절한 태그를 평가하는 Amazon EventBridge 관리형 규칙을 생성합니다.
    문제 해결을 위해 AWS Systems Manager Automation 사용자 지정 런북을 실행하도록 EventBridge 규칙을 구성합니다.

Selected Answer: C
Checks if your resources have the tags that you specify. For example, you can check whether your Amazon EC2 instances have the CostCenter tag, while also checking if all your RDS instance have one set of Keys tag. Separate multiple values with commas. You can check up to 6 tags at a time. The AWS-managed AWS Systems Manager automation document AWS-SetRequiredTags does not work as a remediation with this rule. You will need to create your own custom Systems Manager automation documentation for remediation.
