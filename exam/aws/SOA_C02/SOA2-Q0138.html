아마존 AWS 공인 시스템 운영 관리자 - 어소시에이트 시험 문제
문제 번호: 138
주제 번호: 1

한 회사가 Elastic Load Balancer(ELB) 뒤의 Amazon EC2 인스턴스에서 공개 웹 애플리케이션을 운영할 계획입니다. 회사 보안팀은 AWS Certificate Manager(ACM) 인증서를 사용하여 웹사이트를 보호하고자 합니다. ELB는 모든 HTTP 요청을 자동으로 HTTPS로 리디렉션해야 합니다.

이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. 포트 80에서 HTTPS 수신 대기열을 하나 갖는 애플리케이션 로드 밸런서를 생성합니다. 수신 대기열 포트 80에 SSL/TLS 인증서를 연결합니다. HTTP 요청을 HTTPS로 리디렉션하는 규칙을 생성합니다.
  • B. HTTP 리스너 하나(80번 포트)와 HTTPS 프로토콜 리스너 하나(443번 포트)를 갖는 애플리케이션 로드 밸런서를 생성합니다. 리스너 443번 포트에 SSL/TLS 인증서를 연결합니다. 80번 포트로 들어오는 요청을 443번 포트로 리디렉션하는 규칙을 생성합니다. 가장 많은 표를 받은
  • C. 포트 80과 포트 443에 TCP 리스너 두 개를 갖는 애플리케이션 로드 밸런서를 생성합니다. 리스너 포트 443에 SSL/TLS 인증서를 연결합니다. 포트 80으로 들어오는 요청을 포트 443으로 리디렉션하는 규칙을 생성합니다.
  • D. 포트 80과 포트 443에 TCP 리스너 두 개를 갖는 네트워크 로드 밸런서를 생성합니다. 리스너 포트 443에 SSL/TLS 인증서를 연결합니다. 포트 80으로 들어오는 요청을 포트 443으로 리디렉션하는 규칙을 생성합니다.

A company plans to run a public web application on Amazon EC2 instances behind an Elastic Load Balancer (ELB). The company’s security team wants to protect the website by using AWS Certificate Manager (ACM) certificates. The ELB must automatically redirect any HTTP requests to HTTPS.

Which solution will meet these requirements?

  • A. Create an Application Load Balancer that has one HTTPS listener on port 80. Attach an SSL/TLS certificate to listener port 80. Create a rule to redirect requests from HTTP to HTTPS.
  • B. Create an Application Load Balancer that has one HTTP listener on port 80 and one HTTPS protocol listener on port 443. Attach an SSL/TLS certificate to listener port 443. Create a rule to redirect requests from port 80 to port 443. Most Voted
  • C. Create an Application Load Balancer that has two TCP listeners on port 80 and port 443. Attach an SSL/TLS certificate to listener port 443. Create a rule to redirect requests from port 80 to port 443.
  • D. Create a Network Load Balancer that has two TCP listeners on port 80 and port 443. Attach an SSL/TLS certificate to listener port 443. Create a rule to redirect requests from port 80 to port 443.
