아마존 AWS 공인 시스템 운영 관리자 - 어소시에이트 시험 문제
문제 번호: 296
주제 번호: 1

한 회사가 여러 가용 영역에 걸쳐 Amazon EC2 인스턴스 클러스터에 Windows 기반 파일 서버를 운영하고 있습니다. 현재 설정으로는 애플리케이션 서버들이 EC2 클러스터의 파일에 동시에 접근할 수 없습니다.

어떤 솔루션이 가장 운영 효율적인 방식으로 이러한 접근을 허용할까요?

  • A. Amazon Elastic File System(Amazon EFS) 멀티 AZ 파일 시스템을 생성합니다. 파일을 EFS 파일 시스템에 복사합니다. EFS 파일 시스템을 애플리케이션 서버의 마운트 지점에 연결합니다.
  • B. Amazon FSx for Windows File Server Multi-AZ 파일 시스템을 생성합니다. 파일을 Amazon FSx 파일 시스템에 복사합니다. 애플리케이션 서버에서 Amazon FSx 파일 시스템이 제공하는 공유 폴더를 사용하도록 연결을 조정합니다. 가장 많은 표를 받은
  • C. EBS 멀티 어태치가 활성화된 Amazon Elastic Block Store(Amazon EBS) 볼륨을 생성합니다. Windows 파일 서버용 Auto Scaling 그룹을 생성합니다. 파일 서버 사용자 데이터에 있는 스크립트를 사용하여 시작 시 EBS 볼륨에 SharedFileAccess 태그를 연결합니다.
  • D. Amazon FSx for Windows File Server 파일 시스템 두 개를 생성합니다. 파일 시스템 간에 분산 파일 시스템(DFS) 복제를 구성합니다. 파일을 Amazon FSx 파일 시스템으로 복사합니다. 애플리케이션 서버에서 Amazon FSx 파일 시스템이 제공하는 공유 폴더를 사용하도록 연결을 조정합니다.

Topic #: 1

A company hosts a Windows-based file server on a fleet of Amazon EC2 instances across multiple Availability Zones. The current setup does not allow application servers to access files simultaneously from the EC2 fleet.

Which solution will allow this access in the MOST operationally efficient way?

  • A. Create an Amazon Elastic File System (Amazon EFS) Multi-AZ file system. Copy the files to the EFS file system. Connect the EFS file system to mount points on the application servers.
  • B. Create an Amazon FSx for Windows File Server Multi-AZ file system. Copy the files to the Amazon FSx file system. Adjust the connections from the application servers to use the share that the Amazon FSx file system exposes. Most Voted
  • C. Create an Amazon Elastic Block Store (Amazon EBS) volume that has EBS Multi-Attach enabled. Create an Auto Scaling group for the Windows file server. Use a script in the file server's user data to attach the SharedFileAccess tag to the EBS volume during launch.
  • D. Create two Amazon FSx for Windows File Server file systems. Configure Distributed File System (DFS) replication between the file systems. Copy the files to the Amazon FSx file systems. Adjust the connections from the application servers to use the shares that the Amazon FSx file systems expose.
