문제 번호: 117
주제 번호: 1

한 회사가 AWS 계정 내에서 IAM CreateUser API 호출이 발생할 때 이메일 알림을 받고 싶어합니다.

시스템 운영 관리자는 이 요구 사항을 충족하기 위해 어떤 조치를 취해야 할까요? (두 가지를 선택하세요.)

  • A. AWS CloudTrail을 이벤트 소스로, IAM CreateUser를 이벤트 패턴에 대한 특정 API 호출로 사용하여 Amazon EventBridge(Amazon CloudWatch Events) 규칙을 생성합니다. 가장 많은 표를 받은
  • B. Amazon CloudSearch를 이벤트 소스로, IAM CreateUser를 이벤트 패턴에 대한 특정 API 호출로 사용하여 Amazon EventBridge(Amazon CloudWatch Events) 규칙을 생성합니다.
  • C. AWS IAM Access Analyzer를 이벤트 소스로, IAM CreateUser를 이벤트 패턴의 특정 API 호출로 사용하여 Amazon EventBridge(Amazon CloudWatch Events) 규칙을 생성합니다.
  • D. 이메일 구독을 통해 이벤트 대상으로 Amazon Simple Notification Service(Amazon SNS) 토픽을 사용합니다. 가장 많은 표를 받은
  • E. 이메일 구독을 통해 Amazon Simple Email Service(Amazon SES) 알림을 이벤트 대상으로 사용합니다.
