아마존 AWS 공인 시스템 운영 관리자 - 어소시에이트 시험 문제
문제 번호: 59
주제 번호: 1

한 회사가 애플리케이션 로드 밸런서(ALB) 뒤에 있는 여러 Amazon EC2 인스턴스에서 소매 웹사이트를 운영하고 있습니다. 이 회사는 웹사이트로 들어오는 트래픽을 HTTPS 연결을 통해 보호해야 합니다.
이러한 요구 사항을 충족하기 위해 시스템 운영 관리자는 어떤 조치를 취해야 할까요? (두 가지를 선택하세요.)

  • A. 각 EC2 인스턴스에 인증서를 연결하십시오.
  • B. 인증서를 ALB에 첨부하십시오. 가장 많은 표를 받은
  • C. AWS Certificate Manager(ACM)에서 개인 인증서를 생성합니다.
  • D. AWS Certificate Manager(ACM)에서 공개 인증서를 생성합니다. 가장 많은 표를 받은
  • E. 인증서를 내보내고 웹사이트에 첨부합니다.

Which combination of actions should a SysOps administrator take to meet these requirements? (Choose two.)

  • B. Attach the certificate to the ALB. Most Voted
  • C. Create a private certificate in AWS Certificate Manager (ACM).
  • D. Create a public certificate in AWS Certificate Manager (ACM). Most Voted
  • E. Export the certificate, and attach it to the website.
