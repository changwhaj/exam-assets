아마존 AWS 공인 시스템 운영 관리자 - 어소시에이트 시험 문제
문제 번호: 124
주제 번호: 1

시스템 운영 관리자는 파일이 Amazon S3 버킷에 업로드될 때마다 이메일 알림을 보내고 데이터베이스에 기록을 삽입하는 솔루션을 개발해야 합니다.

이러한 요구 사항을 충족하는 가장 운영 효율적인 솔루션은 무엇일까요?

  • A. Amazon Simple Notification Service(Amazon SNS) 토픽을 대상으로 하는 S3 이벤트 알림을 설정합니다. SNS 토픽에 대한 구독을 두 개 생성합니다. 하나는 이메일 알림을 보내는 데 사용하고, 다른 하나는 데이터베이스에 레코드를 삽입하는 AWS Lambda 함수를 호출하는 데 사용합니다. 가장 많은 표를 받은
  • B. S3 버킷에 객체가 생성될 때마다 ALARM 상태로 전환되는 Amazon CloudWatch 알람을 설정합니다. 알람이 발생하면 이메일 알림을 보내고 데이터베이스에 레코드를 삽입하는 AWS Lambda 함수를 호출하도록 구성합니다.
  • C. S3 버킷에서 새 객체가 감지될 때마다 이메일 알림을 보내고 데이터베이스에 레코드를 삽입하는 AWS Lambda 함수를 생성합니다. Amazon EventBridge(Amazon CloudWatch Events) 예약 규칙을 사용하여 매분마다 해당 함수를 호출합니다.
  • D. S3 이벤트 알림을 두 개 설정합니다. 각 알림에 대해 별도의 AWS Lambda 함수를 지정합니다. 한 함수는 이메일 알림을 보내도록 구성하고, 다른 함수는 데이터베이스에 레코드를 삽입하도록 구성합니다.

A SysOps administrator needs to develop a solution that provides email notification and inserts a record into a database every time a file is put into an Amazon S3 bucket.

What is the MOST operationally efficient solution that meets these requirements?

  • A. Set up an S3 event notification that targets an Amazon Simple Notification Service (Amazon SNS) topic. Create two subscriptions for the SNS topic. Use one subscription to send the email notification. Use the other subscription to invoke an AWS Lambda function that inserts the record into the database. Most Voted
  • B. Set up an Amazon CloudWatch alarm that enters ALARM state whenever an object is created in the S3 bucket. Configure the alarm to invoke an AWS Lambda function that sends the email notification and inserts the record into the database.
  • C. Create an AWS Lambda function to send the email notification and insert the record into the database whenever a new object is detected in the S3 bucket. Invoke the function every minute with an Amazon EventBridge (Amazon CloudWatch Events) scheduled rule.
  • D. Set up two S3 event notifications. Target a separate AWS Lambda function with each notification. Configure one function to send the email notification. Configure the other function to insert the record into the database.
