아마존 AWS 공인 클라우드 운영 엔지니어 - 어소시에이트 SOA-C03 시험 문제
문제 번호: 51
주제 번호: 1

개발자가 Amazon Linux AMI(Amazon Machine Image)를 사용하여 타사 애플리케이션을 호스팅하는 EC2 인스턴스를 시작합니다. 해당 애플리케이션은 간헐적으로 불안정해집니다. 클라우드 운영 엔지니어는 인스턴스 사용률이 15분 동안 90%를 초과할 경우 자동으로 EC2 인스턴스를 재부팅하고 개발자에게 재부팅 사실을 알리는 솔루션이 필요합니다.
이러한 요구 사항을 충족하면서 관리 노력이 가장 적은 솔루션은 무엇일까요?

  • A. 인스턴스의 CPU 사용률을 평가하는 Amazon CloudWatch 알람을 구성합니다. CloudWatch 알람이 활성화되면 AWS Lambda 함수를 호출하여 Amazon Simple Notification Service(Amazon SNS) 토픽에 메시지를 게시하도록 구성합니다. Lambda 함수가 EC2 인스턴스를 재부팅하도록 구성합니다. 개발자를 SNS 토픽에 구독합니다.
  • B. 인스턴스의 CPU 사용률을 평가하는 Amazon CloudWatch 알람을 생성합니다. 알람이 Amazon Simple Notification Service(Amazon SNS) 토픽에 알림을 게시하고 인스턴스를 재부팅하는 EC2 작업을 수행하도록 구성합니다. 개발자를 SNS 토픽에 구독합니다.
  • C. 인스턴스의 CPU 사용률을 평가하는 Amazon CloudWatch 알람을 생성합니다. 알람이 AWS Systems Manager 작업을 호출하여 개발자에게 알림을 보내고 재부팅을 요청하는 인시던트를 생성하도록 구성합니다.
  • D. AWS Systems Manager 런북 스크립트를 생성하여 Amazon Simple Notification Service(Amazon SNS) 토픽에 메시지를 게시하고 EC2 인스턴스를 재부팅합니다. 개발자 계정을 SNS 토픽에 구독합니다. 인스턴스의 CPU 사용률이 15분 이상 90%를 초과하면 Systems Manager 런북이 실행되도록 Amazon CloudWatch 알람을 구성합니다.

Exam question from Amazon's AWS Certified CloudOps Engineer - Associate SOA-C03
Question #: 51
Topic #: 1

A developer uses an Amazon Linux Amazon Machine Image (AMI) to launch an EC2 instance that hosts a third-party application. The application occasionally becomes unstable. The CloudOps engineer needs a solution to automatically reboot the EC2 instance whenever utilization is above 90% for 15 minutes and to notify the developer about the reboot.
Which solution will meet these requirements with the LEAST administrative effort?

  • A. Configure an Amazon CloudWatch alarm that evaluates the CPU utilization of the instance. Configure the alarm to invoke an AWS Lambda function to publish a message to an Amazon Simple Notification Service (Amazon SNS) topic when the CloudWatch alarm activates. Configure the Lambda function to reboot the EC2 instance. Subscribe the developer to the SNS topic.
  • B. Create an Amazon CloudWatch alarm that evaluates the CPU utilization of the instance. Configure the alarm to publish a notification to an Amazon Simple Notification Service (Amazon SNS) topic and to perform an EC2 action to reboot the instance. Subscribe the developer to the SNS topic.
  • C. Create an Amazon CloudWatch alarm that evaluates the CPU utilization of the instance Configure the alarm to invoke an AWS Systems Manager action to create an incident to notify the developer and request the reboot.
  • D. Create an AWS Systems Manager runbook script to publish a message to an Amazon Simple Notification Service (Amazon SNS) topic and to reboot the EC2 instance. Subscribe the developer to the SNS topic. Configure an Amazon CloudWatch alarm to run the Systems Manager runbook when CPU utilization for the instance remains above 90% for more than 15 minutes.
