아마존 AWS 공인 클라우드 운영 엔지니어 - 어소시에이트 SOA-C03 시험 문제
문제 번호: 58
주제 번호: 1

한 회사의 보안 정책에 따라 수신 SSH 트래픽은 지정된 주소 집합으로 제한되어야 합니다. 이 회사는 AWS Config 규칙을 사용하여 보안 그룹이 제한 없는 수신 SSH 트래픽을 허용하는지 여부를 확인합니다. 클라우드 운영
엔지니어가 규정을 준수하지 않는 리소스를 발견하고 보안 그룹을 수동으로 수정했습니다. 이제 클라우드 운영 엔지니어는 규정을 준수하지 않는 다른 리소스에 대한 수정 작업을 자동화하려고 합니다.
이러한 요구 사항을 충족하는 가장 운영 효율적인 솔루션은 무엇일까요?

  • A. AWS Config 규칙의 상태 메트릭에 대한 Amazon CloudWatch 알람을 생성합니다. 보안 그룹에서 규정을 준수하지 않는 규칙을 제거할 수 있는 AWS Lambda 함수를 생성합니다. 알람 작업이 Lambda 함수를 호출하도록 구성합니다.
  • B. AWS Config 규칙에 자동 복구 작업을 구성합니다. AWS-DisabloncomingSSHOnPort22 복구 작업을 지정합니다.
  • C. AWS Config 구성 항목 변경 이벤트에 대한 Amazon EventBridge 규칙을 구성합니다. 보안 그룹에서 규정을 준수하지 않는 규칙을 제거할 수 있는 AWS Lambda 함수를 생성하고,
    해당 Lambda 함수를 호출하도록 규칙을 구성합니다.
  • D. 보안 그룹의 인바운드 규칙을 분석하여 무제한 SSH 액세스 여부를 확인하는 AWS Lambda 함수를 생성합니다. Lambda 함수가 보안 그룹에서 규정을 준수하지 않는 규칙을 제거하도록 구성합니다. Amazon EventBridge 규칙을 구성하여 Lambda 함수를 매시간 호출하도록 합니다.

A company's security policy requires incoming SSH traffic to be restricted to a defined set of addresses. The company is using an AWS Config rule to check whether security groups allow unrestricted incoming SSH traffic.
A CloudOps engineer discovers a noncompliant resource and fixes the security group manually. The CloudOps engineer wants to automate the remediation of other noncompliant resources.
What is the MOST operationally efficient solution that meets these requirements?

  • A. Create an Amazon CloudWatch alarm for the AWS Config rule's status metric. Create an AWS Lambda function that can remove the noncompliant rule from the security group. Configure the alarm action to invoke the Lambda function.
  • B. Configure an automatic remediation action on the AWS Config rule. Specify the AWS-DisablolncomingSSHOnPort22 remediation action.
  • C. Configure an Amazon EventBridge rule for AWS Config configuration item change events. Create an AWS Lambda function that can remove the noncompliant rule from the security group
    Configure the rule to invoke the Lambda function.
  • D. Create an AWS Lambda function that can analyze a security group’s inbound rules to check for unrestricted SSH access. Configure the Lambda function to remove the noncompliant rule from the security group. Configure an Amazon EventBridge rule to invoke the Lambda function every hour.
