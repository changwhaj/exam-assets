데이터 과학자는 Amazon SageMaker를 사용하여 기계 학습(ML) 모델을 배포합니다. 데이터 과학자는 SageMaker 엔드포인트의 모델로부터 추론을 얻으려고 합니다. 그러나 데이터 과학자가 SageMaker 엔드포인트를 호출하려고 하면 데이터 과학자는 SQL 문 오류를 수신합니다. 데이터 과학자의 IAM 사용자는 현재 SageMaker 엔드포인트를 호출할 수 없습니다.

데이터 과학자의 IAM 사용자에게 SageMaker 엔드포인트를 호출할 수 있는 기능을 제공하는 작업 조합은 무엇입니까? (3개를 선택하세요.)

  • A. AmazonAthenaFullAccess AWS 관리형 정책을 사용자 자격 증명에 연결합니다.
  • B. IAM 사용자가 sagemaker:InvokeEndpoint 작업을 수행할 수 있도록 허용하는 데이터 과학자의 IAM 사용자에 대한 정책 설명을 포함합니다. 최다 투표
  • C. SageMaker가 S3 객체를 읽을 수 있도록 허용하는 데이터 과학자의 IAM 사용자를 위한 인라인 정책을 포함합니다. 최다 투표
  • D. IAM 사용자가 sagemaker:GetRecord 작업을 수행할 수 있도록 허용하는 데이터 과학자의 IAM 사용자에 대한 정책 설명을 포함합니다.
  • E. Athena SQL 쿼리에 "USING EXTERNAL FUNCTION ml_function_name"이라는 SQL 문을 포함합니다. 최다 투표
  • F. SageMaker에서 사용자 재매핑을 수행하여 IAM 사용자를 호스팅 엔드포인트에 있는 다른 IAM 사용자에 매핑합니다.

Exam question from Amazon's AWS Certified Machine Learning - Specialty
Question #: 293
Topic #: 1

A data scientist stores financial datasets in Amazon S3. The data scientist uses Amazon Athena to query the datasets by using SQL.

The data scientist uses Amazon SageMaker to deploy a machine learning (ML) model. The data scientist wants to obtain inferences from the model at the SageMaker endpoint. However, when the data scientist attempts to invoke the SageMaker endpoint, the data scientist receives SQL statement failures. The data scientist’s IAM user is currently unable to invoke the SageMaker endpoint.

Which combination of actions will give the data scientist’s IAM user the ability to invoke the SageMaker endpoint? (Choose three.)

  • A. Attach the AmazonAthenaFullAccess AWS managed policy to the user identity.
  • B. Include a policy statement for the data scientist's IAM user that allows the IAM user to perform the sagemaker:InvokeEndpoint action. Most Voted
  • C. Include an inline policy for the data scientist’s IAM user that allows SageMaker to read S3 objects. Most Voted
  • D. Include a policy statement for the data scientist’s IAM user that allows the IAM user to perform the sagemaker:GetRecord action.
  • E. Include the SQL statement "USING EXTERNAL FUNCTION ml_function_name'' in the Athena SQL query. Most Voted
  • F. Perform a user remapping in SageMaker to map the IAM user to another IAM user that is on the hosted endpoint.
