주제 번호: 1

한 은행이 10년 동안 CSV 형식으로 고객 데이터를 수집해 왔습니다. 은행은 이 데이터를 사내 서버에 저장하고 있습니다. 데이터 과학 팀은 Amazon SageMaker를 사용하여 고객 이탈 확률을 예측하는 머신러닝(ML) 모델을 구축하고 학습시키려고 합니다. 이 팀은 과거 데이터를 활용할 예정입니다. 데이터 과학자들은 모델을 실제 운영 환경에 배포하기 전에 데이터 변환을 신속하게 수행하고 데이터에서 유용한 인사이트를 도출하고자 합니다.

이러한 요구 사항을 충족하면서 개발 노력이 가장 적게 드는 솔루션은 무엇일까요?

  • A. 데이터를 SageMaker Data Wrangler 콘솔에 직접 업로드합니다. Data Wrangler 내에서 데이터 변환을 수행하고 인사이트를 생성합니다.
  • B. 데이터를 Amazon S3 버킷에 업로드합니다. SageMaker가 해당 버킷의 데이터에 접근할 수 있도록 허용합니다. S3 버킷에서 SageMaker Data Wrangler로 데이터를 가져옵니다. Data Wrangler 내에서 데이터 변환을 수행하고 인사이트를 생성합니다. 가장 많은 표를 받은
  • C. 데이터를 SageMaker Data Wrangler 콘솔에 직접 업로드합니다. SageMaker와 Amazon QuickSight가 Amazon S3 버킷에 있는 데이터에 접근할 수 있도록 허용합니다. Data Wrangler에서 데이터 변환을 수행하고 변환된 데이터를 두 번째 S3 버킷에 저장합니다. QuickSight를 사용하여 데이터 인사이트를 생성합니다.
  • D. 데이터를 Amazon S3 버킷에 업로드합니다. SageMaker가 버킷에 있는 데이터에 접근할 수 있도록 허용합니다. 버킷에서 SageMaker Data Wrangler로 데이터를 가져옵니다. Data Wrangler에서 데이터 변환을 수행합니다. 데이터를 두 번째 S3 버킷에 저장합니다. SageMaker Studio 노트북을 사용하여 데이터 인사이트를 생성합니다.

Exam question from Amazon's AWS Certified Machine Learning - Specialty
Question #: 335
Topic #: 1

A bank has collected customer data for 10 years in CSV format. The bank stores the data in an on-premises server. A data science team wants to use Amazon SageMaker to build and train a machine learning (ML) model to predict churn probability. The team will use the historical data. The data scientists want to perform data transformations quickly and to generate data insights before the team builds a model for production.

Which solution will meet these requirements with the LEAST development effort?

  • A. Upload the data into the SageMaker Data Wrangler console directly. Perform data transformations and generate insights within Data Wrangler.
  • B. Upload the data into an Amazon S3 bucket. Allow SageMaker to access the data that is in the bucket. Import the data from the S3 bucket into SageMaker Data Wrangler. Perform data transformations and generate insights within Data Wrangler. Most Voted
  • C. Upload the data into the SageMaker Data Wrangler console directly. Allow SageMaker and Amazon QuickSight to access the data that is in an Amazon S3 bucket. Perform data transformations in Data Wrangler and save the transformed data into a second S3 bucket. Use QuickSight to generate data insights.
  • D. Upload the data into an Amazon S3 bucket. Allow SageMaker to access the data that is in the bucket. Import the data from the bucket into SageMaker Data Wrangler. Perform data transformations in Data Wrangler. Save the data into a second S3 bucket. Use a SageMaker Studio notebook to generate data insights.
