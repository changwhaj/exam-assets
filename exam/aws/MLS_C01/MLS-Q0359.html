A machine learning (ML) engineer is preparing a dataset for a classification model. The ML engineer notices that some continuous numeric features have a significantly greater value than most other features. A business expert explains that the features are independently informative and that the dataset is representative of the target distribution.

After training, the model's inferences accuracy is lower than expected.

Which preprocessing technique will result in the GREATEST increase of the model's inference accuracy?

  • A. Normalize the problematic features. Most Voted
  • B. Bootstrap the problematic features.
  • C. Remove the problematic features.
  • D. Extrapolate synthetic features.

A. 문제가 있는 특징들을 정규화합니다. **이유**: 연속형 수치 특징들이 다른 특징들에 비해 현저히 높은 값을 가질 경우, 이러한 스케일 차이가 모델 학습에 부정적인 영향을 미쳐 정확도를 떨어뜨릴 수 있습니다. 정규화(예: 최소-최대 스케일링 또는 표준화)는 특징들을 공통된 스케일로 조정하여 모델 학습을 향상시킵니다. B(부트스트래핑)는 데이터 샘플링 기법으로, 스케일 문제를 직접적으로 해결하지 못합니다. C(특징 제거)는 귀중한 정보를 손실할 위험이 있으며, 비즈니스 전문가가 해당 특징들이 독립적으로 유용한 정보를 제공한다고 언급한 점을 고려할 때 바람직하지 않습니다. D(합성 특징 추정)는 스케일 불균형을 직접적으로 해결하지 못하며, 복잡성을 증가시킵니다.

Selected Answer: A
A. Normalize the problematic features. **Reason**: When continuous numerical features have significantly higher values than others, the scale difference can negatively impact model training, leading to lower accuracy. Normalization (e.g., min-max scaling or standardization) adjusts features to a common scale, improving model learning. B (bootstrapping) is a data sampling technique and does not directly address scale issues. C (removing features) risks losing valuable information, which is not ideal given the business expert's indication that these features are independently informative. D (estimating synthetic features) does not directly resolve scale imbalances and introduces additional complexity.
