A data scientist uses Amazon SageMaker to perform hyperparameter tuning for a prototype machine leaming (ML) model. The data scientist's domain knowledge suggests that the hyperparameter is highly sensitive to changes.

The optimal value, x, is in the 0.5 < x < 1.0 range. The data scientist's domain knowledge suggests that the optimal value is close to 1.0.

The data scientist needs to find the optimal hyperparameter value with a minimum number of runs and with a high degree of consistent tuning conditions.

Which hyperparameter scaling type should the data scientist use to meet these requirements?

  • A. Auto scaling
  • B. Linear scaling
  • C. Logarithmic scaling
  • D. Reverse logarithmic scaling Most Voted

The data scientist indicates that the optimal hyperparameter value lies within 0.5 < x < 1.0, with a high likelihood of being close to 1.0. Logarithmic scaling is ideal because it increases sampling density near the upper boundary (1.0), allowing for finer exploration of values close to 1.0. This meets the requirement of finding the optimal hyperparameter value with minimal runs and high consistency. D. Reverse logarithmic scaling: This allocates more sampling points to smaller values (near 0.5), which is unsuitable given the domain knowledge suggesting the optimal value is near 1.0.
