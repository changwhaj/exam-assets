주제 번호: 1

한 회사의 AWS 인프라는 50개 이상의 계정과 5개의 AWS 리전에 분산되어 있습니다. 이 회사는 모든 AWS 계정에 대해 간소화된 관리 및 유지 관리를 통해 보안 상태를 관리해야 합니다. 회사는 방화벽 규칙 및 요구 사항을 관리하기 위해 AWS Firewall Manager를 사용하려고 합니다.

회사는 AWS Organizations에서 모든 기능이 활성화된 조직을 생성했습니다.

이 요구 사항을 충족하기 위해 회사가 다음에 취해야 할 단계는 무엇일까요? (세 가지를 선택하세요.)

  • A. 방화벽 관리자 관리자 계정만 조직에 가입하도록 구성하십시오.
  • B. 모든 계정이 조직에 가입하도록 구성합니다. 가장 많은 표를 받은
  • C. 방화벽 관리자 관리자 계정으로 계정을 설정합니다. 가장 많은 표를 받은
  • D. 방화벽 관리자 하위 계정으로 계정을 설정합니다.
  • E. 회사에서 리소스를 보유하고 있는 모든 계정과 모든 리전에 대해 AWS Config를 설정합니다. 가장 많은 표를 받은
  • F. 조직의 관리 계정에 대해서만 AWS Config를 설정합니다.

Topic #: 1

A company's AWS infrastructure is spread across more than 50 accounts and across five AWS Regions. The company needs to manage its security posture with simplified administration and maintenance for all the AWS accounts. The company wants to use AWS Firewall Manager to manage the firewall rules and requirements.

The company creates an organization with all features enabled in AWS Organizations.

Which combination of steps should the company take next to meet the requirements? (Choose three.)

  • A. Configure only the Firewall Manager administrator account to join the organization.
  • B. Configure all the accounts to join the organization. Most Voted
  • C. Set an account as the Firewall Manager administrator account. Most Voted
  • D. Set an account as the Firewall Manager child account.
  • E. Set up AWS Config for all the accounts and all the Regions where the company has resources. Most Voted
  • F. Set up AWS Config for only the organization's management account.
