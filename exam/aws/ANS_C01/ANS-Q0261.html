Amazon AWS Certified Advanced Networking - Specialty ANS-C01 시험 문제
문제 번호: 261
주제 번호: 1

한 회사가 AWS VPC에서 워크로드를 실행하고 있습니다. 이 회사의 아키텍처에는 Amazon CloudWatch Logs 및 AWS Key Management Service(AWS KMS)를 포함한 여러 AWS 서비스에 대한 인터페이스 VPC 엔드포인트가 있습니다. 이러한 엔드포인트는 공유 보안 그룹을 사용하도록 구성되어 있으며, 해당 보안 그룹은 다른 워크로드나 리소스에는 사용되지 않습니다.

환경 보안 검토 결과, 회사는 공유 보안 그룹의 권한이 필요 이상으로 관대하다고 판단했습니다. 이에 따라 회사는 해당 보안 그룹과 관련된 규칙을 더욱 엄격하게 변경하고자 합니다. 보안 그룹 규칙 변경은 VPC 내 리소스가 인터페이스 VPC 엔드포인트를 통해 AWS 서비스를 사용하는 것을 막아서는 안 되며, 불필요한 접근을 차단하는 데에만 초점을 맞춰야 합니다.

현재 보안 그룹은 다음과 같은 규칙을 사용하고 있습니다.

• 인바운드 - 규칙 1

프로토콜: TCP -

포트: 443 -

출발지: 0.0.0.0/0 -

• 인바운드 - 규칙 2

프로토콜: TCP -

포트: 443 -

출발지: VPC CIDR -

• 아웃바운드 - 규칙 1

프로토콜: 전체 -

포트: 전체 -

목적지: 0.0.0.0/0 -

이러한 요구 사항을 충족하려면 어떤 규칙을 제거해야 합니까?

  • A. 출국 - 규칙 2
  • B. 인바운드 - 규칙 1 및 아웃바운드 - 규칙 1 가장 많은 표를 받은
  • C. 인바운드 - 규칙 2 및 아웃바운드 - 규칙 1
  • D. 출고 - 규칙 1

Exam question from Amazon's AWS Certified Advanced Networking - Specialty ANS-C01
Question #: 261
Topic #: 1

A company runs a workload in a single VPC on AWS. The company’s architecture contains several interface VPC endpoints for AWS services, including Amazon CloudWatch Logs and AWS Key Management Service (AWS KMS). The endpoints are configured to use a shared security group. The security group is not used for any other workloads or resources.

After a security review of the environment, the company determined that the shared security group is more permissive than necessary. The company wants to make the rules associated with the security group more restrictive. The changes to the security group rules must not prevent the resources in the VPC from using AWS services through interface VPC endpoints. The changes must prevent unnecessary access.

The security group currently uses the following rules:

• Inbound - Rule 1

Protocol: TCP -

Port: 443 -

Source: 0.0.0.0/0 -

• Inbound - Rule 2

Protocol: TCP -

Port: 443 -

Source: VPC CIDR -

• Outbound - Rule 1

Protocol: All -

Port: All -

Destination: 0.0.0.0/0 -

Which rule or rules should the company remove to meet with these requirements?

  • A. Outbound - Rule 2
  • B. Inbound - Rule 1 and Outbound - Rule 1 Most Voted
  • C. Inbound - Rule 2 and Outbound - Rule 1
  • D. Outbound - Rule 1
