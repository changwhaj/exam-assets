Using IGMP (Internet Group Management Protocol) is a common approach for dynamic multicasting. It allows hosts to report their multicast group memberships to any neighboring multicast routers, which in this case is the transit gateway. Creating an IGMP multicast domain within the transit gateway helps organize and manage the multicast traffic. Associating the VPCs and applicable subnets with the multicast domain ensures that the multicast traffic is properly routed within the transit gateway. Registering the multicast senders' network interface with the multicast domain allows them to dynamically join the multicast group. Adjusting the network ACLs to allow UDP traffic from the source to all receivers and to allow UDP traffic that is sent to the multicast group address ensures proper communication between multicast senders and receivers.
