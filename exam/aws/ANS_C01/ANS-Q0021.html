주제 #: 1

회사의 네트워크 엔지니어는 네트워크 이상 현상을 해결하고 감지하는 데 도움이 되는 새로운 솔루션을 설계해야 합니다. 네트워크 엔지니어가 트래픽 미러링을 구성했습니다. 그러나 미러링된 트래픽은 트래픽 미러 대상인 Amazon EC2 인스턴스를 압도합니다. EC2 인스턴스는 회사의 보안 팀이 트래픽을 분석하는 데 사용하는 도구를 호스팅합니다. 네트워크 엔지니어는 미러링된 트래픽의 수요에 맞게 확장할 수 있는 고가용성 솔루션을 설계해야 합니다.
어떤 솔루션이 이러한 요구 사항을 충족합니까?

  • A. NLB(Network Load Balancer)를 트래픽 미러 대상으로 배포합니다. NLB 뒤에 있습니다. Auto Scaling 그룹에 EC2 인스턴스 집합을 배포합니다. 필요에 따라 트래픽 미러링을 사용하십시오. 최다 투표
  • B. ALB(Application Load Balancer)를 트래픽 미러 대상으로 배포합니다. ALB 뒤에서 Auto Scaling 그룹에 EC2 인스턴스 집합을 배포합니다. 업무 시간 외 시간에만 트래픽 미러링을 사용하십시오.
  • C. GLB(Gateway Load Balancer)를 트래픽 미러 대상으로 배포합니다. GLB 뒤에 있습니다. Auto Scaling 그룹에 EC2 인스턴스 집합을 배포합니다. 필요에 따라 트래픽 미러링을 사용하십시오. 최다 투표
  • D. 트래픽 미러 대상으로 HTTPS 리스너를 사용하여 ALB(Application Load Balancer)를 배포합니다. ALB 뒤에 있습니다. Auto Scaling 그룹에 EC2 인스턴스 집합을 배포합니다. 활성 이벤트나 업무 시간에만 트래픽 미러링을 사용하세요.

Question #: 21
Topic #: 1

A company’s network engineer needs to design a new solution to help troubleshoot and detect network anomalies. The network engineer has configured Traffic Mirroring. However, the mirrored traffic is overwhelming the Amazon EC2 instance that is the traffic mirror target. The EC2 instance hosts tools that the company’s security team uses to analyze the traffic. The network engineer needs to design a highly available solution that can scale to meet the demand of the mirrored traffic.
Which solution will meet these requirements?

  • A. Deploy a Network Load Balancer (NLB) as the traffic mirror target. Behind the NLB. deploy a fleet of EC2 instances in an Auto Scaling group. Use Traffic Mirroring as necessary. Most Voted
  • B. Deploy an Application Load Balancer (ALB) as the traffic mirror target. Behind the ALB, deploy a fleet of EC2 instances in an Auto Scaling group. Use Traffic Mirroring only during non-business hours.
  • C. Deploy a Gateway Load Balancer (GLB) as the traffic mirror target. Behind the GLB. deploy a fleet of EC2 instances in an Auto Scaling group. Use Traffic Mirroring as necessary. Most Voted
  • D. Deploy an Application Load Balancer (ALB) with an HTTPS listener as the traffic mirror target. Behind the ALB. deploy a fleet of EC2 instances in an Auto Scaling group. Use Traffic Mirroring only during active events or business hours.

Using Traffic Mirroring as necessary allows you to control when to capture mirrored traffic, reducing the load on the analysis tools during non-critical times.

Deploying a Network Load Balancer (NLB) as the traffic mirror target and using an Auto Scaling group with EC2 instances behind the NLB is the recommended solution. NLB is designed for TCP/UDP traffic and operates at the transport layer (Layer 4), making it a suitable choice when dealing with non-HTTP protocols or when high performance and scalability are required. NLB offers several benefits, including: High performance: NLB is capable of handling extremely high volumes of traffic with low latency, making it suitable for demanding network environments.
