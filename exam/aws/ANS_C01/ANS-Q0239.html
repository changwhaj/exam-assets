한 회사가 프로덕션 VPC에 웹 서버 소프트웨어를 실행하는 Amazon EC2 인스턴스 10개를 보유하고 있습니다. 또한 온프레미스 데이터 센터에도 웹 서버 10개를 운영하고 있습니다. 온프레미스 데이터 센터와 프로덕션 VPC 간에는 10Gbps AWS Direct Connect 연결이 설정되어 있으며, 데이터 센터는 10.100.0.0/20 CIDR 블록을 사용합니다.

이 회사는 수천 명의 외부 사용자로부터 HTTPS 트래픽을 처리하는 로드 밸런싱 솔루션을 구현해야 합니다. 이 솔루션은 AWS의 웹 서버와 온프레미스 데이터 센터의 웹 서버에 트래픽을 분산해야 합니다. 웹 서버의 위치에 관계없이, HTTPS 요청은 세션이 지속되는 동안 동일한 웹 서버로 전송되어야 합니다.

이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. 프로덕션 VPC에 네트워크 로드 밸런서(NLB)를 배포합니다. EC2 인스턴스용 대상 그룹 하나와 온프레미스 서버용 대상 그룹 하나를 생성합니다. 대상 유형으로 IP를 지정합니다. EC2 인스턴스와 온프레미스 서버를 대상 그룹에 등록합니다. NLB에서 연결 드레이닝을 활성화합니다.
  • B. 프로덕션 VPC에 애플리케이션 로드 밸런서(ALB)를 배포합니다. EC2 인스턴스용 대상 그룹 하나와 온프레미스 서버용 대상 그룹 하나를 생성합니다. 대상 유형으로 IP를 지정합니다. EC2 인스턴스와 온프레미스 서버를 대상 그룹에 등록합니다. ALB에서 애플리케이션 기반 스티키 세션을 활성화합니다. 가장 많은 표를 받은
  • C. 프로덕션 VPC에 네트워크 로드 밸런서(NLB)를 배포합니다. EC2 인스턴스용 대상 그룹 하나와 온프레미스 서버용 대상 그룹 하나를 생성합니다. 대상 유형으로 인스턴스를 지정합니다. EC2 인스턴스와 온프레미스 서버를 대상 그룹에 등록합니다. NLB에서 스티키 세션을 활성화합니다.
  • D. 프로덕션 VPC에 애플리케이션 로드 밸런서(ALB)를 배포합니다. EC2 인스턴스용 대상 그룹 하나와 온프레미스 서버용 대상 그룹 하나를 생성합니다. 대상 유형은 인스턴스로 지정합니다. EC2 인스턴스와 온프레미스 서버를 대상 그룹에 등록합니다. ALB에서 애플리케이션 기반 스티키 세션을 활성화합니다.

A company has 10 Amazon EC2 instances that run web server software in a production VPC. The company also has 10 web servers that run in an on-premises data center. The company has a 10 Gbps AWS Direct Connect connection between the on-premises data center and the production VPC. The data center uses the 10.100.0.0/20 CIDR block.

The company needs to implement a load balancing solution that receives HTTPS traffic from thousands of external users. The solution must distribute the traffic across the web servers on AWS and the web servers in the data center. Regardless of the location of the web servers, HTTPS requests must go to the same web server for the duration of the session.

Which solution will meet these requirements?

  • A. Deploy a Network Load Balancer (NLB) in the production VPC. Create one target group for the EC2 Instances and a second target group for the on-premises servers. Specify IP as the target type. Register the EC2 instances and the on-premises servers with the target groups. Enable connection draining on the NLB.
  • B. Deploy an Application Load Balancer (ALB) in the production VPC. Create one target group for the EC2 Instances and a second target group for the on-premises servers. Specify IP as the target type. Register the EC2 instances and the on-premises servers with the target groups. Enable application-based sticky sessions on the ALB. Most Voted

Specify instance as the target type. Register the EC2 instances and the on-premises servers with the target groups. Enable sticky sessions on the NLB.
