한 회사가 언어 번역 웹 서비스를 개발했습니다. 이 웹 서비스 애플리케이션은 Auto Scaling 그룹에 속한 Amazon EC2 인스턴스에서 실행됩니다. 인스턴스는 Application Load Balancer(ALB) 뒤에서 실행되며 프라이빗 서브넷에 배포됩니다. 웹 서비스는 수백 메가바이트의 데이터를 포함하는 요청을 처리할 수 있습니다.

이 회사는 일부 고객에게만 웹 서비스 접근 권한을 부여해야 합니다. 각 고객은 고유한 AWS 계정을 가지고 있습니다. 회사는 모든 고객에게 웹 서비스를 공개하지 않고 승인된 고객에게만 웹 서비스를 제공해야 합니다.

이러한 요구 사항을 충족하면서 운영 오버헤드를 최소화하는 방법은 무엇일까요? (두 가지를 선택하세요.)

  • A. 승인된 고객과만 VPC 피어링 연결을 생성하십시오.
  • B. AWS PrivateLink 엔드포인트 서비스를 생성합니다. 승인된 고객에게만 접근 권한이 부여되도록 엔드포인트 서비스를 구성합니다. 가장 많은 표를 받은
  • C. 엔드포인트 서비스의 로드 밸런서에 대한 인증 작업을 구성하여 고객이 AWS 자격 증명을 사용하여 로그인할 수 있도록 합니다. 승인된 고객에게만 URL을 제공합니다.
  • D. ALB를 대상으로 하는 네트워크 로드 밸런싱(NLB) 및 리스너를 구성합니다. NLB를 엔드포인트 서비스와 연결합니다. 가장 많은 표를 받은
  • E. ALB를 엔드포인트 서비스와 연결합니다.

Exam question from Amazon's AWS Certified Advanced Networking - Specialty ANS-C01
Question #: 199
Topic #: 1

A company has developed a web service for language translation. The web service's application runs on a fleet of Amazon EC2 instances that are in an Auto Scaling group. The instances run behind an Application Load Balancer (ALB) and are deployed in a private subnet. The web service can process requests that contain hundreds of megabytes of data.

The company needs to give some customers the ability to access the web service. Each customer has its own AWS account. The company must make the web service accessible to approved customers without making the web service accessible to all customers.

Which combination of steps will meet these requirements with the LEAST operational overhead? (Choose two.)

  • A. Create VPC peering connections with the approved customers only.
  • B. Create an AWS PrivateLink endpoint service. Configure the endpoint service to require acceptance that will be granted to approved customers only. Most Voted
  • C. Configure an authentication action for the endpoint service's load balancer to allow customers to log in by using their AWS credentials. Provide only approved customers with the URL.
  • D. Configure a Network Load Balancer (NLB) and a listener with the ALB as a target. Associate the NLB with the endpoint service. Most Voted
  • E. Associate the ALB with the endpoint service.
