한 회사가 Amazon Bedrock을 사용하여 고객을 위한 기술 콘텐츠를 생성하고 있습니다. 최근 이 회사의 모델이 긴 기술 문서의 요약을 생성할 때 왜곡된 출력물이 급증하는 현상을 겪고 있습니다. 모델 출력물에는 부정확하거나 조작된 내용이 포함되어 있습니다. 현재 이 회사의 솔루션은 전체 문서를 단일 입력으로 처리하는 기본적인 원샷 프롬프트를 사용하는 대규모 파운데이션 모델(FM)을 사용합니다.
이 회사는 왜곡된 출력물을 줄이고 사실 정확도 목표를 달성할 수 있는 솔루션이 필요합니다. 이 솔루션은 시간당 1,000개 이상의 문서를 처리하고 각 문서에 대해 3초 이내에 요약을 제공해야 합니다.
이러한 요구 사항을 충족하는 솔루션 조합은 무엇입니까? (두 가지를 선택하십시오.)

  • A. 모델이 각 요약을 생성하기 전에 명시적인 사실 검증을 포함한 단계별 추론이 필요한 제로샷 사고 연쇄(CoT) 지침을 구현합니다. 가장 많은 표를 받은
  • B. Amazon Bedrock 지식 기반에서 RAG(Retrieval Augmented Generation)를 사용합니다. 의미론적 청킹과 최적화된 임베딩을 적용하여 요약을 원본 콘텐츠에 기반을 두도록 합니다. 가장 많은 표를 받은
  • C. 아마존 베드락 가드레일을 구성하여 환각 콘텐츠와 관련된 패턴과 일치하는 생성된 출력을 차단하십시오.
  • D. Amazon Bedrock에서 온도 매개변수를 높입니다.
  • E. 아마존 베드락 모델이 각 문서 전체를 한 번에 요약하도록 합니다.

Exam question from Amazon's AWS Certified Generative AI Developer - Professional AIP-C01
Question #: 30
Topic #: 1

A company uses Amazon Bedrock to generate technical content for customers. The company has recently experienced a surge in hallucination outputs when the company's model generates summaries of long technical documents. The model outputs include inaccurate or fabricated details. The company's current solution uses a large foundation model (FM) with a basic one-shot prompt that includes the full document in a single input.
The company needs a solution that will reduce hallucinations and meet factual accuracy goals. The solution must process more than 1,000 documents each hour and deliver summaries within 3 seconds for each document.
Which combination of solutions will meet these requirements? (Choose two.)

  • A. Implement zero-shot chain-of-thought (CoT) instructions that require step-by-step reasoning with explicit fact verification before the model generates each summary. Most Voted
  • B. Use Retrieval Augmented Generation (RAG) with an Amazon Bedrock knowledge base. Apply semantic chunking and tuned embeddings to ground summaries in source content. Most Voted
  • C. Configure Amazon Bedrock guardrails to block any generated output that matches patterns that are associated with hallucinated content.
  • D. Increase the temperature parameter in Amazon Bedrock.
  • E. Prompt the Amazon Bedrock model to summarize each full document in one pass.
