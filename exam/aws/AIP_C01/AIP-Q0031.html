한 회사가 추천 시스템을 운영하고 있습니다. 시스템 애플리케이션은 Amazon EC2 인스턴스에서 실행되며, Amazon Bedrock 기반 모델(FM)에 API를 호출하여 고객 행동을 분석하고 개인화된 제품 추천을 생성합니다. 현재
시스템에서 간헐적인 문제가 발생하고 있으며, 일부 추천이 고객 선호도와 일치하지 않습니다. 이 회사는 운영 지표를 모니터링하고 설정된 기준선 대비 운영 성능 저하 패턴을 감지할 수 있는 관찰 가능성 솔루션이 필요합니다. 또한, FM 동작이 예상 패턴에서 벗어날 경우 10분 이내에 상관 관계 데이터가 포함된 알림을 생성해야 합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. 애플리케이션 인프라에 맞게 Amazon CloudWatch Container Insights를 구성합니다. 지연 시간 임계값에 대한 CloudWatch 알람을 설정합니다. CloudWatch 내장 메트릭 형식을 사용하여 토큰 수에 대한 사용자 지정 메트릭을 추가합니다. 데이터를 시각화하기 위한 CloudWatch 대시보드를 생성합니다.
  • B. AWS X-Ray를 구현하여 애플리케이션 구성 요소를 통한 요청을 추적합니다. 오류 패턴 감지를 위해 CloudWatch Logs Insights를 활성화합니다. Amazon Bedrock에 대한 모든 API 호출을 모니터링하도록 AWS CloudTrail을 설정합니다. Amazon QuickSight에서 사용자 지정 대시보드를 생성합니다.
  • C. 애플리케이션 리소스에 대해 Amazon CloudWatch Application Insights를 활성화합니다. 요청 유형 및 사용자 세그먼트에 대한 차원을 포함하는 CloudWatch 내장 메트릭 형식을 사용하여 추천 품질, 토큰 사용량 및 응답 지연 시간에 대한 사용자 지정 메트릭을 생성합니다. 모델 메트릭에 대해 CloudWatch 이상 탐지를 구성합니다. CloudWatch Logs Insights를 사용하여 로그 패턴 분석을 설정합니다. 가장 많은 표를 받은
  • D. Amazon OpenSearch Service와 Observability 플러그인을 사용합니다. Amazon Kinesis를 사용하여 모델 메트릭과 로그를 수집합니다. 모델 동작 패턴을 분석하기 위해 사용자 지정 PPL(Piped Processing Language) 쿼리를 생성합니다. 실시간으로 이상 징후를 시각화할 수 있는 운영 대시보드를 구축합니다.

Question #: 31
Topic #: 1

A company has a recommendation system. The system's applications run on Amazon EC2 instances. The applications make API calls to Amazon Bedrock foundation models (FMs) to analyze customer behavior and generate personalized product recommendations.
The system is experiencing intermittent issues. Some recommendations do not match customer preferences. The company needs an observability solution to monitor operational metrics and detect patterns of operational performance degradation compared to established baselines. The solution must also generate alerts with correlation data within 10 minutes when FM behavior deviates from expected patterns.
Which solution will meet these requirements?

  • A. Configure Amazon CloudWatch Container Insights for the application infrastructure. Set up CloudWatch alarms for latency thresholds. Add custom metrics for token counts by using the CloudWatch embedded metric format. Create CloudWatch dashboards to visualize the data.
  • B. Implement AWS X-Ray to trace requests through the application components. Enable CloudWatch Logs Insights for error pattern detection. Set up AWS CloudTrail to monitor all API calls to Amazon Bedrock. Create custom dashboards in Amazon QuickSight.
  • C. Enable Amazon CloudWatch Application Insights for the application resources. Create custom metrics for recommendation quality, token usage, and response latency by using the CloudWatch embedded metric format with dimensions for request types and user segments. Configure CloudWatch anomaly detection on the model metrics. Establish log pattern analysis by using CloudWatch Logs Insights. Most Voted
  • D. Use Amazon OpenSearch Service with the Observability plugin. Ingest model metrics and logs by using Amazon Kinesis. Create custom Piped Processing Language (PPL) queries to analyze model behavior patterns. Establish operational dashboards to visualize anomalies in real time.
