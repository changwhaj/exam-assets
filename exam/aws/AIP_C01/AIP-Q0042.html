Amazon AWS Certified Generative AI Developer - Professional AIP-C01 시험 문제
문제 번호: 42
주제 번호: 1

한 전자상거래 회사가 아마존 베드락(Amazon Bedrock)을 사용하여 고객 서비스 AI 비서를 구축하고 있습니다. 이 AI 비서는 매일 5만 건 이상의 고객 문의를 처리해야 합니다. 특히 프로모션 기간에는 문의량이 급증하여 하루 최대 15만 건의 문의가 발생하기도 합니다. 분석 결과, 문의의 40%는 유사한 패턴을 보이며 동일한 맥락을 공유하는 것으로 나타났습니다.
GenAI 개발자는 트래픽 급증 시에도 AI 비서의 지연 시간을 최소화하고 일관된 성능을 보장하는 솔루션을 설계해야 합니다.
이러한 요구 사항을 가장 비용 효율적으로 충족하는 솔루션은 무엇일까요?

  • A. Amazon Bedrock에 대한 요청의 성능 구성에서 지연 시간 매개변수를 최적화로 설정하여 지연 시간 최적화 추론을 구성하십시오. 반복적인 쿼리를 처리하기 위해 프롬프트 캐싱을 사용하십시오. 가장 많은 표를 받은
  • B. 최대 트래픽 부하를 처리할 수 있도록 구성된 프로비저닝된 처리량 및 모델 단위(MU)를 구매하십시오. 반복적인 쿼리를 캐싱하기 위해 Amazon ElastiCache(Redis OSS)를 사용하십시오.
  • C. Amazon Bedrock 에이전트와 사용자 지정 지식 기반을 사용하여 고객 문의를 사전 처리합니다. 트래픽 분산을 위해 리전 간 추론을 구성합니다.
  • D. 사용자 지정 프롬프트 라우팅 메커니즘을 사용하여 AWS Lambda 함수를 통해 요청을 사전 처리합니다. 자주 묻는 질문을 처리하기 위해 Amazon DynamoDB를 캐싱 계층으로 사용합니다.

Exam question from Amazon's AWS Certified Generative AI Developer - Professional AIP-C01
Question #: 42
Topic #: 1

An ecommerce company is using Amazon Bedrock to build a customer service AI assistant. The AI assistant needs to process over 50,000 customer inquiries every day. The AI assistant occasionally experiences traffic spikes of up to 150,000 inquiries every day during promotional events. Analysis shows that 40% of inquiries follow similar patterns that share the same context.
A GenAI developer must design a solution that will ensure low latency and consistent performance for the AI assistant during traffic spikes.
Which solution will meet these requirements MOST cost-effectively?

  • A. Configure latency-optimized inference by setting the latency parameter to optimized in the performance configuration of the request to Amazon Bedrock. Use prompt caching to handle the repetitive inquiries. Most Voted
  • B. Purchase provisioned throughput and model units (MUs) that are sized to handle peak traffic loads. Use Amazon ElastiCache (Redis OSS) to cache repetitive inquiries.
  • C. Use Amazon Bedrock Agents and custom knowledge bases to pre-process customer inquiries. Configure cross-Region inference to distribute traffic.
  • D. Use AWS Lambda functions to pre-process requests by using a custom prompt routing mechanism. Use Amazon DynamoDB as a caching layer to handle frequently asked questions.
