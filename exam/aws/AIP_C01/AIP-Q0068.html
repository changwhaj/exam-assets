한 기업이 유럽과 미주 지역의 여러 국가에서 운영되는 5개의 독립적인 사업부에 여러 개의 생성형 AI(GenAI) 애플리케이션을 배포할 계획입니다. 각 애플리케이션은 사업부별 지식 기반(테라바이트 규모의 비정형 데이터 저장)을 사용하는 Amazon Bedrock Retrieval Augmented Generation(RAG) 패턴을 활용합니다.
이 기업은 모든 GenAI 애플리케이션에 걸쳐 보안 제어, 관찰 가능성, 배포 패턴을 위한 잘 설계된 표준화된 구성 요소를 구축해야 합니다. 이러한 구성 요소는 재사용 가능하고, 버전 관리가 가능하며, 일관된 방식으로 거버넌스되어야 합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. GenAI 애플리케이션에 대한 Amazon API Gateway REST API 엔드포인트를 구성합니다. AWS Well-Architected Generative AI Lens를 기반으로 표준화된 AWS CloudFormation 템플릿에 공통 보안, 관찰 가능성 및 RAG 패턴을 배포합니다. 배포 후 CloudFormation Guard를 사용하여 각 사업부에서 정책 준수 여부를 검증합니다.
  • B. AWS Well-Architected Generative AI Lens를 기반으로 보안, 관찰 가능성 및 RAG 패턴을 구현하는 표준화된 AWS CloudFormation 템플릿을 생성합니다. 버전 관리를 수행하는 중앙 집중식 저장소를 구축합니다. CloudFormation Guard와 CI/CD 파이프라인을 통합하여 비즈니스 부서 전반에 걸쳐 일관되고 반복 가능한 배포를 시행합니다. 가장 많은 표를 받은
  • C. AWS 서비스 카탈로그를 사용하여 각 사업부별로 표준화된 포트폴리오와 버전 관리 제품을 정의합니다. AWS Well-Architected Generative AI Lens를 기반으로 포트폴리오를 활용하여 보안, 관찰 가능성 및 RAG 패턴을 적용합니다. 사업부에서 서비스 카탈로그 콘솔을 사용하여 리소스를 배포하도록 요구합니다.
  • D. AWS Well-Architected Generative AI Lens를 기반으로 보안 제어, 관찰 가능성 요구 사항 및 RAG 패턴을 공유 설계 문서에 문서화합니다. Amazon Macie를 사용하여 배포를 강제합니다. 각 사업부에 구현 책임을 위임합니다.

Exam question from Amazon's AWS Certified Generative AI Developer - Professional AIP-C01
Question #: 68
Topic #: 1

A company is planning to deploy multiple generative AI (GenAI) applications to five independent business units that operate in multiple countries in Europe and the Americas. Each application uses Amazon Bedrock Retrieval Augmented Generation (RAG) patterns with business unit-specific knowledge bases that store terabytes of unstructured data.
The company must establish well-architected, standardized components for security controls, observability practices, and deployment patterns across all the GenAI applications. The components must be reusable, versioned, and governed consistently.
Which solution will meet these requirements?

  • A. Configure Amazon API Gateway REST API endpoints for the GenAI applications. Deploy common security, observability, and RAG patterns based on the AWS Well-Architected Generative AI Lens in standardized AWS CloudFormation templates. Use CloudFormation Guard after the deployment to validate policy compliance in each business unit.
  • B. Create standardized AWS CloudFormation templates to implement security, observability, and RAG patterns based on the AWS Well-Architected Generative AI Lens. Establish a centralized repository that performs version control. Integrate a CI/CD pipeline with CloudFormation Guard to enforce consistent and repeatable deployments across business units. Most Voted
  • C. Use AWS Service Catalog to define standardized portfolios and versioned products for each business unit. Use the portfolios to enforce security, observability, and RAG patterns based on the AWS Well-Architected Generative AI Lens. Require the business units to use the Service Catalog console to deploy resources.
  • D. Document security controls, observability requirements, and RAG patterns based on the AWS Well-Architected Generative AI Lens in a shared design document. Use Amazon Macie to enforce deployment. Delegate implementation responsibility to each business unit.
