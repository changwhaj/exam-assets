한 의료 회사가 Amazon Bedrock을 사용하여 임상 문서 요약을 생성하는 애플리케이션을 배포했습니다. 이 애플리케이션은 응답 품질이 일관되지 않고 때때로 사실과 다른 오류를 발생시키는 문제가 있습니다. 월별 비용은 회사 예상치를 40% 초과하고 있습니다. GenAI 개발자는 오류 감지, 비정상적인 토큰 소비 식별, 비용 이상 징후에 대한 조기 경고를 제공하는 거의 실시간 모니터링 솔루션을 구현해야 합니다. 이 솔루션은 맞춤 개발 작업과 유지 관리 오버헤드를 최소화해야 합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. Amazon CloudWatch 알람을 구성하여 InputTokenCount 및 OutputTokenCount 메트릭을 모니터링하고 이상 징후를 감지합니다. 모델 호출 로그는 Amazon S3 버킷에 저장합니다. AWS Glue 및 Amazon Athena를 사용하여 잠재적인 오류를 식별합니다.
  • B. LLM 기반 판단을 사용하여 환각을 감지하는 Amazon Bedrock 평가 작업을 실행합니다. 토큰 사용량을 추적하도록 Amazon CloudWatch를 구성합니다. CloudWatch 지표를 처리하는 AWS Lambda 함수를 생성합니다. Lambda 함수가 사용 패턴 알림을 보내도록 구성합니다.
  • C. Amazon Bedrock에서 모델 호출 로그를 Amazon S3 버킷에 저장하도록 구성합니다. 텍스트 출력 로깅을 활성화합니다. Amazon Bedrock 가드레일을 구성하여 컨텍스트 접지 검사를 실행하여 오류를 감지합니다. 토큰 사용량 메트릭에 대한 Amazon CloudWatch 이상 감지 알람을 생성합니다. 가장 많은 표를 받은
  • D. AWS CloudTrail을 사용하여 모든 Amazon Bedrock API 호출을 기록합니다. Amazon QuickSight에서 사용자 지정 대시보드를 생성하여 토큰 사용 패턴을 시각화합니다. Amazon SageMaker Model Monitor를 사용하여 생성된 요약의 품질 저하를 감지합니다.

Exam question from Amazon's AWS Certified Generative AI Developer - Professional AIP-C01
Question #: 18
Topic #: 1

A healthcare company uses Amazon Bedrock to deploy an application that generates summaries of clinical documents. The application experiences inconsistent response quality with occasional factual hallucinations. Monthly costs exceed the company's projections by 40%. A GenAI developer must implement a near real-time monitoring solution to detect hallucinations, identify abnormal token consumption, and provide early warnings of cost anomalies. The solution must require minimal custom development work and maintenance overhead.
Which solution will meet these requirements?

  • A. Configure Amazon CloudWatch alarms to monitor InputTokenCount and OutputTokenCount metrics to detect anomalies. Store model invocation logs in an Amazon S3 bucket. Use AWS Glue and Amazon Athena to identify potential hallucinations.
  • B. Run Amazon Bedrock evaluation jobs that use LLM-based judgments to detect hallucinations. Configure Amazon CloudWatch to track token usage. Create an AWS Lambda function to process CloudWatch metrics. Configure the Lambda function to send usage pattern notifications.
  • C. Configure Amazon Bedrock to store model invocation logs in an Amazon S3 bucket. Enable text output logging. Configure Amazon Bedrock guardrails to run contextual grounding checks to detect hallucinations. Create Amazon CloudWatch anomaly detection alarms for token usage metrics. Most Voted
  • D. Use AWS CloudTrail to log all Amazon Bedrock API calls. Create a custom dashboard in Amazon QuickSight to visualize token usage patterns. Use Amazon SageMaker Model Monitor to detect quality drift in generated summaries.
