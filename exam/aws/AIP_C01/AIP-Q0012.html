Amazon AWS Certified Generative AI Developer - Professional AIP-C01 시험 문제
문제 번호: 12
주제 번호: 1

한 의료 회사가 의료진의 임상적 의사결정을 지원하는 검색 증강 생성(RAG) 애플리케이션을 구축하기 위해 Amazon Bedrock을 사용하고 있습니다. 이 애플리케이션은 환자 정보 검색에서 높은 정확도를 달성하고, 생성된 콘텐츠에서 오류를 식별하며, 사람의 검토 비용을 절감해야 합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. Amazon Comprehend를 사용하여 RAG 응답을 분석 및 분류하고 의료 관련 개체와 관계를 추출합니다. AWS Step Functions를 사용하여 자동화된 평가를 오케스트레이션합니다. Amazon CloudWatch 메트릭을 구성하여 개체 인식 신뢰도 점수를 추적합니다. 정확도가 지정된 임계값 아래로 떨어질 경우 CloudWatch에서 알림을 보내도록 구성합니다.
  • B. 의료 콘텐츠에 맞게 세밀하게 조정된 특수 모델을 사용하여 모든 응답을 평가하는 자동화된 대규모 언어 모델(LLM) 기반 평가를 구현합니다. AWS Lambda 함수를 배포하여 평가를 병렬화합니다. 관련성 및 사실 정확도를 추적하는 Amazon CloudWatch 지표에 결과를 게시합니다.
  • C. Amazon CloudWatch Synthetics를 구성하여 정기적으로 알려진 답을 가진 테스트 쿼리를 생성하고 모델 성공률을 추적합니다. 합성 테스트 결과를 예상 결과와 비교하는 대시보드를 설정합니다.
  • D. 응답을 초기 선별하기 위해 자동화된 LLM(Learning Leadership Machine) 심사 시스템을 사용하고, 예외적인 경우에 대해서는 담당자가 직접 검토하는 하이브리드 평가 시스템을 구축합니다. 평가 데이터 세트는 Amazon SageMaker Feature Store를 사용하여 관리하고, 검색 정확도 및 오류 발생률은 Amazon Bedrock에 내장된 평가 기능을 활용하여 추적합니다. Most Voted

Exam question from Amazon's AWS Certified Generative AI Developer - Professional AIP-C01
Question #: 12
Topic #: 1

A healthcare company is using Amazon Bedrock to build a Retrieval Augmented Generation (RAG) application that helps practitioners make clinical decisions. The application must achieve high accuracy for patient information retrievals, identify hallucinations in generated content, and reduce human review costs.
Which solution will meet these requirements?

  • A. Use Amazon Comprehend to analyze and classify RAG responses and to extract medical entities and relationships. Use AWS Step Functions to orchestrate automated evaluations. Configure Amazon CloudWatch metrics to track entity recognition confidence scores. Configure CloudWatch to send an alert when accuracy falls below specified thresholds.
  • B. Implement automated large language model (LLM)-based evaluations that use a specialized model that is fine-tuned for medical content to assess all responses. Deploy AWS Lambda functions to parallelize evaluations. Publish results to Amazon CloudWatch metrics that track relevance and factual accuracy.
  • C. Configure Amazon CloudWatch Synthetics to generate test queries that have known answers on a regular schedule, and track model success rates. Set up dashboards that compare synthetic test results against expected outcomes.
  • D. Deploy a hybrid evaluation system that uses an automated LLM-as-a-judge evaluation to initially screen responses and targeted human reviews for edge cases. Use Amazon SageMaker Feature Store to maintain evaluation datasets. Use a built-in Amazon Bedrock evaluation to track retrieval precision and hallucination rates. Most Voted
