문제 번호: 77
주제 번호: 1

한 회사가 AWS에서 비디오 분석 플랫폼을 구축하고 있습니다. 이 플랫폼은 Amazon Rekognition과 Amazon Bedrock을 사용하여 대규모 비디오 아카이브를 분석할 것입니다. 플랫폼은 사전 정의된 개인정보 보호 표준을 준수해야 합니다. 또한, 보안 모델 I/O를 사용하고, 제어 기반 모델(FM) 접근 패턴을 준수하며, 누가 언제 무엇에 접근했는지에 대한 감사 기능을 제공해야 합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. Amazon Bedrock 모델 API 호출을 위한 VPC 엔드포인트를 구성합니다. Amazon Bedrock Guardrails를 구현하여 프롬프트 및 응답에서 유해하거나 승인되지 않은 콘텐츠를 필터링합니다. 감사 목적으로 모든 에이전트 및 모델 호출을 추적하기 위해 Amazon Bedrock 추적 이벤트를 사용합니다. 모델 사용에 대한 감사 기록으로 추적 데이터를 Amazon CloudWatch Logs로 내보냅니다. 모든 프롬프트와 출력은 AWS KMS 키(SSE-KMS)를 사용한 서버 측 암호화 방식으로 Amazon S3에 저장합니다.
  • B. IAM을 사용하여 속성 기반 제어를 통해 부서를 특정 권한에 매핑하여 액세스 제어를 정의합니다. Amazon Bedrock 모델 API 호출을 위한 VPC 엔드포인트를 구성합니다. IAM 조건 키를 사용하여 특정 GuardrailIdentifier 및 ModelId 값을 적용합니다. S3 객체 및 KMS 키 사용 활동에 대한 관리 및 데이터 이벤트를 캡처하도록 AWS CloudTrail을 구성합니다. 비디오 아카이브와의 파일 수준 상호 작용에 대한 자세한 기록을 위해 S3 서버 액세스 로깅을 활성화합니다. 모든 CloudTrail 로그를 AWS CloudTrail Lake로 전송합니다. Amazon Bedrock, Amazon Rekognition 및 AWS KMS에서 발생하는 예기치 않은 활동을 감지하고 경고하도록 Amazon CloudWatch 알람을 설정합니다.
  • C. VPC 엔드포인트 정책을 사용하여 서비스 접근을 제한합니다. AWS Config를 사용하여 리소스 변경 사항 및 보안 규칙 준수 여부를 추적합니다. AWS KMS 키(SSE-KMS)를 사용한 서버 측 암호화를 통해 저장된 데이터를 암호화합니다. 모델의 I/O 데이터는 별도의 Amazon S3 버킷에 저장합니다. 파일 수준의 상호 작용을 추적하기 위해 S3 서버 접근 로깅을 활성화합니다.
  • D. AWS CloudTrail Insights를 구성하여 계정 전반의 API 호출 패턴을 분석하고 Amazon Bedrock, Amazon Rekognition, Amazon S3 및 AWS KMS에서 비정상적인 활동을 감지합니다. Amazon Macie를 배포하여 비디오 아카이브를 스캔하고 분류합니다. AWS KMS 키(SSE-KMS)를 사용한 서버 측 암호화를 통해 저장된 모든 데이터를 암호화합니다. 감사 목적으로 KMS API 사용 이벤트를 캡처하도록 CloudTrail을 구성합니다. Amazon EventBridge 규칙을 구성하여 CloudTrail Insights의 이상 징후 및 Macie 분석 결과를 처리합니다. 잠재적인 보안 문제가 감지될 때 자동 알림 및 보안 대응을 트리거하도록 CloudWatch 알람을 사용합니다.

Exam question from Amazon's AWS Certified Generative AI Developer - Professional AIP-C01
Question #: 77
Topic #: 1

A company is building a video analysis platform on AWS. The platform will analyze a large video archive by using Amazon Rekognition and Amazon Bedrock. The platform must comply with predefined privacy standards. The platform must also use secure model I/O, control foundation model (FM) access patterns, and provide an audit of who accessed what and when.
Which solution will meet these requirements?

  • A. Configure VPC endpoints for Amazon Bedrock model API calls. Implement Amazon Bedrock Guardrails to filter harmful or unauthorized content in prompts and responses. Use Amazon Bedrock trace events to track all agent and model invocations for auditing purposes. Export the traces to Amazon CloudWatch Logs as an audit record of model usage. Store all prompts and outputs in Amazon S3 with server-side encryption with AWS KMS keys (SSE-KMS).
  • B. Define access control by using IAM with attribute-based controls to map departments to specific permissions. Configure VPC endpoints for Amazon Bedrock model API calls. Use IAM condition keys to enforce specific GuardrailIdentifier and ModelId values. Configure AWS CloudTrail to capture management and data events for S3 objects and KMS key usage activities. Enable S3 server access logging to record detailed file-level interactions with the video archives. Send all CloudTrail logs to AWS CloudTrail Lake. Set up Amazon CloudWatch alarms to detect and alert on unexpected activity from Amazon Bedrock, Amazon Rekognition, and AWS KMS.
  • C. Restrict access to services by using VPC endpoint policies. Use AWS Config to track resource changes and compliance with security rules. Use server-side encryption with AWS KMS keys (SSE-KMS) to encrypt data at rest. Store the model's I/O in separate Amazon S3 buckets. Enable S3 server access logging to track file-level interactions.
  • D. Configure AWS CloudTrail Insights to analyze API call patterns across accounts and detect anomalous activity in Amazon Bedrock, Amazon Rekognition, Amazon S3, and AWS KMS. Deploy Amazon Macie to scan and classify the video archive. Use server-side encryption with AWS KMS keys (SSE-KMS) to encrypt all stored data. Configure CloudTrail to capture KMS API usage events for audit purposes. Configure Amazon EventBridge rules to process CloudTrail Insights anomalies and Macie findings. Use CloudWatch alarms to trigger automated notifications and security responses when potential security issues are detected.
