주제 번호: 1

한 회사가 AWS Lambda와 REST API를 사용하여 고객 지원 워크플로를 자동화하는 추론 에이전트를 구축하고 있습니다. 이 시스템은 상호 작용 전반에 걸쳐 메모리를 유지하고, 관련 에이전트 상태를 공유하며, 이벤트 기반 호출과 동기식 호출을 모두 지원해야 합니다. 또한 접근 제어 및 세션 기반 권한 관리도 필수적입니다. 다음
단계 중 어떤 조합이 가장 확장성이 뛰어난 솔루션을 제공할까요? (두 가지를 선택하세요.)

  • A. Amazon Bedrock AgentCore를 사용하여 메모리 및 세션 인식 추론을 관리합니다. 내장된 ID 지원, 이벤트 처리 및 관찰 기능을 갖춘 에이전트를 배포합니다. Most Voted
  • B. Amazon API Gateway 및 Amazon EventBridge를 사용하여 Lambda 함수와 REST API를 액션으로 등록합니다. Amazon Bedrock AgentCore가 사용자 지정 오케스트레이션 코드 없이 Lambda 함수와 REST API를 호출할 수 있도록 설정합니다. Most Voted
  • C. 추론 및 대화 관리를 위해 Amazon Bedrock 에이전트를 사용합니다. 오케스트레이션을 위해 AWS Step Functions 및 Amazon SQS 큐를 사용합니다. 단계별 메모리 사용량을 줄이기 위해 에이전트 상태를 Amazon DynamoDB에 저장합니다.
  • D. 추론 로직을 Amazon API Gateway 뒤의 Amazon ECS에 컨테이너로 배포합니다. 메모리 데이터와 ID 데이터는 Amazon Aurora를 사용하여 저장합니다.
  • E. Amazon Kendra와 Amazon Bedrock을 사용하여 사용자 지정 RAG 파이프라인을 구축합니다. AWS Lambda를 사용하여 도구 호출을 오케스트레이션합니다. 에이전트 상태는 Amazon S3에 저장합니다.

Question #: 16
Topic #: 1

A company is using AWS Lambda and REST APIs to build a reasoning agent to automate support workflows. The system must preserve memory across interactions, share the relevant agent state, and support event-driven invocation and synchronous invocation. The system must also enforce access control and session-based permissions.
Which combination of steps provides the MOST scalable solution? (Choose two.)

  • A. Use Amazon Bedrock AgentCore to manage memory and session-aware reasoning. Deploy the agent with built-in identity support, event handling, and observability. Most Voted
  • B. Register the Lambda functions and the REST APIs as actions by using Amazon API Gateway and Amazon EventBridge. Enable Amazon Bedrock AgentCore to invoke the Lambda functions and the REST APIs without custom orchestration code. Most Voted
  • C. Use Amazon Bedrock Agents for reasoning and conversation management. Use AWS Step Functions and Amazon SQS queues for orchestration. Store the agent state in Amazon DynamoDB to maintain memory between steps.
  • D. Deploy the reasoning logic as a container on Amazon ECS behind Amazon API Gateway. Use Amazon Aurora to store memory data and identity data.
  • E. Build a custom RAG pipeline by using Amazon Kendra and Amazon Bedrock. Use AWS Lambda to orchestrate tool invocations. Store the agent state in Amazon S3.
