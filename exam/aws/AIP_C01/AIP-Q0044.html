이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. AWS Step Functions Express 워크플로를 사용하여 대화 흐름을 구성합니다. AWS Lambda 함수를 호출하여 추가 설명 로직을 실행합니다. 대화 기록은 Amazon RDS에 저장하고 세션 ID를 기본 키로 사용합니다.
  • B. AWS Step Functions Standard 워크플로를 사용하여 명확화 워크플로를 구성합니다. 워크플로 관리를 위해 콜백 대기 패턴을 포함합니다. 대화 기록은 Amazon DynamoD에 저장하고, 필요에 따라 용량을 구매하고 서버 측 암호화를 구성합니다. 가장 많은 표를 받은
  • C. Amazon API Gateway REST API를 사용하여 애플리케이션을 배포하고, 사용자 요청을 AWS Lambda 함수로 라우팅하여 대화 컨텍스트를 업데이트하고 검색합니다. 대화 기록은 Amazon S3에 저장하고 서버 측 암호화를 구성합니다. 각 상호 작용은 별도의 JSON 파일로 저장합니다.
  • D. AWS Lambda 함수를 사용하여 Amazon Bedrock 추론 API를 호출합니다. Amazon SQS 큐를 사용하여 확인 단계를 구성합니다. 대화 기록을 Amazon ElastiCache(Redis OSS) 클러스터에 저장합니다. 저장 데이터 암호화를 구성합니다.

Exam question from Amazon's AWS Certified Generative AI Developer - Professional AIP-C01
Question #: 44
Topic #: 1

A company is developing a generative AI (GenAI)-powered customer support application that uses Amazon Bedrock foundation models (FMs). The application must maintain conversational context across multiple interactions with the same user. The application must run clarification workflows to handle ambiguous user queries. The company must store encrypted records of each user conversation to use for personalization. The application must be able to handle thousands of concurrent users while responding to each user quickly.
Which solution will meet these requirements?

  • A. Use an AWS Step Functions Express workflow to orchestrate conversation flow. Invoke AWS Lambda functions to run clarification logic. Store conversation history in Amazon RDS and use session IDs as the primary key.
  • B. Use an AWS Step Functions Standard workflow to orchestrate clarification workflows. Include Wait for a Callback patterns to manage the workflows. Store conversation history in Amazon DynamoDPurchase on-demand capacity and configure server-side encryption. Most Voted
  • C. Deploy the application by using an Amazon API Gateway REST API to route user requests to an AWS Lambda function to update and retrieve conversation context. Store conversation history in Amazon S3 and configure server-side encryption. Save each interaction as a separate JSON file.
  • D. Use AWS Lambda functions to call Amazon Bedrock inference APIs. Use Amazon SQS queues to orchestrate clarification steps. Store conversation history in an Amazon ElastiCache (Redis OSS) cluster. Configure encryption at rest.

Selected Answer: A
. Express vs. Standard Workflows The requirement to handle thousands of concurrent users and respond quickly is the deciding factor between Step Functions types. Express Workflows: Designed for high-volume, short-duration (up to 5 minutes) events. They can handle over 100,000 events per second, making them ideal for a busy customer support API. Standard Workflows (Option B): These are intended for long-running, auditable processes (up to a year). They have much lower throughput limits and higher costs per execution, which would struggle with the "thousands of concurrent users" and "responding quickly" requirements.
