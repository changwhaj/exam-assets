한 보험 회사가 기존 Amazon SageMaker AI 인프라를 활용하여 고객이 보험료를 예측할 수 있는 웹 기반 애플리케이션을 운영하고 있습니다. 이 회사는 SageMaker AI 모델 학습에 사용되는 고객 데이터를 Amazon S3 버킷에 저장하고 있으며, 데이터 세트가 빠르게 증가하고 있습니다. 따라서 회사는 모델을 지속적으로 재학습할 수 있는 솔루션을 원합니다. 이 솔루션은 직원이 새로운 고객 데이터 파일을 S3 버킷에 업로드할 때마다 자동으로 모델을 재학습하고 애플리케이션에 재배포해야 합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. AWS Glue를 사용하여 업로드된 각 파일에 대해 ETL 작업을 실행합니다. ETL 작업이 AWS SDK를 사용하여 Sage Maker AI 모델 엔드포인트를 호출하도록 구성합니다. 엔드포인트에서 실시간 추론을 사용하여 업데이트된 고객 데이터 세트로 모델을 재학습한 후 다시 배포합니다.
  • B. 직원이 새 파일을 업로드할 때 이벤트를 생성하는 AWS Lambda 함수와 웹훅 핸들러를 생성합니다. 업데이트된 고객 데이터 세트로 모델을 재학습한 후 SageMaker Pipelines를 사용하여 모델을 재배포하도록 구성합니다. Amazon EventBridge를 사용하여 이벤트 버스를 생성합니다. Lambda 함수 이벤트를 소스로, SageMaker Pipelines를 대상으로 설정합니다.
  • C. AWS SDK 통합을 사용하여 AWS Step Functions Express 워크플로를 생성하고, 직원이 S3 버킷에 새 파일을 업로드할 때 S3 버킷에서 고객 데이터를 검색합니다. SageMaker Data Wrangler 플로우를 사용하여 S3 버킷에서 SageMaker Autopilot으로 데이터를 내보냅니다. 업데이트된 고객 데이터 세트로 모델을 재학습한 후 SageMaker Autopilot을 사용하여 모델을 다시 배포합니다.
  • D. AWS Step Functions Standard 워크플로를 생성합니다. 첫 번째 상태에서 직원이 S3 버킷에 새 파일을 업로드할 때 응답하도록 AWS Lambda 함수를 호출하도록 구성합니다. SageMaker Pipelines의 파이프라인을 사용하여 업데이트된 고객 데이터 세트로 재학습된 모델을 다시 배포합니다. 첫 번째 상태에서 응답을 받으면 워크플로의 다음 상태에서 파이프라인을 실행합니다. 가장 많은 표를 받은

Exam question from Amazon's AWS Certified Generative AI Developer - Professional AIP-C01

Topic #: 1

An insurance company uses existing Amazon SageMaker AI infrastructure to support a web-based application that allows customers to predict what their insurance premiums will be. The company stores customer data that is used to train the SageMaker AI model in an Amazon S3 bucket. The dataset is growing rapidly. The company wants a solution to continuously re-train the model. The solution must automatically re-train and re-deploy the model to the application when an employee uploads a new customer data file to the S3 bucket.
Which solution will meet these requirements?

  • A. Use AWS Glue to run an ETL job on each uploaded file. Configure the ETL job to use the AWS SDK to invoke the Sage Maker AI model endpoint. Use real-time inference with the endpoint to re-deploy the model after it is re-trained on the updated customer dataset.
  • B. Create an AWS Lambda function and webhook handlers to generate an event when an employee uploads a new file. Configure SageMaker Pipelines to re-deploy the model after it is re-trained on the updated customer dataset. Use Amazon EventBridge to create an event bus. Set the Lambda function event as the source and SageMaker Pipelines as the target.
  • C. Create an AWS Step Functions Express workflow with AWS SDK integrations to retrieve the customer data from the S3 bucket when an employee uploads a new file to the S3 bucket. Use a SageMaker Data Wrangler flow to export the data from the S3 bucket to SageMaker Autopilot. Use SageMaker Autopilot to re-deploy the model after it has been re-trained on the updated customer dataset.
  • D. Create an AWS Step Functions Standard workflow. Configure the first state to call an AWS Lambda function to respond when an employee uploads a new file to the S3 bucket. Use a pipeline in SageMaker Pipelines to re-deploy the model after it has been re-trained on the updated customer dataset. Use the next state in the workflow to run the pipeline when the first state receives a response. Most Voted
