한 회사가 AWS Lake Formation을 사용하여 여러 AWS 리전에 걸쳐 여러 사업부의 데이터베이스와 테이블을 포함하는 데이터 레이크를 구축했습니다. 이 회사는 Amazon Bedrock을 통해 파운데이션 모델(FM)을 사용하여 사기 탐지를 수행하려고 합니다. FM은 데이터 레이크에서 민감한 재무 데이터를 가져와야 합니다. 이 데이터에는 일부 고객 개인 식별 정보(PM)가 포함됩니다.

회사는 PM이 프로덕션 환경에 노출되지 않도록 하는 접근 제어 솔루션을 설계해야 합니다. FM은 특정 데이터 열에서 PM이 삭제된 승인된 데이터 하위 집합에만 접근할 수 있어야 합니다. 또한 모든 데이터 접근에 대한 감사 추적을 기록해야 합니다.

이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. 각 사업부 및 지역 조합별로 별도의 Amazon S3 버킷에 데이터 세트를 생성합니다. FM 교육 인스턴스에 할당된 IAM 역할을 기반으로 액세스를 제어하도록 S3 버킷 정책을 구성합니다. S3 액세스 로그를 사용하여 데이터 액세스를 추적합니다.
  • B. IAM 역할과 LF-Tag 표현식 기반의 Lake Formation 권한을 사용하여 인증하도록 FM을 구성합니다. 비즈니스 단위와 리전을 데이터베이스 및 테이블에 할당되는 LF-Tag로 정의합니다. AWS CloudTrail을 사용하여 데이터 액세스에 대한 포괄적인 감사 추적을 수집합니다. 가장 많은 표를 받은
  • C. Lake Formation의 특정 데이터베이스 및 테이블에 대해 직접 IAM 주체 권한 부여를 사용합니다. 액세스 요청을 기록하고 민감한 열을 추가로 필터링한 후 FM으로 데이터를 전송하는 사용자 지정 애플리케이션 계층을 생성합니다.
  • D. FM이 AWS STS에서 임시 자격 증명을 요청하도록 구성합니다. 비즈니스 단위 및 지역 필터를 적용하는 API에서 생성된 사전 서명된 S3 URL을 사용하여 데이터에 액세스합니다. AWS CloudTrail을 사용하여 데이터 액세스에 대한 포괄적인 감사 추적을 수집합니다.

Topic #: 1

A company uses AWS Lake Formation to set up a data lake that contains databases and tables for multiple business units across multiple AWS Regions. The company wants to use a foundation model (FM) through Amazon Bedrock to perform fraud detection. The FM must ingest sensitive financial data from the data lake. The data includes some customer personally identifiable information (PM).

The company must design an access control solution that prevents PI I from appearing in a production environment. The FM must access only authorized data subsets that have PH redacted from specific data columns. The company must capture audit trails for all data access.

Which solution will meet these requirements?

  • A. Create a separate dataset in a separate Amazon S3 bucket for each business unit and Region combination. Configure S3 bucket policies to control access based on IAM roles that are assigned to FM training instances. Use S3 access logs to track data access.
  • B. Configure the FM to authenticate by using IAM roles and Lake Formation permissions based on LF-Tag expressions. Define business units and Regions as LF-Tags that are assigned to databases and tables. Use AWS CloudTrail to collect comprehensive audit trails of data access. Most Voted
  • C. Use direct IAM principal grants on specific databases and tables in Lake Formation. Create a custom application layer that logs access requests and further filters sensitive columns before sending data to the FM.
  • D. Configure the FM to request temporary credentials from AWS STS. Access the data by using presigned S3 URLs that are generated by an API that applies business unit and Regional filters. Use AWS CloudTrail to collect comprehensive audit trails of data access.
