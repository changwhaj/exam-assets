주제 번호: 1

한 전자상거래 회사가 아마존 베드락 파운데이션 모델(FM)을 사용하여 생성형 AI 애플리케이션 개발을 위한 내부 플랫폼을 구축하고 있습니다. 개발자는 전자상거래 사용 사례에 맞춰 평가된 모델을 선택해야 합니다. 플랫폼은 대시보드에 텍스트 생성 및 요약 정확도 지표를 표시해야 합니다. 이 회사는 표준화된 평가 입력으로 사용할 맞춤형 전자상거래 데이터 세트를 보유하고 있습니다.
이러한 요구 사항을 충족하면서 운영 오버헤드를 최소화하는 단계 조합은 무엇일까요? (두 가지를 선택하세요.)

  • A. 데이터셋을 Amazon S3 버킷으로 가져옵니다. 평가 작업이 데이터셋에 접근할 수 있도록 적절한 IAM 권한과 CORS(교차 출처 리소스 공유) 권한을 부여합니다. 가장 많은 표를 받은
  • B. 데이터셋을 Amazon S3 버킷으로 가져옵니다. 평가 작업이 데이터셋에 접근할 수 있도록 적절한 IAM 권한과 VPC 엔드포인트 구성을 제공합니다.
  • C. Amazon Bedrock 콘솔에서 설정한 일정에 따라 모델 평가 작업을 생성하는 AWS Lambda 함수를 구성합니다. 데이터셋이 포함된 S3 버킷의 URI를 입력으로 제공합니다. 텍스트 생성에 대한 실세계 지식(RWK) 점수와 요약에 대한 BERT 점수를 측정하도록 평가 작업을 구성합니다. 작업 상태를 확인하고 사용자 지정 로그를 Amazon CloudWatch에 게시하는 두 번째 Lambda 함수를 구성합니다. 사용자 지정 Amazon CloudWatch Logs Insights 대시보드를 생성합니다. 가장 많은 표를 받은
  • D. Amazon SageMaker Clarify를 사용하여 예약된 시간에 모델 평가 작업을 생성합니다. 오픈 소스 프레임워크를 활용하여 표준화된 평가를 생성하고 실행합니다. 결과를 Amazon CloudWatch 네임스페이스에 게시합니다. 정확도 지표로 텍스트 생성 시 단어 오류율 점수와 요약 시 독성도를 사용합니다. AWS Lambda 함수를 구성하여 작업 상태를 확인하고 사용자 지정 로그를 CloudWatch에 게시합니다. 사용자 지정 Amazon CloudWatch Logs Insights 대시보드를 생성합니다.
  • E. fmevals 또는 ragas 프레임워크를 사용하여 S3 버킷의 데이터 세트를 활용하는 평가를 실행하는 Amazon SageMaker AI 노트북 작업을 예약된 시간에 실행합니다. 노트북에 Python 코드를 작성하여 함수 모듈(FM)에 대한 InvokeModel API를 직접 호출하고 응답을 처리하여 평가합니다. 작업 상태 및 결과를 Amazon CloudWatch Logs에 게시하여 텍스트 생성에 대한 실제 지식(RWK) 점수와 요약에 대한 유해성 점수를 정확도 지표로 측정합니다. 사용자 지정 CloudWatch Logs Insights 대시보드를 생성합니다.

Exam question from Amazon's AWS Certified Generative AI Developer - Professional AIP-C01
Question #: 34
Topic #: 1

An ecommerce company is building an internal platform to develop generative AI applications by using Amazon Bedrock foundation models (FMs). Developers need to select models based on evaluations that are aligned to ecommerce use cases. The platform must display accuracy metrics for text generation and summarization in dashboards. The company has custom ecommerce datasets to use as standardized evaluation inputs.
Which combination of steps will meet these requirements with the LEAST operational overhead? (Choose two.)

  • A. Import the datasets to an Amazon S3 bucket. Provide appropriate IAM permissions and cross-origin resource sharing (CORS) permissions to give the evaluation jobs access to the datasets. Most Voted
  • B. Import the datasets to an Amazon S3 bucket. Provide appropriate IAM permissions and a VPC endpoint configuration to give the evaluation jobs access to the datasets.
  • C. Configure an AWS Lambda function to create model evaluation jobs on a schedule in the Amazon Bedrock console. Provide the URI of the S3 bucket that contains the datasets as an input. Configure the evaluation jobs to measure the real world knowledge (RWK) score for text generation and BERT Score for summarization. Configure a second Lambda function to check the status of the jobs and publish custom logs to Amazon CloudWatch. Create a custom Amazon CloudWatch Logs Insights dashboard. Most Voted
  • D. Use Amazon SageMaker Clarify on a schedule to create model evaluation jobs. Use open source frameworks to create and run standardized evaluations. Publish results to Amazon CloudWatch namespaces. Use the word error rate score for text generation and toxicity for summarization as metrics for accuracy. Configure an AWS Lambda function to check the status of the jobs and publish custom logs to CloudWatch. Create a custom Amazon CloudWatch Logs Insights dashboard.
  • E. Run an Amazon SageMaker AI notebook job on a schedule by using the fmevals or ragas framework to run evaluations that use the datasets in the S3 bucket. Write Python code in the notebook that makes direct InvokeModel API calls to the FMs and processes their responses for evaluation. Publish job status and results to Amazon CloudWatch Logs to measure the real world knowledge (RWK) score for text generation and toxicity for summarization as metrics for accuracy. Create a custom CloudWatch Logs Insights dashboard.
