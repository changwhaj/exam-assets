금융 서비스 회사가 Amazon Bedrock 기반의 파운데이션 모델(FM)을 사용하는 고객 서비스 AI 어시스턴트 애플리케이션을 개발 중입니다. 이 애플리케이션은 추론 과정을 문서화하고 검색 증강 생성(RAG)에 사용된 출처를 명시하여 투명한 답변을 제공해야 합니다. 또한 모든 사용자 답변에 대한 포괄적인 감사 추적 기록을 남겨야 합니다. 최대 10,000명의 동시 사용자를 처리할 수 있어야 하며, 각 고객 문의에 2초 이내에 응답해야 합니다.
이러한 요구 사항을 충족하면서 운영 오버헤드를 최소화하는 솔루션은 무엇일까요?

  • A. Amazon Bedrock 에이전트에 대한 추적을 활성화합니다. FM이 증거 프레젠테이션을 제공하도록 안내하는 구조화된 프롬프트를 구성합니다. RAG를 활성화하기 위해 Amazon Bedrock 기술 자료를 데이터 소스와 통합합니다. 애플리케이션이 권위 있는 콘텐츠를 참조하고 인용하도록 구성합니다. 다중 AZ 아키텍처에 애플리케이션을 배포합니다. Amazon API Gateway 및 AWS Lambda 함수를 사용하여 애플리케이션을 확장합니다. Amazon CloudFront를 사용하여 지연 시간이 짧은 전송을 제공합니다. 가장 많은 표를 받은
  • B. Amazon Bedrock 에이전트에 대한 추적 기능을 활성화합니다. Amazon OpenSearch Service와 사용자 지정 RAG 파이프라인을 통합하여 출처를 검색하고 인용합니다. 검색된 증거를 제시하도록 구조화된 프롬프트를 구성합니다. Amazon API Gateway REST API 뒤에 애플리케이션을 배포합니다. AWS Lambda 함수와 Amazon CloudFront를 사용하여 애플리케이션을 확장하고 지연 시간을 최소화합니다. 로그를 Amazon S3에 저장하고 AWS CloudTrail을 사용하여 감사 추적을 기록합니다.
  • C. Amazon CloudWatch를 사용하여 지연 시간과 오류율을 모니터링합니다. 소스 코드를 인용하기 위해 모델 프롬프트를 애플리케이션 백엔드에 직접 삽입합니다. 감사 목적으로 애플리케이션과 사용자 간의 상호 작용 기록을 Amazon RDS에 저장합니다.
  • D. 생성된 답변과 증빙 자료를 Amazon S3 버킷에 저장합니다. 감사 목적으로 버킷에 버전 관리를 활성화합니다. AWS Glue를 사용하여 검색된 문서를 카탈로그화합니다. Amazon Athena에서 검색된 문서를 처리하여 주기적인 규정 준수 보고서를 생성합니다.

Exam question from Amazon's AWS Certified Generative AI Developer - Professional AIP-C01
Question #: 62
Topic #: 1

A financial services company is developing a customer service AI assistant application that uses a foundation model (FM) in Amazon Bedrock. The application must provide transparent responses by documenting reasoning and by citing sources that are used for Retrieval Augmented Generation (RAG). The application must capture comprehensive audit trails for all responses to users. The application must be able to serve up to 10,000 concurrent users and must respond to each customer inquiry within 2 seconds.
Which solution will meet these requirements with the LEAST operational overhead?

  • A. Enable tracing for Amazon Bedrock agents. Configure structured prompts that direct the FM to provide evidence presentations. Integrate Amazon Bedrock knowledge bases with data sources to enable RAG. Configure the application to reference and cite authoritative content. Deploy the application in a Multi-AZ architecture. Use Amazon API Gateway and AWS Lambda functions to scale the application. Use Amazon CloudFront to provide low-latency delivery. Most Voted
  • B. Enable tracing for Amazon Bedrock agents. Integrate a custom RAG pipeline with Amazon OpenSearch Service to retrieve and cite sources. Configure structured prompts to present retrieved evidence. Deploy the application behind an Amazon API Gateway REST API. Use AWS Lambda functions and Amazon CloudFront to scale the application and to provide low latency. Store logs in Amazon S3 and use AWS CloudTrail to capture audit trails.
  • C. Use Amazon CloudWatch to monitor latency and error rates. Embed model prompts directly in the application backend to cite sources. Store application interactions with users in Amazon RDS for audits.
  • D. Store generated responses and supporting evidence in an Amazon S3 bucket. Enable versioning on the bucket for audits. Use AWS Glue to catalog retrieved documents. Process the retrieved documents in Amazon Athena to generate periodic compliance reports.
