한 회사가 온프레미스 Apache Hadoop 클러스터를 Amazon EMR로 마이그레이션할 계획입니다. 또한 데이터 카탈로그를 영구 스토리지 솔루션으로 마이그레이션해야 합니다.
현재 이 회사는 Hadoop 클러스터의 온프레미스 Apache Hive 메타스토어에 데이터 카탈로그를 저장하고 있습니다. 데이터 카탈로그 마이그레이션을 위해 서버리스 솔루션이 필요합니다.
이러한 요구 사항을 가장 비용 효율적으로 충족하는 솔루션은 무엇일까요?

  • A. AWS Database Migration Service(AWS DMS)를 사용하여 Hive 메타스토어를 Amazon S3로 마이그레이션합니다. AWS Glue Data Catalog가 Amazon S3를 스캔하여 데이터 카탈로그를 생성하도록 구성합니다.
  • B. Amazon EMR에 Hive 메타스토어를 구성합니다. 기존 온프레미스 Hive 메타스토어를 Amazon EMR로 마이그레이션합니다. AWS Glue 데이터 카탈로그를 사용하여 회사 데이터 카탈로그를 외부 데이터 카탈로그로 저장합니다. 가장 많은 표를 받은
  • C. Amazon EMR에 외부 Hive 메타스토어를 구성합니다. 기존 온프레미스 Hive 메타스토어를 Amazon EMR로 마이그레이션합니다. Amazon Aurora MySQL을 사용하여 회사 데이터 카탈로그를 저장합니다.
  • D. Amazon EMR에 새 Hive 메타스토어를 구성합니다. 기존 온프레미스 Hive 메타스토어를 Amazon EMR로 마이그레이션합니다. 새 메타스토어를 회사 데이터 카탈로그로 사용합니다.

Exam question from Amazon's AWS Certified Data Engineer - Associate DEA-C01
Question #: 54
Topic #: 1

A company is planning to migrate on-premises Apache Hadoop clusters to Amazon EMR. The company also needs to migrate a data catalog into a persistent storage solution.
The company currently stores the data catalog in an on-premises Apache Hive metastore on the Hadoop clusters. The company requires a serverless solution to migrate the data catalog.
Which solution will meet these requirements MOST cost-effectively?

  • A. Use AWS Database Migration Service (AWS DMS) to migrate the Hive metastore into Amazon S3. Configure AWS Glue Data Catalog to scan Amazon S3 to produce the data catalog.
  • B. Configure a Hive metastore in Amazon EMR. Migrate the existing on-premises Hive metastore into Amazon EMR. Use AWS Glue Data Catalog to store the company's data catalog as an external data catalog. Most Voted
  • C. Configure an external Hive metastore in Amazon EMR. Migrate the existing on-premises Hive metastore into Amazon EMR. Use Amazon Aurora MySQL to store the company's data catalog.
  • D. Configure a new Hive metastore in Amazon EMR. Migrate the existing on-premises Hive metastore into Amazon EMR. Use the new metastore as the company's data catalog.
