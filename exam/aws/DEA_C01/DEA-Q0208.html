주제 번호: 1

한 회사가 개인 식별 정보(PII)와 비PII 데이터가 포함된 JSON 파일을 보유하고 있습니다. 회사는 해당 데이터를 조회 및 분석할 수 있도록 공개해야 합니다.

비PII 데이터는 회사 내 모든 구성원이 접근할 수 있어야 하며, PII 데이터는 특정 직원 그룹만 접근할 수 있어야 합니다.

이러한 요구 사항을 충족하면서 운영 오버헤드를 최소화하는 솔루션은 무엇일까요?

  • A. JSON 파일을 Amazon S3 버킷에 저장합니다. AWS Glue를 구성하여 파일을 개인 식별 정보(PII)가 포함된 파일과 PII가 아닌 데이터가 포함된 파일로 분할합니다. 분할된 두 파일을 각각 별도의 S3 버킷에 저장합니다. 사용자 유형에 따라 각 버킷에 필요한 접근 권한을 부여합니다.
  • B. JSON 파일을 Amazon S3 버킷에 저장합니다. Amazon Macie를 사용하여 개인 식별 정보(PII)를 식별하고 사용자 유형에 따라 액세스 권한을 부여합니다.
  • C. JSON 파일을 Amazon S3 버킷에 저장합니다. AWS Lake Formation에 파일 스키마를 등록합니다. Lake Formation 권한을 사용하여 사용자 유형에 따라 필요한 데이터에 대한 액세스 권한을 부여합니다. 가장 많은 표를 받은
  • D. Amazon RDS PostgreSQL 데이터베이스 두 개를 생성합니다. 개인 식별 정보(PII)와 비개인 식별 정보를 각각 별도의 데이터베이스에 로드합니다. 사용자 유형에 따라 데이터베이스에 대한 접근 권한을 부여합니다.

Exam question from Amazon's AWS Certified Data Engineer - Associate DEA-C01
Question #: 208
Topic #: 1

A company has as JSON file that contains personally identifiable information (PII) data and non-PII data. The company needs to make the data available for querying and analysis.

The non-PII data must be available to everyone in the company. The PII data must be available only to a limited group of employees.

Which solution will meet these requirements with the LEAST operational overhead?

  • A. Store the JSON file in an Amazon S3 bucket. Configure AWS Glue to split the file into one file that contains the PII data and one file that contains the non-PII data. Store the output files in separate S3 buckets. Grant the required access to the buckets based on the type of user.
  • B. Store the JSON file in an Amazon S3 bucket. Use Amazon Macie to identify PII data and to grant access based on the type of user.
  • C. Store the JSON file in an Amazon S3 bucket. Catalog the file schema in AWS Lake Formation. Use Lake Formation permissions to provide access to the required data based on the type of user. Most Voted
  • D. Create two Amazon RDS PostgreSQL databases. Load the PII data and the non-PII data into the separate databases. Grant access to the databases based on the type of user.
