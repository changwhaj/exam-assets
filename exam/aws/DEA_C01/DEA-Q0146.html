한 회사가 새로운 분석팀을 위해 데이터 레이크를 구축하고 있습니다. 데이터 저장에는 Amazon S3를, 쿼리 분석에는 Amazon Athena를 사용하고 있습니다. Amazon S3에 저장된 모든 데이터는 Apache Parquet 형식입니다.

회사 데이터센터에는 새로운 Oracle 데이터베이스가 소스 시스템으로 운영되고 있습니다. Oracle 데이터베이스에는 70개의 테이블이 있으며, 모든 테이블에는 기본 키가 있습니다. 소스 시스템의 데이터는 때때로 변경될 수 있습니다. 회사는 매일 이 테이블의 데이터를 데이터 레이크로 수집하고자 합니다.

어떤 솔루션이 최소한의 노력으로 이 요구 사항을 충족할 수 있을까요?

  • A. Amazon EMR에서 Apache Sqoop 작업을 생성하여 Oracle 데이터베이스에서 데이터를 읽어옵니다. Sqoop 작업이 Parquet 형식으로 데이터를 Amazon S3에 저장하도록 구성합니다.
  • B. Oracle 데이터베이스에 대한 AWS Glue 연결을 생성합니다. 데이터를 점진적으로 수집하고 Parquet 형식으로 Amazon S3에 저장하는 AWS Glue 북마크 작업을 생성합니다.
  • C. 지속적인 복제를 위해 AWS 데이터베이스 마이그레이션 서비스(AWS DMS) 작업을 생성합니다. 소스는 Oracle 데이터베이스로 설정하고, 대상은 Amazon S3로 설정합니다. 데이터를 Parquet 형식으로 저장하도록 작업을 구성합니다. 가장 많은 표를 받은
  • D. Amazon RDS에 Oracle 데이터베이스를 생성합니다. AWS Database Migration Service(AWS DMS)를 사용하여 온프레미스 Oracle 데이터베이스를 Amazon RDS로 마이그레이션합니다. 테이블에 트리거를 구성하여 AWS Lambda 함수를 호출하고 변경된 레코드를 Parquet 형식으로 Amazon S3에 기록합니다.

Exam question from Amazon's AWS Certified Data Engineer - Associate DEA-C01
Question #: 146
Topic #: 1

A company is building a data lake for a new analytics team. The company is using Amazon S3 for storage and Amazon Athena for query analysis. All data that is in Amazon S3 is in Apache Parquet format.

The company is running a new Oracle database as a source system in the company’s data center. The company has 70 tables in the Oracle database. All the tables have primary keys. Data can occasionally change in the source system. The company wants to ingest the tables every day into the data lake.

Which solution will meet this requirement with the LEAST effort?

  • A. Create an Apache Sqoop job in Amazon EMR to read the data from the Oracle database. Configure the Sqoop job to write the data to Amazon S3 in Parquet format.
  • B. Create an AWS Glue connection to the Oracle database. Create an AWS Glue bookmark job to ingest the data incrementally and to write the data to Amazon S3 in Parquet format.
  • C. Create an AWS Database Migration Service (AWS DMS) task for ongoing replication. Set the Oracle database as the source. Set Amazon S3 as the target. Configure the task to write the data in Parquet format. Most Voted
  • D. Create an Oracle database in Amazon RDS. Use AWS Database Migration Service (AWS DMS) to migrate the on-premises Oracle database to Amazon RDS. Configure triggers on the tables to invoke AWS Lambda functions to write changed records to Amazon S3 in Parquet format.
