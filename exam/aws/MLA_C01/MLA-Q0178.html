한 은행이 Amazon SageMaker AI를 사용하여 새로운 상품에 적합한 고객을 판별하는 머신러닝 모델을 구축해야 합니다. 은행은 SageMaker AI가 직접 지원하는 알고리즘을 사용해야 하며, 해당 모델은 은행의 규제 기관에 설명 가능해야 합니다.

이러한 요구 사항을 충족하는 모델링 접근 방식은 무엇일까요?

  • A. Object2Vec 알고리즘을 사용하여 모델을 학습시킵니다.
  • B. 선형 학습기 알고리즘을 사용하여 모델을 학습시킵니다.
  • C. 신경망을 훈련시킵니다.
  • D. k-평균 알고리즘을 사용하여 모델을 학습시킵니다.

A bank needs to use Amazon SageMaker AI to create an ML model to determine which customers qualify for a new product. The bank must use algorithms that SageMaker AI directly supports. The model must be explainable to the bank’s regulators.

Which modeling approach will meet these requirements?

  • A. Train the model by using the Object2Vec algorithm.
  • B. Train the model by using the linear learner algorithm.
  • C. Train a neural network.
  • D. Train the model by using the k-means algorithm.

Answer: B — Train the model by using the Linear Learner algorithm. Why: The task is a supervised classification (qualify vs. not qualify). SageMaker Linear Learner is a built‑in algorithm that supports binary/multiclass classification and regression. Linear models are highly explainable (feature coefficients and signs indicate direction and strength), which suits regulatory requirements.
