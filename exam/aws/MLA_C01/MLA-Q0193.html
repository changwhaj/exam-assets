An ML engineer is using Amazon QuickSight anomaly detection to detect very high or very low machine operating temperatures compared to normal. The ML engineer sets the Severity parameter to Low and above. The ML engineer sets the Direction parameter to All.

What effect will the ML engineer observe in the anomaly detection results if the ML engineer changes the Direction parameter to Lower than expected?

  • A. Increased anomaly identification frequency and increased recall
  • B. Decreased anomaly identification frequency and decreased recall
  • C. Increased anomaly identification frequency and decreased recall
  • D. Decreased anomaly identification frequency and increased recall

Selected Answer: B
Answer: B — Decreased anomaly identification frequency and decreased recall. Why: The Direction control in QuickSight anomaly detection determines whether the detector flags higher, lower, or all anomalies. Changing it from All to Lower than expected restricts detection to only low values, so you’ll see fewer anomalies overall. Because high anomalies will no longer be considered, the detector will miss those true positives, which reduces recall when measured against both very high and very low anomalies combined. (Severity remains at “Low and above,” which governs sensitivity, but the narrowed direction still lowers total findings.)
