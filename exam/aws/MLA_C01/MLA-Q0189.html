한 회사가 머신러닝 학습용 데이터를 저장하기 위해 NFS 기반 데이터 저장소를 사용하고 있습니다. Linux 기반 시스템에서 이 데이터 저장소에 접근합니다.

이 회사는 온프레미스 서버와 데이터를 사용할 Amazon SageMaker AI 노트북에서 공유 데이터 저장소에 접근할 수 있도록 하이브리드 시스템이 필요합니다. 데이터 생산자에게는 파일 잠금이 필수적입니다.

이러한 요구 사항을 충족하는 AWS 스토리지 솔루션은 무엇일까요?

  • A. 데이터를 저장할 위치로 Amazon S3 버킷을 사용합니다. Mountpoint for Amazon S3를 사용하여 S3 버킷을 온프레미스 서버 및 SageMaker AI 노트북에 마운트합니다.
  • B. Amazon Elastic File System(Amazon EFS) 파일 시스템을 사용하여 데이터를 저장합니다. 해당 파일 시스템을 온프레미스 서버와 SageMaker AI 노트북에 마운트합니다.
  • C. Amazon FSx for Lustre 파일 시스템을 사용하여 데이터를 저장합니다. 해당 파일 시스템을 온프레미스 서버와 SageMaker AI 노트북에 마운트합니다.
  • D. 데이터를 저장하기 위해 Amazon Elastic Block Store(Amazon EBS) 볼륨을 사용합니다. 해당 볼륨을 온프레미스 서버와 SageMaker AI 노트북에 마운트합니다.

A company uses an NFS-based data store to store data for ML training. Linux-based systems access the data store.

The company needs a hybrid system to make the shared data store accessible to on-premises servers and Amazon SageMaker AI notebooks that will consume the data. File locking is required for the data producers.

Which AWS storage solution will meet these requirements?

  • A. Use an Amazon S3 bucket to store the data. Use Mountpoint for Amazon S3 to mount the S3 bucket to the on-premises servers and the SageMaker AI notebooks.
  • B. Use an Amazon Elastic File System (Amazon EFS) file system to store the data. Mount the file system to the on-premises servers and the SageMaker AI notebooks.
  • C. Use an Amazon FSx for Lustre file system to store the data. Mount the file system to the on-premises servers and the SageMaker AI notebooks.
  • D. Use an Amazon Elastic Block Store (Amazon EBS) volume to store the data. Mount the volume to the on-premises servers and the SageMaker AI notebooks.

Answer: B — Use an Amazon EFS file system and mount it from on‑prem servers and SageMaker notebooks. Why this fits NFS-based requirement: Amazon EFS is a fully managed NFSv4/v4.1 file system, so it matches the existing NFS workflows. Hybrid access: EFS can be mounted from on‑premises over AWS Direct Connect or VPN and from compute in your VPC (e.g., SageMaker notebooks/Studio kernels running in the VPC). File locking: EFS supports POSIX semantics including advisory file locking, which the data producers require. Shared, scalable storage: It supports many concurrent clients with elastic capacity—ideal for shared ML datasets.
