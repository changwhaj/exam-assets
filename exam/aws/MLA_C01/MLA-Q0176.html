An ML engineer is using Amazon SageMaker Canvas to build a custom ML model from an imported dataset. The ML engineer wants the model to make continuous numeric predictions based on 10 years of data.

Which metric should the ML engineer use to evaluate the model’s performance?

  • A. Accuracy
  • B. InferenceLatency
  • C. Area Under the ROC Curve (AUC)
  • D. Root mean square error (RMSE)

정답: D — 평균 제곱근 오차(RMSE) 이유: 연속적인 수치 값을 예측하는 문제이므로 회귀 분석 문제입니다. RMSE는 예측 오차의 평균 크기(목표값과 동일한 단위 사용)를 측정하며, 오차가 클수록 더 큰 불이익을 주기 때문에 회귀 분석 성능을 평가하는 표준 지표입니다. 다른 선택지가 아닌 이유는 다음과 같습니다. A. 정확도 – 분류 문제이지 회귀 분석이 아닙니다. B. 추론 지연 시간 – 예측 품질이 아닌 속도를 측정합니다. C. AUC(ROC) – 이진 분류 임계값에 사용되는 지표이지 연속적인 목표값에 사용되는 지표가 아닙니다.

Selected Answer: D
Answer: D — Root mean square error (RMSE) Why: You’re predicting continuous numeric values, so this is a regression problem. RMSE measures the average magnitude of prediction errors (in the same units as the target), penalizing larger errors more heavily—making it a standard metric for evaluating regression performance. Why not the others: A. Accuracy – for classification, not regression. B. InferenceLatency – measures speed, not predictive quality. C. AUC (ROC) – for binary classification thresholds, not continuous targets.
