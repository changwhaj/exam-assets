An ML engineer is training a text generation model on Amazon SageMaker AI. After several epochs, the loss function does not converge, and the model’s accuracy on the validation dataset starts to show oscillating results.

The ML engineer needs to ensure that the model achieves generalization.

Which solution will meet this requirement?

  • A. Increase the learning rate and decrease the mini-batch size.
  • B. Increase the learning rate as the number of epochs increases.
  • C. Decrease the learning rate and increase the mini-batch size.
  • D. Decrease the learning rate and decrease the mini-batch size.

Answer: C — Decrease the learning rate and increase the mini‑batch size. Why: Oscillating validation accuracy and a loss that won’t converge are classic signs that the learning rate is too high and/or the batch size is too small, causing noisy gradient estimates. Lowering the learning rate helps the optimizer take smaller, more stable steps toward a minimum, and increasing the mini‑batch size reduces variance in the gradients—both of which improve convergence and typically aid generalization. Why not the others: A/B (increase LR) → Likely worsens the oscillation and prevents convergence. D (decrease LR + decrease batch) → The smaller batch keeps gradient noise high; may still oscillate.
