선택된 답변: D
정답은 D입니다. 머신러닝 모델이 생성될 때 자동으로 버전을 생성하려면 Amazon SageMaker Model Registry를 사용하는 것이 좋습니다. 이 시스템은 자동 버전 관리, 프로덕션 환경에서 사용할 모델 카탈로그화, 모델 메타데이터 추적, 모델 승인 워크플로 관리를 제공합니다. 중앙 집중식 레지스트리 시스템을 통해 다양한 모델 버전을 쉽게 추적하고 프로덕션 환경에서 모델 배포에 대한 거버넌스를 유지할 수 있습니다. SageMaker ML Lineage Tracking(옵션 C)도 머신러닝 아티팩트 간의 관계를 추적할 수 있지만, 종속성 및 데이터 계보 추적에 중점을 두고 있으며, 모델의 여러 버전을 관리하는 데 필요한 자동 버전 관리 기능은 제공하지 않습니다.

The correct answer is D: To automatically create versions of ML models as they are created, the company should use Amazon SageMaker Model Registry, which provides automatic versioning, cataloging of models for production use, tracking of model metadata, and management of model approval workflows. This centralized registry system makes it easy to track different versions of models and maintain governance over model deployment in production environments. While SageMaker ML Lineage Tracking (option C) can track relationships between ML artifacts, it focuses on tracking dependencies and data lineage rather than providing the automatic versioning capability needed for managing multiple iterations of models.
