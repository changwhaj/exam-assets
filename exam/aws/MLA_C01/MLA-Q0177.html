한 회사가 두 개의 새로운 머신러닝 모델을 구축, 학습 및 최적화했습니다.

• 모델 A는 IP 주소, 위치 및 사용자 자격 증명을 기반으로 거래의 사기 여부를 감지합니다. 이 모델은 거래가 발생할 때마다 실행됩니다.
• 모델 B는 과거 판매 데이터를 기반으로 다음 달 총 매출액을 예측합니다. 이 모델은 매달 한 번씩 실행됩니다.

회사는 Amazon SageMaker AI를 사용하여 두 모델 모두를 운영 환경에 배포해야 합니다.

이러한 요구 사항을 충족하기 위해 어떤 호스팅 솔루션을 사용하는 것이 가장 좋을까요?

  • A. 두 모델을 하나의 컨테이너에 호스팅하고 하나의 실시간 엔드포인트 뒤에 배치합니다.
  • B. 비동기 엔드포인트를 사용하는 호스트 모델 A. 실시간 엔드포인트를 사용하는 호스트 모델 B.
  • C. 모델 A를 실시간 엔드포인트로 호스팅합니다. 모델 B에는 배치 변환을 사용합니다.
  • D. 모델 A에는 배치 변환을 사용하고, 모델 B는 비동기 엔드포인트를 사용하여 호스팅합니다.

A company has built, trained, and tuned two new ML models:

• Model A detects if a transaction is fraudulent based on the IP address, location, and user credentials. This model will be accessed every time a transaction occurs.
• Model B forecasts sales totals for the next month based on historical sales data. This model will be accessed one time each month.

The company must deploy both models to production by using Amazon SageMaker AI.

Which hosting solution for the models should the company use to meet these requirements?

  • A. Host both models in one container behind one real-time endpoint.
  • B. Host Model A with an asynchronous endpoint. Host Model B with a real-time endpoint.
  • C. Host Model A with a real-time endpoint. Use batch transform for Model B.
  • D. Use batch transform for Model A. Host Model B with an asynchronous endpoint.

Selected Answer: C
Answer: C — Host Model A with a real‑time endpoint. Use Batch Transform for Model B. Why this fits: Model A (fraud detection) is invoked on every transaction, so it requires low‑latency, synchronous inference. A real‑time SageMaker endpoint is designed for millisecond response times and autoscaling to handle traffic spikes. Model B (monthly sales forecast) runs once per month over historical data, which is a classic offline/batch use case. SageMaker Batch Transform efficiently processes large datasets without keeping an endpoint running, reducing cost and operational overhead.
