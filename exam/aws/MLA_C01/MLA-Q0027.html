The model is using sensitive data. An ML engineer needs to implement a solution to identify and remove the sensitive data.

  • B. Deploy the model on an Amazon Elastic Container Service (Amazon ECS) cluster that uses AWS Fargate. Create an AWS Batch job to identify and remove the sensitive data.
  • C. Use Amazon Macie to identify the sensitive data. Create a set of AWS Lambda functions to remove the sensitive data. Most Voted
  • D. Use Amazon Comprehend to identify the sensitive data. Launch Amazon EC2 instances to remove the sensitive data.

This is a tricky question (the kind AWS loves to ask) as the key term is "Operational Overhead". Macie is a tool for large scale PII discovery. Comprehend is for Text-specific PII detection and redaction. Yet, Lambda doesn't require much if any operational attention vs an EC2 instance which should be monitored and perhaps scaled. The best scenario would be Comprehend with Lambda. However Macie (which can be used in 'near real time') will work, it's like using a crowbar to remove a nail. D is a better solution but C 'technically' less operational overhead. Be aware of those tricky terms like "operational overhead" and "least effort". They greatly change the nature of the solution.
