핫스팟 -
한 회사가 Amazon S3에 .csv 파일 형식으로 과거 데이터를 저장하고 있습니다. .csv 파일의 행과 열 중 일부만 데이터가 채워져 있고, 열에는 레이블이 지정되어 있지 않습니다. 머신러닝 엔지니어는 회사가 머신러닝 모델 학습에 사용할 수 있도록 데이터를 준비하고 저장해야 합니다.
다음 목록에서 이 작업을 수행하는 올바른 단계를 선택하고 순서를 정하세요. 각 단계는 한 번만 선택하거나 전혀 선택하지 않아야 합니다. (세 가지 단계를 선택하고 순서를 정하세요.)
• 데이터 클리닝 및 특징 엔지니어링을 위해 Amazon SageMaker 배치 변환 작업을 생성합니다.
• 결과 데이터를 Amazon S3에 다시 저장합니다.
• Amazon Athena를 사용하여 스키마와 사용 가능한 열을 추론합니다.
• AWS Glue 크롤러를 사용하여 스키마와 사용 가능한 열을 추론합니다.
• AWS Glue DataBrew를 사용하여 데이터 클리닝 및 특징 엔지니어링을 수행합니다.

HOTSPOT -
A company stores historical data in .csv files in Amazon S3. Only some of the rows and columns in the .csv files are populated. The columns are not labeled. An ML engineer needs to prepare and store the data so that the company can use the data to train ML models.
Select and order the correct steps from the following list to perform this task. Each step should be selected one time or not at all. (Select and order three.)
• Create an Amazon SageMaker batch transform job for data cleaning and feature engineering.
• Store the resulting data back in Amazon S3.
• Use Amazon Athena to infer the schemas and available columns.
• Use AWS Glue crawlers to infer the schemas and available columns.
• Use AWS Glue DataBrew for data cleaning and feature engineering.
