음악 스트리밍 회사는 애플리케이션에서 수집한 곡 평점 데이터를 아마존 S3 버킷에 지속적으로 스트리밍합니다. 이 회사는 해당 평점 데이터를 아마존 SageMaker AI 모델의 학습 및 추론에 활용하고자 합니다. 이미

S3 버킷을 데이터 소스로 사용하는 AWS Glue 데이터 카탈로그를 구축해 놓은 상태입니다. 머신러닝 엔지니어는 이 데이터를 저장할 저장소를 생성하는 솔루션을 구현해야 합니다. 이 솔루션은 배치 학습과 실시간 추론 과정 모두에서 데이터의 동기화를 보장해야 합니다.

이러한 요구 사항을 충족하는 솔루션은 무엇일까요?

  • A. S3 버킷에서 SageMaker Feature Store로 데이터를 가져옵니다. 태그와 인덱스를 적용합니다.
  • B. Amazon Athena를 사용합니다. CREATE TABLE AS SELECT (CTAS) 쿼리를 사용하여 데이터를 그룹화하는 테이블을 생성합니다.
  • C. AWS Lake Formation을 사용합니다. 태그 기반으로 데이터를 제어합니다.
  • D. SageMaker Data Wrangler의 데이터 인사이트 생성 기능을 사용합니다.

A music streaming company constantly streams song ratings from an application to an Amazon S3 bucket. The company wants to use the ratings as an input for training and inference of an Amazon SageMaker AI model.

The company has an AWS Glue Data Catalog that is configured with the S3 bucket as the source. An ML engineer needs to implement a solution to create a repository for this data. The solution must ensure that the data stays synchronized during batch training and real-time inference.

Which solution will meet these requirements?

  • A. Ingest data into SageMaker Feature Store from the S3 bucket. Apply tags and indexes.
  • B. Use Amazon Athena. Create tables by using CREATE TABLE AS SELECT (CTAS) queries to group data.
  • C. Use AWS Lake Formation. Apply tag-based control on the data.
  • D. Use the Generate Data Insights function in SageMaker Data Wrangler.

Answer: A — Ingest data into SageMaker Feature Store from the S3 bucket; apply tags and indexes. Why this meets the requirements Centralized, purpose-built repository for ML features: Amazon SageMaker Feature Store provides a managed feature repository designed for both training (batch) and inference (real-time). Online + Offline stores kept in sync: When you ingest ratings into a Feature Group with the online store enabled, SageMaker automatically writes to the low‑latency online store (for real-time inference) and to the offline store in Amazon S3 (for batch training). This setup ensures your features remain consistent and synchronized across both paths.
