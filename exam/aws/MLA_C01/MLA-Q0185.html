Linear regression whose coefficients should shrink but not become zero → L2 regularization (Ridge) Why: L2 penalizes the sum of squared coefficients, shrinking them toward zero while rarely setting any exactly to zero. Good for stabilizing estimates without feature elimination. Polynomial regression with irrelevant polynomial terms that should be eliminated → L1 regularization (Lasso) Logistic regression with highly correlated features to eliminate redundant predictors → L1 regularization (Lasso)
