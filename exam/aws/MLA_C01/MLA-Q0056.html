An ML engineer needs to use Amazon SageMaker to fine-tune a large language model (LLM) for text summarization. The ML engineer must follow a low-code no-code (LCNC) approach.
Which solution will meet these requirements?

  • A. Use SageMaker Studio to fine-tune an LLM that is deployed on Amazon EC2 instances.
  • B. Use SageMaker Autopilot to fine-tune an LLM that is deployed by a custom API endpoint.
  • C. Use SageMaker Autopilot to fine-tune an LLM that is deployed on Amazon EC2 instances.
  • D. Use SageMaker Autopilot to fine-tune an LLM that is deployed by SageMaker JumpStart. Most Voted

Another tricky AWS question... Deploying a SageMaker Autopilot trained model with SageMaker JumpStart is not a direct process in the way you might deploy a pre-trained JumpStart model. The "more correct" process would be to use Autopilot to train the model and have it deploy it to a Sagemaker (custom) endpoint. Of course use the API to call it. This is one of those typical AWS style questions where they obscure part of the right answer (in this case the second part) but mentions another service that satisfies the condition of the second part answer; yet, the two services don't work together as you may "assume". They're testing the depth of your service knowledge.
